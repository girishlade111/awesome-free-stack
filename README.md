## Mission

**Replace expensive developer tools with free alternatives.** This repository is the largest curated collection of free and freemium resources for developers, students, indie hackers, and startups. Every resource is vetted, categorized, and ranked so you can build, deploy, and scale without burning through your budget.

Whether you need **free cloud hosting**, **free AI APIs**, **student developer packs**, **free PostgreSQL databases**, **free authentication services**, or **free CI/CD pipelines** — this repo saves you thousands of dollars per year.

## Contributing

We welcome contributions. To add a resource:

1. Read the [Resource Template](.github/resource-template.md)
2. Add a markdown file to the appropriate `categories/<category>/` folder
3. Open a PR using the [Pull Request Template](.github/PULL_REQUEST_TEMPLATE.md)

Every submission must include: **free tier specifics**, **category**, **card requirement**, **region restrictions**, and **verification status**.
