# Build a Portfolio

Create a professional developer portfolio site with zero hosting costs.

## Stack

| Layer | Choice | Why |
|---|---|---|
| **Frontend** | Astro | Fastest static output, Markdown + components |
| **Backend** | None needed | Fully static site |
| **Hosting** | Cloudflare Pages | Unlimited bandwidth, global CDN, free |
| **Database** | None needed | Content stored in Markdown files |
| **Auth** | None needed | Public portfolio |
| **Storage** | GitHub + Cloudflare Images | Free image hosting via repo + CDN |
| **Email** | Formspree Free | 50 form submissions/mo for contact |
| **Analytics** | Umami Cloud Free | 10k events/mo, privacy-first |
| **Domain** | `*.pages.dev` or `*.vercel.app` | Free subdomain |

## Setup Steps

1. Scaffold Astro project with `create astro`
2. Choose a template (astrophere, astro-cv, or custom)
3. Write portfolio content in Markdown files
4. Add project showcase with screenshots
5. Implement contact form with Formspree
6. Add Umami analytics snippet
7. Deploy to Cloudflare Pages via GitHub
8. Point custom domain (or use free subdomain)

## Sections to Include

- Hero with tagline
- Tech stack badges
- Featured projects (3-5)
- Work experience timeline
- Blog / writing samples
- Contact form
- Social links (GitHub, Twitter, LinkedIn)

## SEO Checklist

- Meta descriptions per page
- Open Graph images
- Sitemap.xml (auto-generated by Astro)
- RSS feed for blog
- Lighthouse score target: 95+
