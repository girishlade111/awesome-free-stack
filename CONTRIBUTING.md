# Contributing

Thank you for contributing to awesome-free-stack. Every addition helps developers find quality free tools.

## How to Add a Resource

1. Read the [resource template](.github/resource-template.md).
2. Create a markdown file in the appropriate `categories/<category>/` folder.
3. Open a pull request using the [PR template](.github/PULL_REQUEST_TEMPLATE.md).

## Guidelines

- Only list tools with a meaningful free tier.
- Do not list tools requiring a credit card without noting it.
- Verify the free tier before submitting.
- Check for duplicates before adding.
- Follow the category taxonomy — see the [README](./README.md#categories).

## Verification Badges

| Badge | Meaning |
|---|---|
| ✅ Tested | Maintainer has personally verified |
| 🟡 Community Verified | Reported by community, not yet tested by maintainer |
| 🔴 Unverified | Submitted but not confirmed |
| ⚠ Deprecated | No longer free or shut down |

## Review Process

Maintainers review every submission for accuracy before merging.
