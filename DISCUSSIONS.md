# Discussions

GitHub Discussions is where the community gathers to share ideas, request tools, compare options, and help each other.

## Categories

| Category | Icon | Purpose |
|---|---|---|
| [Ideas](./../../discussions/categories/ideas) | 💡 | Suggest improvements to the repository structure, content, or tooling |
| [Tool Requests](./../../discussions/categories/tool-requests) | 🔧 | Nominate a free/freemium tool that should be added |
| [Comparisons](./../../discussions/categories/comparisons) | ⚖️ | Compare free tools head-to-head by features, limits, and experience |
| [Monthly Highlights](./../../discussions/categories/monthly-highlights) | 📅 | Monthly recap of new additions, top contributors, and trending topics |
| [Support](./../../discussions/categories/support) | 🆘 | Get help with using a listed tool or contributing to the repo |
| [Voting](./../../discussions/categories/voting) | 🗳️ | Community polls for rankings, best-of categories, and feature priority |

## Guidelines

- **Search first** — Check if your topic already exists before posting
- **Be specific** — Include tool names, free tier details, and links
- **Be respectful** — Follow the [Code of Conduct](../CODE_OF_CONDUCT.md)
- **No spam** — Promotional posts, affiliate links, and self-promotion without value will be removed
- **One topic per discussion** — Keeps conversations focused and searchable

## Voting

Rankings are influenced by community votes. When a voting discussion is active:

1. Read the nominees and criteria
2. React with the appropriate emoji to cast your vote
3. Results are tallied monthly and factored into ranking scores

See the [rankings methodology](../data/rankings.json) for how votes affect scores.

## Recognition

Active contributors earn badges:

- 🏅 **Top Voter** — Most votes cast in a quarter
- ⭐ **Helpful Member** — Frequently provides accurate answers
- 🔍 **Bug Hunter** — Reports broken tools with verified evidence
