## yq

### Description
Portable command-line YAML processor with jq-like syntax. Reads, writes, updates, and merges YAML, JSON, and XML files. Supports CSS-style selectors, shell variable injection, and in-place file editing.

### Free Tier
- Completely free open-source under MIT license
