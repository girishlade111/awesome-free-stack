## Maven

**Website**: https://maven.apache.org
**Docs**: https://maven.apache.org/guides/
**GitHub**: https://github.com/apache/maven
**Category**: devtools
**Subcategory**: package-managers

### Description
Apache build automation and dependency management tool for Java. Uses POM (Project Object Model) XML for project configuration. Manages dependencies from Maven Central with lifecycle phases (compile, test, package, deploy).
