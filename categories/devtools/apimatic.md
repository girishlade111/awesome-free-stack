## APIMatic

**Website**: https://www.apimatic.io
**Docs**: https://apimatic.io/docs
**Category**: devtools
**Subcategory**: api-tools

### Description
API SDK generation platform that creates client libraries from OpenAPI specs. Generates idiomatic SDKs in 20+ languages including C#, Python, Java, Go, Ruby, and TypeScript. Free tier for individual developers.

### Free Tier
- Free tier: 1 user, 5 APIs, SDK generation in all languages, community support
- API transformation and validation included.

### Paid Plan
- **Starting Price**: $99/month
- Business from $99/month for team collaboration, custom generators, and priority support.
