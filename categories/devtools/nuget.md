## NuGet

**Website**: https://www.nuget.org
**Docs**: https://docs.microsoft.com/en-us/nuget/
**GitHub**: https://github.com/NuGet/NuGet.Client
**Category**: devtools
**Subcategory**: package-managers

### Description
Microsoft's package manager for .NET. Hosts over 300K packages on nuget.org. Integrates with Visual Studio, CLI, and Azure DevOps. Supports semantic versioning, package signing, and private feeds.

### Free Tier
- CLI and public registry are free
- Unlimited package publishing and downloads from nuget.org
- GitHub free tier includes 2GB nuget storage.

### Paid Plan
- **Starting Price**: $6/month
- Azure Artifacts free tier: 2GB storage. Paid from $6/month for unlimited storage and private feeds.
