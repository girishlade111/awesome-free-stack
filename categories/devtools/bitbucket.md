## Bitbucket

**Website**: https://bitbucket.org
**Docs**: https://support.atlassian.com/bitbucket-cloud/
**Category**: devtools
**Subcategory**: version-control

### Description
Atlassian's Git code hosting with Jira integration. Supports unlimited private repos, pull requests, and built-in CI/CD via Bitbucket Pipelines. Free tier for small teams with 50 build minutes per month.

### Free Tier
- Free tier: up to 5 users, unlimited private repos, 50 CI build minutes/month, 1GB file storage.

### Paid Plan
- **Starting Price**: $3/month
- Standard from $3/month per user for unlimited build minutes. Premium from $6/month per user with advanced deployment.
