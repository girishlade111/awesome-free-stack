## zoxide

**Category**: devtools

### Description
Smarter cd command that learns your directory preferences. Uses a frecency algorithm to rank directories based on frequency and recency of access. Navigate to any directory with just a few keystrokes and fuzzy matching.

### Free Tier
- Completely free open-source under MIT license
- Rust-based with shell hooks for automatic learning
- Single binary.
