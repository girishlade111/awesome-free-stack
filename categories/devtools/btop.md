## btop

**Website**: https://github.com/aristocratos/btop

**Category**: devtools

### Description
Modern resource monitor with GPU support and responsive UI. Displays CPU, memory, disks, network, and GPU usage in real-time. Features mouse support, custom themes, and process management. Written in C++ with true color.

### Free Tier
- Completely free open-source under Apache 2.0
- GPU monitoring with NVIDIA, AMD, and Intel GPU support.
