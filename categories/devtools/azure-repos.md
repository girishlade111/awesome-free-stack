## Azure Repos

**Website**: https://azure.microsoft.com/en-us/services/devops/repos/
**Docs**: https://docs.microsoft.com/en-us/azure/devops/repos/
**Category**: devtools
**Subcategory**: version-control

### Description
Microsoft's Git repository hosting as part of Azure DevOps. Supports unlimited private repos, pull requests, branch policies, and semantic code search. Free for teams up to 5 users with Azure Pipelines.

### Free Tier
- Free tier: up to 5 users, unlimited private Git repos, 1,800 CI/CD pipeline minutes/month, 2GB storage.

### Paid Plan
- **Starting Price**: $6/month
- Basic from $6/month per user for unlimited CI/CD, self-hosted agents, and advanced features.
