## GitHub Copilot

**Website**: https://github.com/features/copilot
**Docs**: https://docs.github.com/en/copilot
**GitHub**: https://github.com/github/copilot-docs
**Category**: devtools
**Subcategory**: code-generation

### Description
AI pair programmer from GitHub and OpenAI that suggests code in real-time. Trained on public code repositories with support for all major languages. Integrates with VS Code, JetBrains, Neovim, and Azure. Context-aware completions.

### Free Tier
- Free tier: 2,000 code completions/month, 50 chat requests/month
- Supports all languages and IDE integrations.

### Paid Plan
- **Starting Price**: $10/month
- Copilot Pro from $10/month for unlimited completions and chat. Enterprise from $19/user/month with policy controls.
