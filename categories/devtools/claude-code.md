### Description
Anthropic's AI coding assistant powered by Claude. Terminal-native tool for code generation, debugging, refactoring, and workflow automation. Handles complex multi-file changes with agentic code exploration.

### Free Tier
- Free tier: limited daily conversations with Claude
- Pay-as-you-go for extended usage via Anthropic API.

### Paid Plan
- **Starting Price**: $20/month
- Anthropic API: pay per token. Claude Pro: $20/month for higher usage limits. Team from $25/user/month.
