## Gerrit

**Website**: https://www.gerritcodereview.com
**Docs**: https://gerrit-review.googlesource.com/Documentation/
**GitHub**: https://github.com/GerritCodeReview/gerrit
**Category**: devtools
**Subcategory**: version-control

### Description
Web-based code review system for Git repositories with line-by-line commenting. Used by Android, Eclipse, and Chrome projects. Supports patch sets, verified CI integration, and access control policies.

### Free Tier
- Completely free open-source under Apache 2.0
- Self-hosted with unlimited users, projects, and code reviews.
