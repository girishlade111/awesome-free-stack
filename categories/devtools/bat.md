## bat

**Website**: https://github.com/sharkdp/bat

**Category**: devtools
**Subcategory**: cli-tools

### Description
A cat(1) clone with syntax highlighting for 200+ languages. Integrates with Git to show modifications, line numbers, and paging. Works as a drop-in replacement for cat with less-like paging through large files.
