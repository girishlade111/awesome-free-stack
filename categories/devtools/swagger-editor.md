## Swagger Editor

**Website**: https://editor.swagger.io
**Docs**: https://swagger.io/docs/open-source-tools/swagger-editor/
**GitHub**: https://github.com/swagger-api/swagger-editor
**Category**: devtools
**Subcategory**: api-tools

### Description
Browser-based editor for OpenAPI/Swagger specification files. Real-time validation, syntax highlighting, and live preview of API documentation. Supports YAML and JSON formats with auto-completion for API definitions.

### Free Tier
- Completely free open-source under Apache 2.0
- Browser-based with no installation needed
- Can be self-hosted or used on editor.swagger.io.

### Paid Plan
- **Starting Price**: $49/month
- SwaggerHub free tier: 1 user, 2 private APIs. Pro from $49/month for team API design collaboration.
