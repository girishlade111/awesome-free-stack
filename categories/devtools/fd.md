## fd

**Website**: https://github.com/sharkdp/fd
**Docs**: https://github.com/sharkdp/fd#fd
**GitHub**: https://github.com/sharkdp/fd
**Category**: devtools
**Subcategory**: cli-tools

### Description
Fast and user-friendly alternative to the find command. Uses parallel traversal with regex/glob patterns, colorized output, and smart case detection. Respects gitignore by default. Single binary written in Rust.
