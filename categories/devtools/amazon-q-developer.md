### Description
AWS's AI-powered development assistant with code generation, debugging, and AWS expertise. Generates code, explains code, detects vulnerabilities, and helps build cloud applications. Free tier with generous monthly limits.

### Free Tier
- Free tier: 50 code completions/month, unlimited chat requests, AWS infrastructure expertise
- Code vulnerability scanning included.

### Paid Plan
- **Starting Price**: $19/month
- Professional from $19/user/month with unlimited completions. Enterprise with admin controls and SAML SSO.
