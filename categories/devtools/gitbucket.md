## GitBucket

**Website**: https://gitbucket.github.io
**Docs**: https://github.com/gitbucket/gitbucket/wiki
**GitHub**: https://github.com/gitbucket/gitbucket
**Category**: devtools
**Subcategory**: version-control

### Description
Self-hosted Git platform written in Scala with a GitHub-like interface. Single JAR deployment with no external database required. Supports pull requests, issues, wiki, and Git LFS. Lightweight and easy to set up.

### Free Tier
- Completely free open-source under Apache 2.0
- Runs as a single JAR file with embedded H2 database
- Unlimited repos and users.
