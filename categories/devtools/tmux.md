## tmux

**Website**: https://github.com/tmux/tmux
**Docs**: https://github.com/tmux/tmux/wiki
**GitHub**: https://github.com/tmux/tmux
**Category**: devtools
**Subcategory**: cli-tools

### Description
Terminal multiplexer enabling multiple terminal sessions within a single window. Features session persistence, split panes, window management, and customizable key bindings. Essential for remote server work and development.

### Free Tier
- Completely free open-source under BSD license
- Runs in any terminal without GUI
- Session persistence across network disconnects.
