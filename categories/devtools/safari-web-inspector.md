## Safari Web Inspector

**Website**: https://webkit.org/web-inspector/
**Docs**: https://webkit.org/web-inspector/web-inspector-guide/
**GitHub**: https://github.com/WebKit/webkit
**Category**: devtools
**Subcategory**: browser-devtools

### Description
Apple's built-in web development tools in Safari. Features Elements tab, Timeline, Debugger, Console, Storage, Accessibility tree, and responsive design mode. Essential for iOS web debugging via remote inspection.

### Free Tier
- Completely free — built into Safari on macOS and iOS
- Enable via Develop menu in Safari preferences.
