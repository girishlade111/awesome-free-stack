## AskCodi

**Website**: https://www.askcodi.com
**Docs**: https://docs.askcodi.com

### Description
AI coding assistant with code generation, explanation, testing, and documentation features. Supports 50+ languages with IDE integrations for VS Code, JetBrains, and more. Includes SQL, regex, and Excel formula generators.

### Free Tier
- Free tier: 10 AI requests per week, basic code generation, and community support
- All features included with limits.

### Paid Plan
- **Starting Price**: $13/month
- Pro from $12.99/month for unlimited requests, priority support, and advanced AI models.
