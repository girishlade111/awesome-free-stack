## Tabnine

**Website**: https://www.tabnine.com
**Docs**: https://www.tabnine.com/docs

**Category**: devtools

### Description
AI code completion assistant with local and cloud models. Supports 90+ languages and 15+ IDEs. Offers context-aware completions based on entire codebase. Enterprise version can be deployed on-premises with data privacy.

### Free Tier
- Free tier: basic code completions, all languages, community support
- Local model runs on your machine with no data sharing.

### Paid Plan
- **Starting Price**: $12/month
- Pro from $12/month for full-line completions, whole-codebase context, and priority support.
