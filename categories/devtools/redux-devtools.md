## Redux DevTools

**Website**: https://github.com/reduxjs/redux-devtools
**Docs**: https://github.com/reduxjs/redux-devtools/tree/main/docs
**GitHub**: https://github.com/reduxjs/redux-devtools
**Category**: devtools
**Subcategory**: browser-devtools

### Description
Developer tools for Redux state management. Features time-travel debugging, action replay, state diffing, and custom monitors. Available as browser extension and standalone app. Integrates with Redux Toolkit.

### Free Tier
- Completely free open-source under MIT license
- Browser extension with action history and state export/import.
