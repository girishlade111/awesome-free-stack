## BundlePhobia

**Website**: https://bundlephobia.com
**Docs**: https://bundlephobia.com/docs
**GitHub**: https://github.com/pastelsky/bundlephobia
**Category**: devtools
**Subcategory**: browser-devtools

### Description
Find the size of npm packages before adding them to your project. Analyzes minified and gzipped bundle sizes with tree-shaking analysis. Shows dependency graph and compares alternative package sizes.

### Free Tier
- Completely free web tool

- Unlimited package size lookups with dependency analysis.
