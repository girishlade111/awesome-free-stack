## GitLab

**Website**: https://gitlab.com
**Docs**: https://docs.gitlab.com
**GitHub**: https://gitlab.com/gitlab-org/gitlab
**Category**: devtools
**Subcategory**: version-control

### Description
Complete DevOps platform with Git repositories, CI/CD, container registry, and security scanning. Self-hosted or SaaS with built-in CI/CD pipelines. Free tier includes unlimited private repos and 400 CI/CD minutes.

### Free Tier
- SaaS free tier: unlimited repos, 400 CI/minutes/month, 5GB storage
- Self-hosted Community Edition is completely free.

### Paid Plan
- **Starting Price**: $24/month
- Premium from $24/month per user. Ultimate from $99/month per user with security scanning and compliance.
