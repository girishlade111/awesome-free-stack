## Polypane

**Website**: https://polypane.app
**Docs**: https://polypane.app/docs/
**Category**: devtools
**Subcategory**: browser-devtools

### Description
Purpose-built browser for responsive web development and design. Displays multiple viewports simultaneously with synchronized browsing. Includes CSS grid tools, accessibility checker, and social media preview generator.

### Free Tier
- Free tier: 3 viewports, basic features
- Ideal for individual developers testing responsiveness.

### Paid Plan
- **Starting Price**: $19/month
- Pro from $19/month for unlimited viewports, advanced features, and team sync.
