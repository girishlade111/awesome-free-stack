## Responsively App

**Website**: https://responsively.app
**Docs**: https://responsively.app/docs
**GitHub**: https://github.com/responsively-org/responsively-app
**Category**: devtools
**Subcategory**: browser-devtools

### Description
Open-source web browser for responsive web development. Mirrors page across multiple screen sizes simultaneously with device frames. Features element inspection, screenshot capture, and hot-reload for live editing.
