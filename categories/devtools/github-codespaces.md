### Description
Cloud development environments integrated into GitHub. Spin up full dev environments in seconds with customizable dev containers, VS Code in browser, and pre-installed tools. Code from any device.

### Free Tier
- **Compute**: 120 core-hours/month (2-core: 60h, 4-core: 30h)
- **Storage**: 15 GB
- **Features**: Prebuilds, dotfiles, VS Code desktop + browser, dev container config

### Paid Plan
- **Team**: $4/user/month
- **Features**: 180 core-hours, 20GB storage, org management, audit logs
