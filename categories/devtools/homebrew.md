## Homebrew

**Website**: https://brew.sh
**Docs**: https://docs.brew.sh
**GitHub**: https://github.com/Homebrew/brew
**Category**: devtools
**Subcategory**: package-managers

### Description
The missing package manager for macOS (and Linux). Installs command-line tools, libraries, and desktop apps with a simple formula system. Manages 6,000+ formulas and 6,000+ casks with automatic dependency resolution.
