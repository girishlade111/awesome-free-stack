## Hex

**Website**: https://hex.pm
**Docs**: https://hex.pm/docs

**Category**: devtools

### Description
Package manager for the Erlang ecosystem (Elixir and Erlang). Provides hex.pm registry with dependency resolution, documentation hosting, and package publishing. Mix integration for Elixir projects.

- Completely free open-source under MIT license
