## Cargo

**Website**: https://doc.rust-lang.org/cargo/

**Category**: devtools

### Description
Rust's built-in package manager and build system. Handles dependencies from crates.io, builds, tests, benchmarks, and documentation. Features workspaces, lockfiles, semantic versioning, and custom registries.

### Free Tier
- Completely free open-source under MIT/Apache 2.0
- Ships with Rust
- Access to crates.io with unlimited package publishing.
