## GitKraken

**Website**: https://www.gitkraken.com
**Docs**: https://help.gitkraken.com
**Category**: devtools
**Subcategory**: version-control

### Description
Cross-platform Git GUI client with intuitive visual interface. Features drag-and-drop branching, built-in merge conflict editor, interactive rebase, and Git LFS support. Free for non-commercial use with premium features.

### Free Tier
- Free plan: Git GUI with visual commits, branching, and staging
- No commercial use
- Integrates with GitHub, GitLab, Bitbucket.

### Paid Plan
- **Starting Price**: $59/month
- Pro from $59/year for commercial use, Glo boards, and premium support. Enterprise with SSO and admin controls.
