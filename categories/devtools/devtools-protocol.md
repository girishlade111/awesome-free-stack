## Chrome DevTools Protocol

**Website**: https://chromedevtools.github.io/devtools-protocol/
**Docs**: https://chromedevtools.github.io/devtools-protocol/tot/
**GitHub**: https://github.com/ChromeDevTools/devtools-protocol
**Category**: devtools
**Subcategory**: browser-devtools

### Description
API for instrumenting, inspecting, debugging, and profiling Chromium-based browsers. Enables programmatic control of browser automation, network interception, performance metrics, and DOM inspection via WebSocket.

### Free Tier
- Completely free open-source protocol
- Built into every Chrome/Chromium instance
- No usage limits or license required.
