## Lighthouse

**Website**: https://developer.chrome.com/docs/lighthouse/
**Docs**: https://developer.chrome.com/docs/lighthouse/overview/
**GitHub**: https://github.com/GoogleChrome/lighthouse
**Category**: devtools
**Subcategory**: browser-devtools

### Description
Automated auditing tool for web page quality by Google. Audits performance, accessibility, SEO, best practices, and Progressive Web Apps. Generates actionable reports with scores and optimization suggestions.

### Free Tier
- Completely free open-source under Apache 2.0
- CLI, Node module, Chrome DevTools panel, and PageSpeed Insights available.
