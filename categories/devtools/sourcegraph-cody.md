**Website**: https://sourcegraph.com/cody

### Description
AI coding assistant with deep codebase understanding. Answers questions about your entire codebase, generates code, and fixes bugs. Uses code graph indexing for context-aware completions beyond file-level scope.

### Free Tier
- Free tier: unlimited code completions and chat with Cody Free
- 10 chat messages/week with Pro LLMs
- Code graph search included.

### Paid Plan
- **Starting Price**: $9/month
- Pro from $9/month for unlimited Pro LLM messages, custom commands, and advanced context.
