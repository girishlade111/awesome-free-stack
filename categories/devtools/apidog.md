## ApiDog

**Website**: https://www.apidog.com
**Docs**: https://docs.apidog.com
**Category**: devtools
**Subcategory**: api-tools

### Description
All-in-one API collaboration platform combining design, debugging, testing, and documentation. Supports REST, GraphQL, WebSocket, and gRPC. Free team collaboration with CI/CD integration and API mocking.

### Free Tier
- Free tier: 3 team members, unlimited API requests, API documentation, and cloud mocking
- 30-day version history.

### Paid Plan
- **Starting Price**: $10/month
- Team from $9.90/month per user for unlimited team members, advanced mocking, and priority support.
