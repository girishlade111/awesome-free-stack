### Description
Beautiful API documentation hosting platform with interactive features. Automatically syncs from OpenAPI specs with code examples and try-it-out API console. Free tier for public documentation pages.

### Free Tier
- Free tier: unlimited public docs, 1 project, community support
- Auto-generated from OpenAPI/Swagger specs.

### Paid Plan
- **Starting Price**: $99/month
- Pro from $99/month for custom domain, private docs, and API metrics. Enterprise with SSO and audit log.
