## GraphQL Playground

### Description
Interactive GraphQL IDE for exploring schemas and testing queries. Features schema viewer, query history, subscription support, and multiple themes. Works as a standalone app, browser tool, or embedded IDE.

### Free Tier
- Completely free open-source under MIT license
- Desktop app and browser-based IDE with full GraphQL introspection support.
