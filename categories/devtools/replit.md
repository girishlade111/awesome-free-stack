## Replit

**Website**: https://replit.com
**Docs**: https://docs.replit.com
**GitHub**: https://github.com/replit
**Category**: devtools
**Subcategory**: code-editors

### Description
Online IDE with instant dev environments, AI-powered code completion (Ghostwriter), and team collaboration. Deploy apps with one click. The easiest way to code from any browser without setup.

### Free Tier
- **Repls**: Unlimited public
- **Storage**: 500MB
- **Compute**: 1 vCPU, 512MB RAM
- **AI**: Ghostwriter included
- **Deployments**: Community hosting

### Paid Plan
- **Core**: $20/month
- **Features**: Unlimited private repls, 4 vCPU/4GB RAM, boosted AI, always-on
