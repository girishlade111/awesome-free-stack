## npm

**Website**: https://www.npmjs.com
**Docs**: https://docs.npmjs.com
**GitHub**: https://github.com/npm/cli
**Category**: devtools
**Subcategory**: package-managers

### Description
The default Node.js package manager with the world's largest software registry (2M+ packages). CLI for installing, publishing, and managing dependencies. Supports workspaces, lockfiles, and semver versioning.

### Free Tier
- CLI is free open-source
- Public packages free to publish and install
- Free private packages: 2 users per org, unlimited packages.

### Paid Plan
- **Starting Price**: $7/month
- Pro from $7/month for unlimited private packages and teams. Enterprise with SSO and custom registry.
