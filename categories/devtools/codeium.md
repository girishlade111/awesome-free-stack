**Website**: https://codeium.com

### Description
Free AI code acceleration platform with code completion, search, and chat. Supports 70+ languages and 40+ IDEs. Features natural language search across codebases and AI-powered refactoring suggestions.

### Free Tier
- Free tier: unlimited code completions, code search, and AI chat for individual developers
- No credit card required.

### Paid Plan
- **Starting Price**: $15/month
- Teams from $15/user/month for admin controls, SSO, and usage analytics.
