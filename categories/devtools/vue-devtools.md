## Vue DevTools

**Website**: https://devtools.vuejs.org
**Docs**: https://devtools.vuejs.org/guide/
**GitHub**: https://github.com/vuejs/devtools
**Category**: devtools
**Subcategory**: browser-devtools

### Description
Browser extension and standalone app for debugging Vue.js applications. Inspect component tree, reactive data, computed properties, Vuex store, and router. Timeline for event and performance tracing.

### Free Tier
- Completely free open-source under MIT license
- Browser extension with offline usage
- No remote servers or accounts needed.
