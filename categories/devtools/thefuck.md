### Description
Command correction tool that fixes your previous shell command. Detects and corrects common errors like misspellings, missing sudo, wrong Git commands, and incorrect directory names. Activates with the "fuck" command.

### Free Tier
- Completely free open-source under MIT license
- Learns from shell history with 50+ correction rules.
