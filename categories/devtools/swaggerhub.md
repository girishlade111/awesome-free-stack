### Description
API design and documentation platform by SmartBear. Collaboratively design OpenAPI specs with integrated editor, mock server, and auto-generated docs. Free tier for individual developers and open source projects.

### Free Tier
- Free tier: 1 user, 2 private APIs, unlimited public APIs
- Includes API editor, mock server, and documentation.

### Paid Plan
- **Starting Price**: $49/month
- Pro from $49/month for unlimited APIs and collaborators. Enterprise with SSO, audit logs, and SLA.
