## Gogs

**Website**: https://gogs.io
**Docs**: https://gogs.io/docs
**GitHub**: https://github.com/gogs/gogs
**Category**: devtools
**Subcategory**: version-control

### Description
Self-hosted Git service written in Go with minimal resource requirements. Runs on Raspberry Pi-level hardware. Supports repository browsing, issue tracker, pull requests, webhooks, and LDAP authentication.

### Free Tier
- Completely free open-source under MIT license
- Extremely lightweight — runs on 512MB RAM
- Unlimited users and repos.
