## AWS CodeCommit

**Website**: https://aws.amazon.com/codecommit/
**Docs**: https://docs.aws.amazon.com/codecommit/
**Category**: devtools
**Subcategory**: version-control

### Description
Amazon's managed Git repository service with no repository size limits. Integrated with AWS IAM, CodeBuild, CodePipeline, and CloudTrail. Encrypted at rest with 50GB storage per repo.

### Free Tier
- Free tier: 5 active users, 50GB storage, 10,000 Git requests/month
- Unlimited repositories within free limits.

### Paid Plan
- **Starting Price**: $1/month
- $1/user/month for active users beyond free tier. $0.10/GB of storage beyond free tier. Pay-as-you-go pricing.
