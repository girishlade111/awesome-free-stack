## DVC

**Website**: https://dvc.org
**Docs**: https://dvc.org/doc
**GitHub**: https://github.com/iterative/dvc
**Category**: devtools
**Subcategory**: version-control

### Description
Open-source version control for machine learning projects. Extends Git to track datasets, models, and experiments. Manages data pipelines with caching, remote storage (S3, GCS, Azure), and experiment tracking.

### Free Tier
- Completely free open-source under Apache 2.0
- CLI tool with no usage limits
- Integrates with any cloud storage backend.

### Paid Plan
- **Starting Price**: $50/month
- DVC Studio free tier: 25GB storage, 1 project. Pro from $50/month for more storage and collaboration.
