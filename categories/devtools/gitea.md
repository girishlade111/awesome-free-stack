## Gitea

**Website**: https://gitea.io
**Docs**: https://docs.gitea.io
**GitHub**: https://github.com/go-gitea/gitea
**Category**: devtools
**Subcategory**: version-control

### Description
Lightweight, self-hosted Git service written in Go. Minimal resource usage with high performance. Features repository management, issue tracking, pull requests, CI/CD via Actions, and OAuth integration.

### Free Tier
- Completely free open-source under MIT license
- Self-hosted with unlimited users, repos, and storage (depends on host).

### Paid Plan
- **Starting Price**: N/A
- No paid version; fully free and open source. Cloud hosting available from codeberg.org.
