## Stoplight Studio

**Website**: https://stoplight.io/studio
**Docs**: https://docs.stoplight.io/docs/studio/
**GitHub**: https://github.com/stoplightio
**Category**: devtools
**Subcategory**: api-tools

### Description
Visual API design editor with OpenAPI 3.0 support. Drag-and-drop interface for designing REST APIs with real-time validation. Generates server stubs, client SDKs, and interactive documentation from API specs.

### Free Tier
- Free tier: desktop app with visual API designer, real-time validation, and mock server
- Limited to 1 workspace.

### Paid Plan
- **Starting Price**: $59/month
- Pro from $59/month for cloud collaboration, advanced mocking, and team workspaces.
