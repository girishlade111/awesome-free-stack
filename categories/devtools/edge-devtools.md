## Edge DevTools

**Website**: https://learn.microsoft.com/en-us/microsoft-edge/devtools-guide-chromium/
**Docs**: https://learn.microsoft.com/en-us/microsoft-edge/devtools-guide-chromium/overview
**Category**: devtools
**Subcategory**: browser-devtools

### Description
Chromium-based Edge developer tools with Microsoft-specific features. Includes CSS grid tools, 3D view, issues tab, and AI-powered debugging. Available in Edge browser with deep Azure/Office 365 integration.

### Free Tier
- Completely free — built into Microsoft Edge browser
- Based on Chrome DevTools with additional Microsoft features.
