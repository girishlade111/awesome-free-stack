# Free Developer Tools

Curated collection of free code editors, IDEs, and development environments.

## Quick Comparison

| Tool | Type | Free Limit | AI Features | Card? |
|---|---|---|---|---|
| **VS Code** | Desktop Editor | 100% free, forever | Copilot integration | No |
| **Cursor** | AI IDE (desktop) | 2,000 AI requests/mo | ✅ Deep AI | No |
| **Windsurf** | AI IDE (desktop) | Unlimited completions | ✅ AI chat | No |
| **Replit** | Online IDE | 500MB, 1vCPU | ✅ Ghostwriter | No |
| **Zed** | Desktop Editor | 100% free, OSS | ✅ AI completions | No |
| **GitHub Codespaces** | Cloud Dev Env | 120 core-hours/mo | ❌ | No |

## Selection Guide

- **Best overall editor**: VS Code — massive ecosystem, free, all platforms
- **Best AI coding**: Cursor — most popular AI IDE, generous free tier
- **Best free AI**: Zed (free unlimited AI) or Windsurf (unlimited completions)
- **Best online IDE**: Replit — instant shareable environments
- **Best cloud dev**: GitHub Codespaces — full dev container in browser
- **Best for speed**: Zed — built in Rust, instant startup
- **Best for students**: All have free tiers; most have GitHub Pack benefits
