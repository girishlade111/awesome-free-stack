## Gradle

**Website**: https://gradle.org
**Docs**: https://docs.gradle.org
**GitHub**: https://github.com/gradle/gradle
**Category**: devtools
**Subcategory**: package-managers

### Description
Advanced build automation tool for Java, Kotlin, Android, and Groovy. Uses Groovy/Kotlin DSL with incremental builds and build caching. Default build system for Android with multi-project support.

### Free Tier
- Completely free open-source under Apache 2.0
- Build caching and parallel execution included
- No usage limits.
