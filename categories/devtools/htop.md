## htop

**Website**: https://htop.dev
**Docs**: https://htop.dev/docs/
**GitHub**: https://github.com/htop-dev/htop
**Category**: devtools
**Subcategory**: cli-tools

### Description
Interactive process viewer and system monitor for the terminal. Color-coded display of processes, CPU, memory, and swap usage. Features tree view, mouse support, process filtering, and signal sending via function keys.
