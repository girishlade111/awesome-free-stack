## ripgrep (rg)

**Website**: https://github.com/BurntSushi/ripgrep
**Docs**: https://github.com/BurntSushi/ripgrep/blob/master/GUIDE.md
**GitHub**: https://github.com/BurntSushi/ripgrep
**Category**: devtools
**Subcategory**: cli-tools

### Description
Ultra-fast text search tool recursively searching directories. Uses Rust's regex engine with automatic gitignore filtering. Significantly faster than grep, ack, and ag. Supports PCRE2, multi-line search, and binary detection.

### Free Tier
- Completely free open-source under MIT license
- Single binary with no dependencies
- Recursive search with smart-case matching.
