### Description
Open-source OpenAPI documentation renderer with three-panel layout. Generates responsive, searchable API reference docs from any OpenAPI/Swagger spec. Features code samples, schema tables, and Try It console.

### Free Tier
- Completely free open-source under MIT license
- Self-hosted with customizable theme and branding options.
