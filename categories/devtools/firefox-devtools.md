## Firefox Developer Tools

**Website**: https://firefox-dev.tools
**Docs**: https://developer.mozilla.org/en-US/docs/Tools
**GitHub**: https://github.com/firefox-devtools
**Category**: devtools
**Subcategory**: browser-devtools

### Description
Integrated web development tools in Firefox. Unique features like CSS Grid/Flexbox inspectors, accessibility inspector, 3D view, and responsive design mode. Advanced debugging with source map support.

### Free Tier
- Completely free — built into every Firefox and Firefox Developer Edition browser
- No configuration needed.
