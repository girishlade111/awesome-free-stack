## Angular DevTools

**Website**: https://angular.io/guide/devtools
**Docs**: https://angular.io/guide/devtools
**GitHub**: https://github.com/angular/angular-devtools
**Category**: devtools
**Subcategory**: browser-devtools

### Description
Browser extension for debugging Angular applications. Inspect component tree, change detection, dependency injection, and NgRx state. Performance profiling with flame graphs and change detection cycle visualization.
