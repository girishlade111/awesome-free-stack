### Description
The world's most popular code editor. Open-source with a massive extension ecosystem (50,000+), built-in Git, debugging, terminal, IntelliSense, and Live Share. Free for everyone, forever.

### Free Tier
- **Editor**: 100% free and open-source
- **Extensions**: 50,000+ in marketplace
- **Features**: IntelliSense, debugging, Git, terminal, tasks, snippets, Live Share
- **Platforms**: Windows, macOS, Linux, web (vscode.dev)

### Paid Plan
- **Price**: No paid version
- **Copilot**: AI pair programming via GitHub Copilot ($10/month)
