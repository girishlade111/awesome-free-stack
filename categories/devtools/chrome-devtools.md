## Chrome DevTools

**Website**: https://developer.chrome.com/docs/devtools/
**Docs**: https://developer.chrome.com/docs/devtools/overview/
**GitHub**: https://github.com/ChromeDevTools
**Category**: devtools
**Subcategory**: browser-devtools

### Description
Built-in set of web authoring and debugging tools in Google Chrome. Features Elements panel, Console, Sources debugger, Network analyzer, Performance profiler, Lighthouse audits, and Application storage viewer.

### Free Tier
- Completely free — built into every Chrome/Chromium browser
- No installation or configuration needed.
