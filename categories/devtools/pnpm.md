## pnpm

**Website**: https://pnpm.io
**Docs**: https://pnpm.io/motivation
**GitHub**: https://github.com/pnpm/pnpm
**Category**: devtools
**Subcategory**: package-managers

### Description
Fast, disk-space-efficient Node.js package manager using content-addressable storage. Features strict dependency isolation, workspaces, and monorepo support. Up to 2x faster than npm with significantly less disk usage.

### Free Tier
- Completely free open-source under MIT license
- Content-addressable storage saves disk space across projects.
