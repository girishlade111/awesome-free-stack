## Conda

**Website**: https://docs.conda.io

### Description
Cross-platform package and environment manager for Python and data science. Manages binary packages for Python, R, C/C++, and CUDA. Supports environment snapshots, reproducible builds, and channel-based distribution.

### Free Tier
- Completely free open-source under BSD license
- Largest package ecosystem for data science with Anaconda repository.

### Paid Plan
- **Starting Price**: $49/month
- Anaconda Business from $49/user/year with commercial license. Team and Enterprise tiers available.
