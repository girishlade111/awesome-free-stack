## Go Modules

**Website**: https://go.dev/ref/mod
**Docs**: https://go.dev/doc/modules/managing-dependencies
**GitHub**: https://github.com/golang/go
**Category**: devtools
**Subcategory**: package-managers

### Description
Go's official dependency management system built into the Go toolchain. Uses go.mod and go.sum files for reproducible builds. Fetches packages directly from Git repositories with semantic versioning and minimal version selection.

### Free Tier
