## WebPageTest

**Website**: https://www.webpagetest.org
**Docs**: https://docs.webpagetest.org
**GitHub**: https://github.com/WPO-Foundation/webpagetest
**Category**: devtools
**Subcategory**: browser-devtools

### Description
Web performance testing tool with real browsers from worldwide locations. Provides waterfall charts, filmstrip view, performance grades, content breakdown, and TTFB analysis. Free public instance with advanced tests.

### Free Tier
- Free public instance on webpagetest.org with real Chrome browsers
- Run custom tests from multiple global locations.

### Paid Plan
- **Starting Price**: $50/month
- API plans from $50/month for higher test volumes. Enterprise with private instances and SLA.
