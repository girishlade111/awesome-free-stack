## Git LFS

**Website**: https://git-lfs.com
**Docs**: https://github.com/git-lfs/git-lfs#git-lfs
**GitHub**: https://github.com/git-lfs/git-lfs
**Category**: devtools
**Subcategory**: version-control

### Description
Git extension for handling large files by replacing them with text pointers. Stores large binary files (design assets, datasets, audio) on external storage while Git tracks lightweight references. Supported by major hosting platforms.

### Free Tier
- Open-source Git extension free under MIT license
- GitHub free tier: 2GB LFS storage, 2GB bandwidth/month.

### Paid Plan
- **Starting Price**: $5/month
- GitHub LFS paid: $5/month for 50GB storage, 50GB bandwidth. GitLab and Bitbucket have separate LFS pricing.
