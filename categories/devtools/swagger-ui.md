## Swagger UI

**Website**: https://swagger.io/tools/swagger-ui/
**Docs**: https://swagger.io/docs/open-source-tools/swagger-ui/
**GitHub**: https://github.com/swagger-api/swagger-ui
**Category**: devtools
**Subcategory**: api-tools

### Description
Interactive API documentation renderer for OpenAPI specs. Generates a fully interactive web UI where users can explore and test API endpoints. Supports try-it-out functionality with request/response visualization.

### Free Tier
- Completely free open-source under Apache 2.0
- Self-hosted or use the hosted demo
- Interactive "Try it out" API testing built-in.
