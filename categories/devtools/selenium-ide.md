## Selenium IDE

**Website**: https://www.selenium.dev/selenium-ide/
**Docs**: https://www.selenium.dev/documentation/ide/
**GitHub**: https://github.com/SeleniumHQ/selenium-ide
**Category**: devtools
**Subcategory**: browser-devtools

### Description
Browser extension for record-and-playback web test automation. Records user interactions for replay as Selenium tests. Export tests to Python, Java, C#, Ruby, and JavaScript. Built-in locator assistance.

### Free Tier
- Completely free open-source browser extension under Apache 2.0
- Record unlimited tests with export to multiple languages.
