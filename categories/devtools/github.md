### Description
The world's largest code hosting platform with Git-based version control. Features pull requests, issues, actions CI/CD, code review, wikis, and project management. Free tier includes unlimited private repositories with collaborators.

### Free Tier
- Free tier: unlimited public and private repositories, 2,000 CI/minutes/month, 500MB storage, 1GB bandwidth
- Student Pack includes $200+ in credits.

### Paid Plan
- **Starting Price**: $4/month
- Team from $4/month per user. Enterprise from $21/month per user with SAML SSO, audit log, and 50GB storage.
