## 2. Selection Guide

```
Need hosting...
│
├── VPS (full control, root access)?
│   ├── Best value → Linode ($100 credit, no card needed)
│   └── Global coverage → Vultr (25+ locations, bare metal)
│
├── Free shared hosting (no cost)?
│   ├── Most generous → InfinityFree (1 GB, unlimited bandwidth)
│   └── Simple & reliable → Alwaysdata (100 MB, free DNS)
│
├── Manage containers visually?
│   └── Portainer (CE is free, Docker/K8s UI)
│
├── Self-hosted Heroku alternative?
│   └── CapRover (one-command deploy on any VPS)
│
└── Larger cloud platforms?
    └── See [Cloud](../cloud/cloud.md)
```
