## k6

**Website**: https://k6.io
**Docs**: https://k6.io/docs/
**GitHub**: https://github.com/grafana/k6
**Category**: testing
**Subcategory**: load-testing

### Description
Grafana's modern load testing tool built with Go. JavaScript-extensible with CLI execution and Grafana dashboard integration. Supports HTTP/1.1, HTTP/2, WebSocket, gRPC, and browser-level testing. Free tier with cloud execution.

### Free Tier
- Open-source CLI is completely free with unlimited local tests
- Cloud free tier: 50 virtual users/month, 500K test runs, 10 cloud runs/month.

### Paid Plan
- **Starting Price**: $87/month
- Cloud Pro from $87/month for 1K VUs and 5M test runs. Enterprise with dedicated infrastructure and support.
