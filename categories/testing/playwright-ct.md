## Playwright Test Runner

**Website**: https://playwright.dev
**Docs**: https://playwright.dev/docs/intro
**GitHub**: https://github.com/microsoft/playwright
**Category**: testing
**Subcategory**: browser-testing

### Description
Microsoft's cross-browser test runner supporting Chromium, Firefox, and WebKit. Features auto-waiting, network interception, mobile emulation, component testing, and trace viewer. Superior cross-browser reliability vs Selenium.

### Free Tier
- Completely free open-source under Apache 2.0
- All three browser engines included
- No usage limits or cloud dependency.
