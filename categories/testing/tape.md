## Tape

**Website**: https://github.com/tape-testing/tape

**Category**: testing

### Description
Minimalist JavaScript test framework producing TAP-output. Zero dependencies with a simple API. Designed for testing that produces standard TAP output consumable by any TAP reporter. Works with Node.js and browsers.
