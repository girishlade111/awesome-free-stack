## Mockoon

**Website**: https://mockoon.com

### Description
Open-source API mocking tool for designing and testing APIs locally. Desktop app with instant mock servers, route configuration, response templating, and proxy mode. No cloud dependency with portable configuration files.

### Free Tier
- Completely free open-source desktop app under MIT license
