## Apache JMeter

**Website**: https://jmeter.apache.org
**Docs**: https://jmeter.apache.org/usermanual/
**GitHub**: https://github.com/apache/jmeter
**Category**: testing
**Subcategory**: load-testing

### Description
Full-featured Java-based load testing tool by Apache. Tests HTTP, JDBC, FTP, SOAP, JMS, LDAP, and more. GUI test planner with CLI execution for distributed load generation. Extensive plugin ecosystem.

### Free Tier
- Completely free under Apache 2.0 license
- GUI-based test creation with CLI for distributed execution.
