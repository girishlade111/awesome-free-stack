## Visual Regression Tracker

**Website**: https://visual-regression-tracker.com
**Docs**: https://docs.visual-regression-tracker.com

### Description
Open-source visual regression testing tool with a web dashboard. Self-hosted backend with support for numerous integrations (Cypress, Playwright, WebDriverIO, Puppeteer). Tracks image diffs with approval workflow.
