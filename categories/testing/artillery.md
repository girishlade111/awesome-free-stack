## Artillery

**Website**: https://artillery.io
**Docs**: https://artillery.io/docs
**GitHub**: https://github.com/artilleryio/artillery
**Category**: testing
**Subcategory**: load-testing

### Description
Modern cloud-scale load testing tool with JavaScript/TypeScript DSL. Tests HTTP, WebSocket, Socket.io, gRPC, and GraphQL services. Features real-time reporting, distributed execution, and CI/CD integration.

### Free Tier
- Open-source CLI is free with unlimited tests
- Artillery Cloud free tier: 10 tests/month, 5 min/test duration, 1 region.

### Paid Plan
- **Starting Price**: $199/month
- Cloud plans from $199/month for 100 tests and 30-min duration. Enterprise with custom pricing.
