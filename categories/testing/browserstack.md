## BrowserStack

**Website**: https://www.browserstack.com
**Docs**: https://www.browserstack.com/docs
**Category**: testing
**Subcategory**: browser-testing

### Description
Cloud-based cross-browser testing platform with 3,000+ real browser-device-OS combinations. Supports live interactive testing, automated Selenium/Cypress/Playwright testing, and Percy visual regression. Free for open source projects.

### Free Tier
- Free for open source projects with unlimited automated tests
- Developer plan includes 60-min live testing sessions.

### Paid Plan
- **Starting Price**: $29/month
- Live plans from $29/month for 30-min parallel sessions. Automate plans from $129/month for 5 parallel tests.
