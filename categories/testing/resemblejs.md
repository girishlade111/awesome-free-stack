## Resemble.js

**Website**: https://github.com/rsmbl/Resemble.js
**Docs**: https://github.com/rsmbl/Resemble.js#resemblejs
**GitHub**: https://github.com/rsmbl/Resemble.js
**Category**: testing
**Subcategory**: visual-regression

### Description
Image comparison and visual regression library for Node.js and browsers. Analyzes and compares images with tolerance settings, ignoring anti-aliasing. Provides color mismatch analysis and bounding box detection.

### Free Tier
- Completely free open-source under MIT license
- Works in browsers and Node.js with canvas-based comparison.
