## Pixelmatch

**Website**: https://github.com/mapbox/pixelmatch
**Docs**: https://github.com/mapbox/pixelmatch#pixelmatch
**GitHub**: https://github.com/mapbox/pixelmatch
**Category**: testing
**Subcategory**: visual-regression

### Description
Fast, accurate pixel-level image comparison library by Mapbox. Compares images and outputs a diff PNG with anti-aliased pixel detection. Used by BackstopJS and other visual testing tools as the comparison engine.

### Free Tier
- Completely free open-source under ISC license
- Library-only with no CLI or GUI
- Designed for integration into testing tools.
