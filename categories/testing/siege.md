## Siege

**Website**: https://www.joedog.org/siege-home/
**Docs**: https://www.joedog.org/siege-manual/
**GitHub**: https://github.com/JoeDog/siege
**Category**: testing
**Subcategory**: load-testing

### Description
HTTP/HTTPS load testing and benchmarking utility with configurable concurrency. Supports basic authentication, cookies, random URL selection from a file, and multi-protocol testing. Simulates multiple users hitting a web server.

### Free Tier
- Completely free open-source under GPLv3
- Supports HTTP/HTTPS, FTP, and configurable concurrent user simulation.
