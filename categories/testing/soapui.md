## SoapUI

**Website**: https://www.soapui.org
**Docs**: https://www.soapui.org/docs/
**GitHub**: https://github.com/SmartBear/soapui
**Category**: testing
**Subcategory**: api-testing

### Description
Open-source API testing tool for SOAP and REST. Features functional testing, load testing, security scanning, and mock services. GUI-based test creation with Groovy scripting for advanced scenarios.

### Free Tier
- SoapUI Open Source is completely free for REST and SOAP API testing
- GUI and CLI with all functional testing features.

### Paid Plan
- **Starting Price**: $549/month
- SoapUI Pro from $549/year for advanced features like JSON/XML assertions, form editor, and SQL database support.
