## Mocha

**Website**: https://mochajs.org
**Docs**: https://mochajs.org/#getting-started
**GitHub**: https://github.com/mochajs/mocha
**Category**: testing
**Subcategory**: unit-testing

### Description
Feature-rich JavaScript test framework running on Node.js and browsers. Supports asynchronous testing, flexible reporting, and works with any assertion library. Highly extensible with plugins and custom reporters.

### Free Tier
- Completely free open-source under MIT license
- Runs locally or in CI
- Works with Chai, Should.js, and any assertion library.
