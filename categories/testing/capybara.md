## Capybara

**Website**: https://teamcapybara.github.io/capybara/
**Docs**: https://rubydoc.info/github/teamcapybara/capybara
**GitHub**: https://github.com/teamcapybara/capybara
**Category**: testing
**Subcategory**: browser-testing

### Description
Ruby acceptance test framework for web applications. Simulates real user interactions with a clean DSL. Supports Selenium, RackTest, and Cuprite drivers. Commonly used with RSpec and Rails system tests.

### Free Tier
- Completely free open-source under MIT license
- Integrates with Selenium for real browser testing or RackTest for headless.
