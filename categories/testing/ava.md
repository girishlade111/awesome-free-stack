**Website**: https://avajs.dev

**Category**: testing
**Subcategory**: unit-testing

### Description
Minimal JavaScript test runner running each test in a separate Node.js process for isolation. Features built-in TypeScript support, parallel execution, snapshot testing, and power-assert integration.

### Free Tier
- Completely free open-source under MIT license
- Process isolation and parallel execution built in with no config.
