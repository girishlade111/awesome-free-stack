## Locust

**Website**: https://locust.io
**Docs**: https://docs.locust.io
**GitHub**: https://github.com/locustio/locust
**Category**: testing
**Subcategory**: load-testing

### Description
Python-based load testing tool with distributed architecture. Define user behavior in regular Python code with a web-based real-time UI. Swarm your system with millions of simultaneous users from multiple worker machines.

### Free Tier
- Completely free open-source under MIT license
- Distributed mode with unlimited users
- Web UI for real-time test monitoring.

### Paid Plan
- **Starting Price**: N/A
- Locust Cloud managed service available. Self-hosted version remains fully free and open source.
