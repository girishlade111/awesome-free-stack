## REST Assured

**Website**: https://rest-assured.io
**Docs**: https://github.com/rest-assured/rest-assured/wiki
**GitHub**: https://github.com/rest-assured/rest-assured
**Category**: testing
**Subcategory**: api-testing

### Description
Java DSL for testing REST APIs with BDD-like syntax. Supports JSON/XML validation, authentication, OAuth 2.0, and spec reusability. Integrates with JUnit, TestNG, and Spring. The de facto Java API testing library.
