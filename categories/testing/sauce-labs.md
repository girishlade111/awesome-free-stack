## Sauce Labs

**Website**: https://saucelabs.com
**Docs**: https://docs.saucelabs.com
**Category**: testing
**Subcategory**: browser-testing

### Description
Enterprise cloud testing platform with real browsers, devices, and emulators. Supports Selenium, Appium, Playwright, and Cypress automated testing. Features live testing, visual testing, and API testing.

### Free Tier
- Free trial with 2 parallel tests, 30 min/test timeout, and access to desktop browsers and mobile emulators.

### Paid Plan
- **Starting Price**: $19/month
- Plans start at $19/month for 2 parallel VMs and 120 min/month. Enterprise with custom pricing and SLAs.
