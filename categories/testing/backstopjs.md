## BackstopJS

**Website**: https://garris.github.io/BackstopJS/
**Docs**: https://github.com/garris/BackstopJS#backstopjs
**GitHub**: https://github.com/garris/BackstopJS
**Category**: testing
**Subcategory**: visual-regression

### Description
Open-source visual regression testing tool using Puppeteer and Chrome Headless. Captures DOM screenshots, compares with pixelmatch, and generates HTML reports. CLI-driven with CI/CD-friendly JSON configuration.

### Free Tier
- Completely free open-source under MIT license
- Unlimited tests with local or CI execution
- HTML reports with side-by-side diff view.
