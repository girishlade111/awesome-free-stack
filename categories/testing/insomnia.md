## Free Tier Details

- **API Requests**: Unlimited locally
- **Collections**: Unlimited
- **Environments**: Unlimited
- **Code Generation**: Included
- **Plugins**: Community plugin ecosystem
- **GraphQL**: Full support
- **Cloud Sync**: Not included (Plus feature)

## Pros

- Unlimited local API requests for free
- Excellent GraphQL support
- Plugin ecosystem for extensibility
- Clean, modern UI
- Offline-first architecture
- Code generation for many languages

## Cons

- Cloud sync and collaboration require Plus ($5/mo)
- Smaller collection sharing features than Postman
- No built-in mock server
- No test runner capabilities

## Key Features

- HTTP and GraphQL request building
- Environment variables and sub-environments
- Code snippets for 20+ languages
- Plugin system (themes, exporters, auth)
- Import from Postman, OpenAPI, cURL
- Git-based collection storage

## Alternatives

- Postman — team collaboration, mock servers, monitors
- Bruno — 100% free, offline-only, Git-based
- Hoppscotch — browser-based, no desktop install needed
