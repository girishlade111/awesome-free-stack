## Gatling

**Website**: https://gatling.io
**Docs**: https://gatling.io/docs/
**GitHub**: https://github.com/gatling/gatling
**Category**: testing
**Subcategory**: load-testing

### Description
High-performance load testing tool for HTTP, JMS, MQTT, and WebSocket. Scala/Java DSL for test scenarios with real-time HTML dashboards. Supports 100K+ concurrent users from a single machine with Akka actors.

### Free Tier
- Open-source OSS version is completely free with unlimited users Cli-based
- Gatling Enterprise free tier: 200 users/month.

### Paid Plan
- **Starting Price**: $499/month
- Gatling Enterprise from $499/month for 5K users. Enterprise with dedicated infrastructure and SLAs.
