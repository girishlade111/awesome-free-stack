## Selenium

**Website**: https://www.selenium.dev

### Description
Open-source browser automation framework supporting Chrome, Firefox, Safari, Edge, and IE. Provides WebDriver API for all major languages. Foundation for most browser testing tools and services.

### Free Tier
- Completely free under Apache 2.0 license
- Self-hosted Selenium Grid supports unlimited parallel browser instances.

- No paid version; fully free and open source. Cloud Selenium Grid services from various providers available separately.
