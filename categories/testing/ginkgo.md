## Ginkgo

**Website**: https://onsi.github.io/ginkgo/
**Docs**: https://onsi.github.io/ginkgo/
**GitHub**: https://github.com/onsi/ginkgo
**Category**: testing
**Subcategory**: unit-testing

### Description
BDD-style Go testing framework with expressive DSL. Features nested describe/it blocks, before/after hooks, async testing, and parallel execution. Pairs with Gomega matchers for readable test assertions.

### Free Tier
- Completely free open-source under MIT license
- De facto standard BDD testing framework for Go applications.
