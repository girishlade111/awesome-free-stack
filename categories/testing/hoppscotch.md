## Hoppscotch

**Website**: https://hoppscotch.io
**Docs**: https://docs.hoppscotch.io
**GitHub**: https://github.com/hoppscotch/hoppscotch
**Category**: testing
**Subcategory**: api-testing

### Description
Open-source API development platform running in the browser. Supports REST, GraphQL, WebSocket, SSE, Socket.io, and MQTT. Features collections, environments, pre-request scripts, and team collaboration. PWA with offline support.

### Free Tier
- Free web app with all features: unlimited collections, environments, history, and API methods
- Self-hosted version is also free.

### Paid Plan
- **Starting Price**: $9/month
- Hoppscotch Cloud Pro from $9/month for team features, unlimited API calls, and priority support.
