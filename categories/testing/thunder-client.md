## Thunder Client

**Website**: https://www.thunderclient.com
**Docs**: https://docs.thunderclient.com
**Category**: testing
**Subcategory**: api-testing

### Description
Lightweight REST API client for VS Code with a clean UI. Supports collections, environments, graphql, scripting, and code generation. Fully offline with no login required. Built-in testing assertions and CI support.

### Free Tier
- Free version for VS Code: unlimited requests, collections, environments, GraphQL, and basic scriptless assertions.

### Paid Plan
- **Starting Price**: $49/month
- Thunder Client Pro from $49/year for scripting, CI integration, and team features.
