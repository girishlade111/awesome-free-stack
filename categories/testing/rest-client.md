### Description
VS Code extension for sending HTTP requests directly from editor files. Supports cURL format, custom headers, environment variables, and response preview in multiple formats. Lightweight with no external dependencies.

### Free Tier
- Completely free open-source VS Code extension
- Send HTTP requests from .http files with response preview.
