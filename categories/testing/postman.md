## Free Tier Details

- **Users**: 3 team members
- **Collections**: 3 collections with 25 requests each
- **Mock Servers**: 1,000 calls per month
- **Monitors**: 100 monitor runs per month (regional)
- **History**: 30 day retention
- **Workspaces**: Unlimited public workspaces
- **API Documentation**: Unlimited public docs

## Pros

- Most popular API platform with largest community
- Excellent documentation and learning resources
- Built-in test scripts (Postman Sandbox)
- Mock servers and API monitoring on free tier
- Code generation in 20+ languages

## Cons

- Collections limited to 25 requests each on free tier
- Cloud-only — no offline mode
- Desktop app can be resource-heavy

## Key Features

- HTTP, GraphQL, gRPC, and WebSocket support
- Environment variables and pre-request scripts
- Automated API tests with assertions
- Collection runner and Newman CLI
- API documentation generation
- Team workspaces and version control

## Alternatives

- Bruno — 100% free, offline-first, Git-based
- Insomnia — open-source, GraphQL-focused
- Hoppscotch — browser-based, lightweight
