## HTTPie

**Website**: https://httpie.io
**Docs**: https://httpie.io/docs
**GitHub**: https://github.com/httpie/cli
**Category**: testing
**Subcategory**: api-testing

### Description
User-friendly CLI HTTP client with intuitive syntax and colored output. Supports JSON, forms, file uploads, authentication, and custom headers. Python-based with HTTPS, proxies, and persistent sessions.

### Free Tier
- CLI client is completely free open-source under BSD license
- Desktop app free with basic features.

### Paid Plan
- **Starting Price**: $10/month
- HTTPie Desktop Pro from $9.99/month for team collaboration, environments, and advanced features.
