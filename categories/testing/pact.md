## Pact

**Website**: https://pact.io
**Docs**: https://docs.pact.io
**GitHub**: https://github.com/pact-foundation/pact-js
**Category**: testing
**Subcategory**: api-testing

### Description
Consumer-driven contract testing framework for HTTP and message integrations. Ensures API compatibility between services without end-to-end tests. Supports JavaScript, Java, Python, Go, Ruby, .NET, and more.

### Free Tier
- Completely free open-source library under MIT license
- Self-hosted Pact Broker or use PactFlow free tier: 1 user, 5 contracts.

### Paid Plan
- **Starting Price**: $187/month
- PactFlow from $187/month for team features. Enterprise with SSO, RBAC, and dedicated support.
