## Free Tier Details

- **Tests**: Unlimited
- **Browsers**: Chromium, Firefox, WebKit
- **Locators**: Auto-waiting, role-based, accessible
- **Codegen**: Built-in test recorder
- **Trace Viewer**: Full network and DOM recording
- **CI**: First-class GitHub Actions support
- **Component Testing**: Experimental

## Pros

- 100% free — no paid plans
- Auto-waiting eliminates flaky selectors
- Cross-browser by default (all three engines)
- Network interception and mocking built-in
- TypeScript-first API
- Fast execution and parallel testing

## Cons

- No built-in dashboard (use CI artifacts)
- No cloud service for non-Microsoft ecosystems yet
- Steeper learning curve than Cypress for beginners
- Component testing still experimental

## Key Features

- Single API for Chromium, Firefox, WebKit
- Auto-wait for elements
- Network route interception
- Browser contexts for isolated sessions
- Codegen test recorder
- Trace Viewer for debugging
- Mobile device emulation
- CI-ready Docker images

## Alternatives

- Cypress — easier DX, time-travel debugging, cloud dashboard
- Puppeteer — Chrome-only, lighter weight
- Selenium — legacy, broader ecosystem
