## Looks Same

**Website**: https://github.com/gemini-testing/looks-same
**Docs**: https://github.com/gemini-testing/looks-same#looks-same
**GitHub**: https://github.com/gemini-testing/looks-same
**Category**: testing
**Subcategory**: visual-regression

### Description
Node.js library for comparing images with smart anti-aliasing detection. Creates diff images with highlighted color mismatches. Used in Gemini and Hermione visual testing tools by Yandex. Supports ignore regions.
