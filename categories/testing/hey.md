## Hey

**Website**: https://github.com/rakyll/hey
**Docs**: https://github.com/rakyll/hey#usage
**GitHub**: https://github.com/rakyll/hey
**Category**: testing
**Subcategory**: load-testing

### Description
Go-based HTTP load generator similar to ApacheBench. Sends configurable numbers of requests with concurrency levels. Provides latency distribution, request statistics, and binary output. Single binary deployment.

### Free Tier
- Completely free open-source under Apache 2.0
- Single binary with no dependencies
- Supports custom headers and HTTP/2.
