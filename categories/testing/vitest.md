## Vitest

**Website**: https://vitest.dev
**Docs**: https://vitest.dev/guide/
**GitHub**: https://github.com/vitest-dev/vitest
**Category**: testing

### Description
Blazing-fast unit testing framework powered by Vite. Jest-compatible API with native TypeScript and ESM support. Features HMR-powered test updates, built-in coverage, and workspace monorepo support.

### Free Tier
- Completely free open-source under MIT license
- No usage limits
- Integrates seamlessly with Vite projects and runs in watch mode with HMR.
