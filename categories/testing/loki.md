## Loki

**Website**: https://loki.js.org
**Docs**: https://loki.js.org/getting-started.html
**GitHub**: https://github.com/oblador/loki
**Category**: testing
**Subcategory**: visual-regression

### Description
Open-source visual regression testing for Storybook components. Uses Dockerized Chrome/Firefox for consistent rendering. Supports CI integration with Docker, configurable thresholds, and parallel test execution.

### Free Tier
- Completely free open-source under MIT license
- Docker-based for consistent browser rendering across environments.
