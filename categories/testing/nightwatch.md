## Nightwatch.js

**Website**: https://nightwatchjs.org
**Docs**: https://nightwatchjs.org/guide
**GitHub**: https://github.com/nightwatchjs/nightwatch
**Category**: testing
**Subcategory**: browser-testing

### Description
Integrated browser testing framework using Selenium WebDriver API. Features built-in test runner, assertion library, page objects, and cloud service integration. Supports parallel testing in CI environments.

- Completely free open-source under MIT license
