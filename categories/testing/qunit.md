## QUnit

**Website**: https://qunitjs.com
**Docs**: https://qunitjs.com/intro/
**GitHub**: https://github.com/qunitjs/qunit
**Category**: testing
**Subcategory**: unit-testing

### Description
JavaScript unit testing framework originally for jQuery. Works in browsers and Node.js with async testing, callback support, and module-scoped fixtures. The jQuery project's official test suite runner.

### Free Tier
- Completely free open-source under MIT license
- Browser-native testing with CLI support via qunit CLI package.
