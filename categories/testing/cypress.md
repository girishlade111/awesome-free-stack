## Free Tier Details

- **Test Runner**: Unlimited open-source
- **Cloud Results**: 500 test results per month
- **Retention**: 30 days
- **Users**: 1 user
- **Parallelization**: Not included in free tier
- **Artifacts**: Screenshots and videos stored

## Pros

- Best developer experience for E2E testing
- Time-travel debugging — inspect at each step
- Real-time reloads and auto-rerun
- Great documentation and learning resources
- Large community and ecosystem

## Cons

- Only supports Chromium-based browsers in open-source
- Cloud features needed for parallelization
- Limited to 500 test results/month on free cloud tier
- Slower than Playwright for large test suites
- No Firefox or WebKit support without paid plan

## Key Features

- Real-time reloads with every save
- Time-travel debugging
- Automatic waiting (no sleeps)
- Network stubbing and mocking
- Screenshots and videos on failure
- Component testing
- Cypress Studio — record tests visually

## Alternatives

- Playwright — faster, cross-browser, also free
- Puppeteer — Chrome-only, programmatic
- Selenium — legacy, multi-language
