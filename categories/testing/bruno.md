## Free Tier Details

- **Collections**: Unlimited
- **Requests**: Unlimited
- **Sync**: Git-based (no cloud dependency)
- **Users**: Unlimited (Git-based collaboration)
- **Storage**: Locally stored as plain text files
- **Offline**: Fully offline-capable

## Pros

- 100% free — no paid plans at all
- Git-friendly — collections are plain text files
- Offline-first — no account or internet required
- Privacy-focused — no data leaves your machine
- Open-source (MIT license)

## Cons

- No cloud sync (both a pro and con)
- No native built-in mock server
- Smaller community than Postman
- No team management UI

## Key Features

- HTTP request builder with full response viewer
- Collections stored as plain text files
- Git diff and PR-based collaboration
- Environment variables and scripting
- Code generation
- Proxy support

## Alternatives

- Postman — cloud-first, team features, larger ecosystem
- Insomnia — open-source, optional cloud sync
- Hoppscotch — browser-based, no install
