# Testing Tools

Curated collection of free testing frameworks, API clients, and QA infrastructure tools.

## Quick Comparison

| Tool | Type | Free Limit | Open Source | Local Only | Card? |
|---|---|---|---|---|---|
| **Postman** | API Client | 3 users, 3 collections, 1K mock calls/mo | ✗ | ✗ | No |
| **Bruno** | API Client | Unlimited (fully free) | ✅ | ✅ | No |
| **Insomnia** | API Client | Unlimited locally, optional cloud sync | ✅ | ✗ | No |
| **Playwright** | E2E Testing | Unlimited (fully free) | ✅ | ✅ | No |
| **Cypress** | E2E Testing | Unlimited runner, 500 cloud results/mo | ✅ | ✗ | No |

## Selection Guide

- **Best API client overall**: Postman — most features, best team collaboration, largest community
- **Best offline API client**: Bruno — Git-friendly, no account required, files stored as text
- **Best E2E testing**: Playwright — faster, more cross-browser, modern API, free forever
- **Best E2E for beginners**: Cypress — exceptional DX, time-travel debugging, real-time reloads
- **Best lightweight API client**: Insomnia — GraphQL support, plugin ecosystem, cheap paid tier

> **Note**: Playwright and Bruno are 100% free and open-source with no paid plans. Postman and Cypress have cloud features that require paid plans for team use. Insomnia's local features are fully free with optional cloud sync via subscription.
