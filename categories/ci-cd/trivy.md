Comprehensive security scanner for containers, filesystems, Git repos, and cloud infrastructure. Scans for vulnerabilities, misconfigurations, secrets, and license issues.

Completely free and open-source. CLI and Docker image. Scans containers, filesystems, repos, and configs.
