### Description
Comprehensive test automation platform supporting web, mobile, API, and desktop testing. Built-in CI/CD integrations with Jenkins, CircleCI, GitHub Actions, and more.

### Free Tier
Free tier: 5 users, 1,000 test runs/month, unlimited test cases, all platform support. Katalon Runtime Engine free for open-source projects.

### Paid Plan
Premium — from /month: 10 users, 5K test runs, parallel execution
