### Description
Automated code review platform that detects bugs, anti-patterns, and security vulnerabilities. Supports Python, Go, JavaScript, TypeScript, Ruby, and Java. Free for open-source.

### Free Tier
Free for open-source: unlimited repos, unlimited users, all analyzers. Private repos: 14-day free trial.

### Paid Plan
Pro — from /month: private repos, priority support, advanced configurations
