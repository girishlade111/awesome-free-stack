## Serverless Framework

**Website**: https://www.serverless.com
**Docs**: https://www.serverless.com/framework/docs
**GitHub**: https://github.com/serverless/serverless
**Category**: ci-cd
**Subcategory**: deployment-automation

### Description
Serverless application framework for AWS Lambda, Azure Functions, Google Cloud Functions, and more. Define serverless infrastructure in YAML, deploy with CLI. Open-source with Serverless Dashboard for monitoring.

### Free Tier
Completely free and open-source CLI. Serverless Dashboard: free for 3 users, 10K invocations/month, 1K function logs.

### Paid Plan
Pro — from /month: 3 users, 100K invocations, secrets, monitoring
