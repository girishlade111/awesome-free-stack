**Website**: https://aws.amazon.com/cdk

### Description
AWS Cloud Development Kit. Define cloud infrastructure using familiar programming languages (TypeScript, Python, Java, C#, Go). Construct library and automatic CloudFormation generation.

### Free Tier
Completely free and open-source CLI. AWS CDK is free; standard AWS charges apply for deployed resources.

### Paid Plan
No separate pricing; standard AWS charges apply for deployed infrastructure
