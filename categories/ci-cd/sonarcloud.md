## SonarCloud

**Website**: https://sonarcloud.io
**Docs**: https://docs.sonarsource.com/sonarcloud

**Category**: ci-cd
**Subcategory**: code-quality

### Description
Cloud-based code quality and security platform by SonarSource. Analyzes code from GitHub, GitLab, Bitbucket, and Azure DevOps. Free for public repositories.

### Free Tier
Free for public repositories: unlimited analysis, all languages, PR decoration, Quality Gates. Private repos: 100K lines of code.

### Paid Plan
From /month: unlimited private repo lines, enterprise features
