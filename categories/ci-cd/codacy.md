### Description
Automated code review platform that integrates with GitHub, GitLab, and Bitbucket. Detects security issues, code coverage changes, and code style violations.

### Free Tier
Free for open-source: unlimited repos, all features. Private repos: 4 users, unlimited repos. Security patterns included.

### Paid Plan
Pro — from /user/month: 15 users, advanced patterns, priority support
