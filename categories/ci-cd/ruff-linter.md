### Description
Extremely fast Python linter and formatter, written in Rust. Compatible with Flake8, isort, and pycodestyle rules. Up to 100x faster than existing Python linters. CI-native with zero-config setup.

### Free Tier
Completely free and open-source. Single binary, no Python runtime needed for execution. Works with any CI/CD system.
