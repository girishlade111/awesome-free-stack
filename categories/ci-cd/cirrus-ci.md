## Cirrus CI

**Website**: https://cirrus-ci.org
**Docs**: https://cirrus-ci.org/guide/quick-start
**GitHub**: https://github.com/cirruslabs/cirrus-cli
**Category**: ci-cd
**Subcategory**: pipelines

### Description
Modern cloud CI/CD with native support for Linux, macOS, Windows, and ARM containers. YAML configuration with task-level caching, parallel execution, and built-in Docker/Podman support.

### Free Tier
Free for public repositories: 4,000 compute minutes/month. Linux containers free. macOS and Windows credits: 50/min free per month with per-task limits.

### Paid Plan
From $15/month for additional compute credits, macOS/Windows, and private repository support
