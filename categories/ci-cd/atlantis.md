## Atlantis

**Website**: https://www.runatlantis.io
**Docs**: https://www.runatlantis.io/docs
**GitHub**: https://github.com/runatlantis/atlantis
**Category**: ci-cd
**Subcategory**: deployment-automation

### Description
Terraform pull request automation. Automatically runs terraform plan and apply when PRs are opened. Comments results back on the PR.

### Free Tier
Completely free and open-source. Self-hosted via Docker or binary. Supports GitHub, GitLab, Bitbucket, and Azure DevOps.
