## CircleCI

**Website**: https://circleci.com
**Docs**: https://circleci.com/docs
**GitHub**: https://github.com/CircleCI-Public
**Category**: ci-cd

### Description
Cloud-native CI/CD platform with blazing fast builds via caching and parallelism. Optimized for Docker, monorepos, and polyglot projects. Powerful YAML configuration with orbs for reusable pipeline components.

### Free Tier
- **Credits**: 6,000/month (Linux)
- **Windows/macOS**: 1,000 credits/month
- **Parallelism**: 30 jobs
- **Users**: 1
- **Features**: Docker layer caching, orbs, SSH debug

### Paid Plan
- **Performance**: $30/month
- **Features**: 25K credits, 10 users, priority support, advanced features
