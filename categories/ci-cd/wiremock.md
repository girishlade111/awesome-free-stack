## WireMock

**Website**: https://wiremock.org
**Docs**: https://wiremock.org/docs
**GitHub**: https://github.com/wiremock/wiremock
**Category**: ci-cd

### Description
HTTP mock server for API testing and service virtualization. Stub HTTP responses, verify requests, simulate faults and delays. Standalone server or library for Java, .NET, and Go.

### Free Tier
Completely free and open-source. Standalone JAR or Docker image. Unlimited stubs and scenarios.

### Paid Plan
WireMock Cloud — from /month for 5K requests, 2 team members
