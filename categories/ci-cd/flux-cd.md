## Flux

**Website**: https://fluxcd.io
**Docs**: https://fluxcd.io/flux
**GitHub**: https://github.com/fluxcd/flux2
**Category**: ci-cd
**Subcategory**: deployment-automation

### Description
Continuous delivery for Kubernetes with GitOps Toolkit. Automates deployments based on Git repository changes. Supports kustomize, Helm, health checks, and notification integration. CNCF graduated project.

### Free Tier
Completely free and open-source. Self-hosted in Kubernetes. Part of CNCF graduated projects.
