# Free CI/CD Platforms

Curated collection of continuous integration and delivery platforms.

## Quick Comparison

| Platform | Type | Free Tier | Self-Host? | Card? |
|---|---|---|---|---|
| **GitHub Actions** | Cloud CI/CD | 2,000 min/mo, unlimited public | No | No |
| **Jenkins** | Self-hosted | Unlimited (on your server) | Yes | No |
| **CircleCI** | Cloud CI/CD | 6K credits/mo, 30 parallel | No | No |
| **GitLab CI/CD** | Cloud + Self-host | 400 min/mo (SaaS), unlimited (self) | Yes | No |
| **Buildkite** | Hybrid CI/CD | 5 agents, unlimited builds | Yes (agents) | No |

## Selection Guide

- **Best for GitHub projects**: GitHub Actions — native integration, massive marketplace
- **Best self-hosted**: Jenkins — most mature, 1,800+ plugins
- **Fastest cloud builds**: CircleCI — caching, parallelism, Docker optimization
- **Best all-in-one**: GitLab CI/CD — source control + CI/CD + registry in one
- **Best hybrid**: Buildkite — your infrastructure, their UI
- **Best for students**: GitHub Actions (free 2K min) or GitLab (free Ultimate via edu email)
