### Description
Automated code review platform with static analysis and test coverage reporting. Integrated with GitHub PR workflows. Maintainability badges and trend tracking.

### Free Tier
Free for open-source: unlimited repos, all analysis engines, PR review. Private repos: Team plan required (14-day free trial).
