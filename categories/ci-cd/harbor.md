## Harbor

**Website**: https://goharbor.io
**Docs**: https://goharbor.io/docs
**GitHub**: https://github.com/goharbor/harbor
**Category**: ci-cd
**Subcategory**: artifact-hosting

### Description
Open-source cloud-native container registry with built-in security scanning. Role-based access control, image replication across registries, vulnerability scanning via Trivy. CNCF graduated project.

### Free Tier
Completely free and open-source. Self-hosted. Unlimited images, users, and projects. Includes vulnerability scanning, replication, and RBAC.
