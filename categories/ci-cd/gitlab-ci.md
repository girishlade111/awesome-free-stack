### Description
Built-in CI/CD integrated into GitLab with auto DevOps, container registry, and artifact management. Single application for source control, CI, CD, container registry, and monitoring. Self-host or GitLab SaaS.

### Free Tier
- **Compute**: 400 minutes/month (SaaS)
- **Self-hosted**: Unlimited (unlimited builds, minutes)
- **Storage**: 5GB + 1GB registry
- **Users**: 1
- **Features**: Auto DevOps, templates, container registry

### Paid Plan
- **Premium**: $19/month
- **Features**: 10K compute minutes, 50GB storage, 50GB registry, multiple users
