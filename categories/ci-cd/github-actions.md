## GitHub Actions

**Website**: https://github.com/features/actions
**Docs**: https://docs.github.com/actions
**GitHub**: https://github.com/features/actions
**Category**: ci-cd
**Subcategory**: pipelines

### Description
GitHub's integrated CI/CD platform for automating builds, tests, and deployments. Massive 20,000+ action marketplace, matrix builds across OS, and deep repository integration. Free for public and private repositories.

### Free Tier
- **Minutes**: 2,000/month (Linux), unlimited for public repos
- **Storage**: 500MB
- **Concurrent**: 20 jobs
- **Runners**: Ubuntu, macOS, Windows
- **Features**: Matrix builds, secrets, environments, deployment protection rules

### Paid Plan
- **Team**: $4/month
- **Features**: 3,000 minutes, required reviewers, code owners, draft PRs
