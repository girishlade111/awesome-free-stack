## Drone CI

**Website**: https://www.drone.io
**Docs**: https://docs.drone.io
**GitHub**: https://github.com/harness/drone
**Category**: ci-cd
**Subcategory**: pipelines

### Description
Lightweight cloud-native CI/CD platform built on container technology. Every pipeline step runs in an isolated Docker container. Single-binary architecture, multi-platform support, and deep VCS integration.

### Free Tier
Open-source: self-hosted, unlimited builds, unlimited repos, unlimited users. Drone Cloud: free for open-source projects.

### Paid Plan
Drone Cloud — from $25/month for private repos. Harness CI — from $0/month for 2 users, 100K CI minutes.
