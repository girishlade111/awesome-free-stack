## Azure Pipelines

**Website**: https://azure.microsoft.com/en-us/products/devops/pipelines
**Docs**: https://learn.microsoft.com/en-us/azure/devops/pipelines

**Category**: ci-cd
**Subcategory**: pipelines

### Description
Microsoft's cloud CI/CD service with unlimited free minutes for public projects. Supports any language, platform, and cloud. Deep Azure integration, YAML or classic editor pipelines, parallel jobs, and deployment gates.

### Free Tier
1,800 minutes/month (30 hours) free. 1 parallel job. Unlimited minutes for public projects. 10 free Azure DevOps users. 2 GiB Git storage.

### Paid Plan
Microsoft-hosted — from $40/month for 1 additional parallel job. Self-hosted: unlimited free agents.
