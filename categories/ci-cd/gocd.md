### Description
Open-source CI/CD server by ThoughtWorks with advanced pipeline modeling. Value stream mapping, fan-in/fan-out dependency management, and template-based configuration. Designed for complex deployment pipelines with approval gates and traceability.

### Free Tier
Completely free and open-source. Self-hosted. Unlimited builds, unlimited pipelines, unlimited agents. All features included.
