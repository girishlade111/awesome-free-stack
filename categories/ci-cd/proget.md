## ProGet

**Website**: https://inedo.com/proget
**Docs**: https://docs.inedo.com/docs/proget/overview

**Category**: ci-cd
**Subcategory**: artifact-hosting

### Description
Universal package manager by Inedo. Host and proxy NuGet, npm, Docker, Maven, RubyGems, PyPI, and Chocolatey packages. Built-in vulnerability scanning and license compliance.

### Free Tier
ProGet Free: 1 feed, unlimited packages/users, 1 connector. Self-hosted on Windows/Linux.

### Paid Plan
Pro — from ,995/year: unlimited feeds, 20+ connectors, vulnerability scanning
