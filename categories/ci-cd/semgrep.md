## Semgrep

**Website**: https://semgrep.dev
**Docs**: https://semgrep.dev/docs
**GitHub**: https://github.com/semgrep/semgrep
**Category**: ci-cd
**Subcategory**: code-quality

### Description
Lightweight static analysis tool for finding bugs, vulnerabilities, and anti-patterns. Rules look like source code, making them easy to write. Supports 30+ languages.

### Free Tier
Semgrep OSS: free CLI, unlimited rules, all languages. Semgrep Cloud Platform: free for up to 25 contributors, unlimited repos.

### Paid Plan
Semgrep Pro — from /month: 100+ contributors, advanced inter-file analysis
