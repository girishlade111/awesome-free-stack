## GitHub Container Registry

**Website**: https://ghcr.io
**Docs**: https://docs.github.com/en/packages/working-with-a-github-packages-registry/working-with-the-container-registry

**Category**: ci-cd
**Subcategory**: artifact-hosting

### Description
Docker container registry integrated into GitHub Packages. Store and publish OCI-compatible container images alongside your source code. Free for public images.

### Free Tier
Free for public images. Private images: 500 MB free storage, 1 GB free data transfer/month for private repos.

### Paid Plan
Part of GitHub paid plans or billed per usage: .25/GB storage, .50/GB transfer
