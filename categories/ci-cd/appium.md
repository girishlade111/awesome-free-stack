## Appium

**Website**: https://appium.io
**Docs**: http://appium.io/docs/en/latest
**GitHub**: https://github.com/appium/appium
**Category**: ci-cd
**Subcategory**: testing-automation

### Description
Cross-platform mobile test automation framework. Automate native, hybrid, and mobile web apps on iOS and Android. WebDriver-compatible protocol, runs on simulators, real devices, or cloud services.

### Free Tier
Completely free and open-source. Self-hosted. Requires device/simulator setup. Unlimited tests.

### Paid Plan
Appium Pro (advisory) — commercial support; cloud device providers like Sauce Labs, BrowserStack provide Appium-compatible device clouds
