## AppVeyor

**Website**: https://www.appveyor.com
**Docs**: https://www.appveyor.com/docs

**Category**: ci-cd
**Subcategory**: pipelines

### Description
CI/CD platform with first-class Windows build support alongside Linux and macOS. Ideal for .NET, C++, and cross-platform projects. YAML configuration, NuGet packaging, and deployment to cloud platforms.

### Free Tier
Free for open-source projects: unlimited builds, 1 concurrent job, 60-minute build timeout. Free tier for private repos: 1 project, 14-day build history.

### Paid Plan
Pro — from $39/month: 2 concurrent jobs, unlimited private projects, enhanced support
