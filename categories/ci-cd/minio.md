## MinIO

**Website**: https://min.io
**Docs**: https://min.io/docs/minio/container/index.html
**GitHub**: https://github.com/minio/minio
**Category**: ci-cd
**Subcategory**: artifact-hosting

### Description
High-performance, S3-compatible object storage server. Perfect for artifact storage in CI/CD pipelines. Supports multi-cloud replication, erasure coding, and bucket versioning.

### Free Tier
Completely free and open-source. Self-hosted. Unlimited storage (hardware-dependent). S3-compatible API.

### Paid Plan
MinIO Enterprise — from /instance/month: SUBNET support, security advisory, performance
