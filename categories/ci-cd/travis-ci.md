## Travis CI

**Website**: https://travis-ci.com
**Docs**: https://docs.travis-ci.com

**Category**: ci-cd
**Subcategory**: pipelines

### Description
Pioneering cloud CI/CD platform with native GitHub and Bitbucket integration. YAML-based pipeline configuration, matrix builds across multiple languages and runtimes, parallel testing, and automatic PR deployments. Free for public repositories.

### Free Tier
Free for public repositories. Unlimited builds, unlimited concurrency for open-source. 10,000 build credits/month for private repos.

### Paid Plan
Travis CI — from $69/month for 20K credits, concurrent builds, private repos
