## JFrog Artifactory

**Website**: https://jfrog.com/artifactory
**Docs**: https://jfrog.com/help/r/jfrog-artifactory-documentation

**Category**: ci-cd
**Subcategory**: artifact-hosting

### Description
Universal artifact repository manager with enterprise-grade features. Supports all major package formats, Docker registries, Helm charts, and generic repositories.

### Free Tier
Artifactory OSS: free self-hosted (Maven, Ivy, Gradle, Docker, generic). JFrog Cloud Free Tier: 2 GB storage, 2 users, 100 CI integrations.

### Paid Plan
Pro — from /year: unlimited storage, 5 users, HA, Xray integration
