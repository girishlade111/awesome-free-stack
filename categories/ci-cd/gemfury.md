## Gemfury

**Website**: https://gemfury.com
**Docs**: https://gemfury.com/help

**Category**: ci-cd
**Subcategory**: artifact-hosting

### Description
Hosted package registry for RubyGems, npm, PyPI, Maven, NuGet, PHP Composer, and Debian packages. Private package hosting with webhook CI integration.

### Free Tier
1 private repository, unlimited public. 100 MB storage. 1 collaborator. 2,500 package downloads/month.

### Paid Plan
Pro — from /month: 1GB storage, unlimited collaborators, 5 repos
