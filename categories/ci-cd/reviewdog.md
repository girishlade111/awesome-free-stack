### Description
Automated code review tool that integrates with any linter. Posts review comments to GitHub, GitLab, and Bitbucket PRs. Supports diff-based reporting to only show new issues.

### Free Tier
Completely free and open-source. Works with any linter tool (ESLint, RuboCop, golangci-lint, etc.). Integrates with GitHub, GitLab, Bitbucket.
