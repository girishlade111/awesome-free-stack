## JitPack

**Website**: https://jitpack.io
**Docs**: https://jitpack.io/docs

**Category**: ci-cd
**Subcategory**: artifact-hosting

### Description
On-demand package repository for JVM and Android libraries. Builds artifacts directly from GitHub repositories on the fly. Supports Maven, Gradle, sbt, and Leiningen.

### Free Tier
Free for public GitHub repositories. Unlimited builds and storage. No account required for consuming public artifacts.

### Paid Plan
JitPack Enterprise — from /month: private repos, priority support, custom domain
