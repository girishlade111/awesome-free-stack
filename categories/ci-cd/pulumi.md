### Description
Modern Infrastructure as Code using familiar programming languages (TypeScript, Python, Go, C#, Java, YAML). Define cloud infrastructure with real code, test it, and deploy it. Open-source with managed service.

### Free Tier
Free and open-source CLI. Pulumi Cloud: free for individual use, unlimited stacks, 1 concurrent operation, state and secrets management.

### Paid Plan
Team — from /user/year: 10 concurrent operations, RBAC, SAML/SSO
