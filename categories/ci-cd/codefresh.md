**Category**: ci-cd

### Description
GitOps-powered CI/CD platform designed for Kubernetes and cloud-native applications. Visual pipeline editor, automatic Docker image caching, hybrid runtime, and Argo CD integration.

### Free Tier
3 users, 500 build minutes/month, 1 pipeline, 1 GitOps environment. Includes all pipeline features.

### Paid Plan
Pro — from $34/month: 5 users, 2,500 build minutes, unlimited pipelines
