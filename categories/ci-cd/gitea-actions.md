## Gitea Actions

**Website**: https://docs.gitea.com/next/usage/actions/overview
**Docs**: https://docs.gitea.com/next/usage/actions/overview
**GitHub**: https://github.com/go-gitea/gitea
**Category**: ci-cd
**Subcategory**: pipelines

### Description
CI/CD natively integrated into Gitea, compatible with GitHub Actions workflow syntax. Self-hosted, lightweight, and supports the same YAML format as GitHub Actions. Runs in Docker containers with matrix builds.

### Free Tier
Completely free as part of Gitea. Self-hosted. Unlimited builds, unlimited runners, compatible with all Actions workflow files.
