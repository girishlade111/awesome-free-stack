## AWS SAM

**Website**: https://aws.amazon.com/serverless/sam
**Docs**: https://docs.aws.amazon.com/serverless-application-model/latest/developerguide
**GitHub**: https://github.com/aws/aws-sam-cli
**Category**: ci-cd
**Subcategory**: deployment-automation

### Description
AWS Serverless Application Model. Framework for building serverless applications on AWS. Define functions, APIs, and databases in simplified YAML. Local testing, debugging, and one-command deployment.

### Free Tier
Completely free and open-source CLI. AWS SAM Accelerate for faster dev/deploy cycles. Standard AWS charges for deployed resources.

### Paid Plan
No separate pricing; standard AWS resource charges apply for deployed infrastructure
