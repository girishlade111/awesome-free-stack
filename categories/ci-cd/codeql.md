**Website**: https://codeql.github.com

### Description
GitHub's semantic code analysis engine for security vulnerabilities. Query-based analysis treats code as data. Free for public repositories on GitHub.com.

### Free Tier
Free for public repositories on GitHub.com: unlimited scans, all query packs. GitHub Advanced Security for private repos.

### Paid Plan
Part of GitHub Advanced Security (GitHub Enterprise) — from /user/month
