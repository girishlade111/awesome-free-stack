## Terragrunt

**Website**: https://terragrunt.gruntwork.io
**Docs**: https://terragrunt.gruntwork.io/docs
**GitHub**: https://github.com/gruntwork-io/terragrunt
**Category**: ci-cd
**Subcategory**: deployment-automation

### Description
Thin wrapper around Terraform that provides DRY configurations, remote state management, and module orchestration. Keeps Terraform configurations clean and maintainable across multiple environments.

### Free Tier
Completely free and open-source. CLI tool that extends Terraform. No usage limits.
