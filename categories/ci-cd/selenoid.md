## Selenoid

**Website**: https://aerokube.com/selenoid
**Docs**: https://aerokube.com/selenoid/latest
**GitHub**: https://github.com/aerokube/selenoid
**Category**: ci-cd
**Subcategory**: testing-automation

### Description
Lightweight Selenium Grid implementation using Docker containers. Launches browsers on demand, supports video recording, and provides a live browser UI.

### Free Tier
Completely free and open-source. Self-hosted with Docker. Unlimited browser sessions (limited by available resources).

### Paid Plan
Aerokube Moon (cloud version) — from .17/hour for managed browser clusters
