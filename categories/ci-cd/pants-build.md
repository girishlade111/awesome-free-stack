## Pants Build

**Website**: https://www.pantsbuild.org
**Docs**: https://www.pantsbuild.org/docs
**GitHub**: https://github.com/pantsbuild/pants
**Category**: ci-cd
**Subcategory**: build-automation

### Description
Fast, scalable build system for monorepos supporting Python, Java, Scala, Go, shell, and Docker. Fine-grained invalidation, remote caching, and parallel execution.

### Free Tier
Completely free and open-source. Self-hosted. Unlimited builds.
