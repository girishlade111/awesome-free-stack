## Concourse CI

**Website**: https://concourse-ci.org
**Docs**: https://concourse-ci.org/docs.html
**GitHub**: https://github.com/concourse/concourse
**Category**: ci-cd
**Subcategory**: pipelines

### Description
Container-centric CI/CD system with a novel pipeline-as-code approach using idempotent resources. Every step runs in a container, pipelines are version-controlled YAML, and the web UI visualizes the full dependency graph.

### Free Tier
Completely free and open-source. Self-hosted. Unlimited pipelines, unlimited workers. All features included.
