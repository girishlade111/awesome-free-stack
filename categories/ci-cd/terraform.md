## Terraform

**Website**: https://www.terraform.io
**Docs**: https://developer.hashicorp.com/terraform/docs
**GitHub**: https://github.com/hashicorp/terraform
**Category**: ci-cd
**Subcategory**: deployment-automation

### Description
Industry-standard Infrastructure as Code tool by HashiCorp. Declarative HCL configuration for provisioning cloud resources across AWS, Azure, GCP, and 1,800+ providers. State management, plan/apply workflow.

### Free Tier
Completely free and open-source CLI. Terraform Cloud: free for up to 5 users, 500 resources, unlimited runs.

### Paid Plan
Terraform Cloud Team — from /user/month: policy enforcement, private module registry
