## Sinon.js

**Website**: https://sinonjs.org
**Docs**: https://sinonjs.org/releases/latest
**GitHub**: https://github.com/sinonjs/sinon
**Category**: ci-cd
**Subcategory**: testing-automation

### Description
Standalone test doubles library for JavaScript/Node.js. Spies, stubs, mocks, fake timers, and fake XHR/server. Works with any test framework (Mocha, Jest, Vitest, Jasmine).

### Free Tier
Completely free and open-source. No usage limits. Works with all major JS test frameworks.
