## Snyk

**Website**: https://snyk.io
**Docs**: https://docs.snyk.io

**Category**: ci-cd
**Subcategory**: code-quality

### Description
Developer security platform for finding and fixing vulnerabilities in open-source dependencies, containers, and infrastructure as code. CI-native with GitHub, GitLab, and Bitbucket integration.

### Free Tier
Free tier: 200 open-source tests/month, unlimited Snyk Code tests (SAST), 1 container test/month. Unlimited projects for public repos.

### Paid Plan
Team — from /month: unlimited open-source tests, 100 container tests, 100 IaC tests
