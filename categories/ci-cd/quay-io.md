## Quay.io

**Website**: https://quay.io
**Docs**: https://docs.quay.io

**Category**: ci-cd
**Subcategory**: artifact-hosting

### Description
Red Hat's enterprise container registry with automated builds, vulnerability scanning, and geo-replication. Supports Docker images, OCI artifacts, and AppC images.

### Free Tier
Unlimited public repositories. 1 private repository. Unlimited public automated builds. Vulnerability scanning included.

### Paid Plan
Starter — /month: 5 private repos. Pro — /month: unlimited private repos
