## Nx

**Website**: https://nx.dev
**Docs**: https://nx.dev/getting-started/intro
**GitHub**: https://github.com/nrwl/nx
**Category**: ci-cd
**Subcategory**: build-automation

### Description
Smart monorepo build system with caching, task orchestration, and code generation. Supports Angular, React, Next.js, NestJS, Node.js, and more.

### Free Tier
Completely free and open-source. Nx Cloud: 500GB remote caching + 100 distributed task execution hours/month free.

### Paid Plan
Nx Cloud Enterprise from $50/month for unlimited caching and distributed execution
