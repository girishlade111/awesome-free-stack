## Mockito

**Website**: https://site.mockito.org
**Docs**: https://javadoc.io/doc/org.mockito/mockito-core/latest/org/mockito/Mockito.html

**Category**: ci-cd
**Subcategory**: testing-automation

### Description
Most popular Java mocking framework for unit tests. Create mock objects, stub methods, and verify interactions. Clean API with annotations, argument matchers, and BDD-style verification.

### Free Tier
Completely free and open-source. No usage limits. Works with JUnit 4/5, TestNG, and other test runners.
