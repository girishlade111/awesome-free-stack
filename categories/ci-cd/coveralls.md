## Coveralls

**Website**: https://coveralls.io
**Docs**: https://docs.coveralls.io

**Category**: ci-cd
**Subcategory**: code-quality

### Description
Hosted code coverage tracking service. Shows which parts of your code aren't covered by tests. Integrates with GitHub, GitLab, Bitbucket, and all major CI platforms.

### Free Tier
Free for public repositories: unlimited coverage reports, badges, and PR comments. 1 private repo for free.

### Paid Plan
Pro — from /month: unlimited private repos, multiple accounts, priority support
