### Description
Run GitHub Actions workflows locally. Execute CI pipelines on your machine before pushing, speeding up iteration. Full workflow YAML support, Docker-based job execution.

### Free Tier
Completely free and open-source. No usage limits. Requires Docker. Works on Linux, macOS, and Windows.
