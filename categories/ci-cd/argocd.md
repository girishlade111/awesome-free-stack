## ArgoCD

**Website**: https://argo-cd.readthedocs.io
**Docs**: https://argo-cd.readthedocs.io/en/stable
**GitHub**: https://github.com/argoproj/argo-cd
**Category**: ci-cd
**Subcategory**: deployment-automation

### Description
Declarative GitOps CD tool for Kubernetes. Automatically syncs cluster state with Git repository desired state. Web UI, CLI, and API with SSO, RBAC, and multi-cluster management. CNCF graduated project.

### Free Tier
Completely free and open-source. Self-hosted in Kubernetes. Unlimited applications, clusters, and users.
