## Crossplane

**Website**: https://www.crossplane.io
**Docs**: https://docs.crossplane.io
**GitHub**: https://github.com/crossplane/crossplane
**Category**: ci-cd
**Subcategory**: deployment-automation

### Description
Open-source control plane framework for building cloud-native platforms. Extends Kubernetes to manage infrastructure across providers. Composition engine for creating custom APIs. CNCF incubating project.

### Free Tier
Completely free and open-source. Self-hosted in Kubernetes. Extends Kubernetes API for infrastructure management.

### Paid Plan
Upbound Cloud — from /month: managed Crossplane control planes, 1 control plane, 10 resources
