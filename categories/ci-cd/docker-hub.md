## Docker Hub

**Website**: https://hub.docker.com
**Docs**: https://docs.docker.com/docker-hub

**Category**: ci-cd
**Subcategory**: artifact-hosting

### Description
World's largest container image registry and community. Host and share Docker images with automated builds from GitHub/Bitbucket. Official images for popular software.

### Free Tier
1 private repository. Unlimited public repositories. 200 pulls/6 hours (unauthenticated), 100 pulls/6 hours (authenticated free).

### Paid Plan
Pro — from /month: unlimited private repos, 300 pulls/6 hours, 5 concurrent builds
