## Semaphore CI

**Website**: https://semaphoreci.com
**Docs**: https://docs.semaphoreci.com

**Category**: ci-cd
**Subcategory**: pipelines

### Description
Fast cloud CI/CD platform with 20-second startup times and parallel test execution. YAML-based workflow configuration, native Docker support, Linux and macOS runners, and automatic caching.

### Free Tier
1,200 build minutes/month (20 hours). 1 GB cache storage. 1 parallel job. Unlimited projects for public repos.

### Paid Plan
Team — from $14/month: 4,000 minutes, 2 parallel jobs, 5 GB cache
