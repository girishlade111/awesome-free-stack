## TestCafe

**Website**: https://testcafe.io
**Docs**: https://testcafe.io/documentation
**GitHub**: https://github.com/DevExpress/testcafe
**Category**: ci-cd
**Subcategory**: testing-automation

### Description
Node.js end-to-end testing framework that works without WebDriver. Runs on any browser without plugins. Built-in waiting mechanism, parallel test execution, and screenshot/video recording.

### Free Tier
Completely free and open-source. Unlimited tests, unlimited browsers. TestCafe Studio has a free 30-day trial.

### Paid Plan
TestCafe Studio — from /month per user for GUI-based test recorder
