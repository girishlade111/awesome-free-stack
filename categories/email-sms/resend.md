### Description
Modern email API for developers with React Email support, SDKs for every framework, and high deliverability. Built for the modern web — send transactional emails with a simple API, beautiful templates, and real-time analytics.

- **Emails**: 3,000/month
- **Daily limit**: 100/day
- **Domains**: 1
- **Audiences**: 1
- **Analytics**: 1 day retention

### Paid Plan
- **Pro**: $20/month
- **Features**: 50K emails, 50K contacts, 30 day retention, multiple domains, team members
