# Free Email & SMS Services

Curated collection of free email delivery, SMS messaging, and notification platforms.

## Quick Comparison

| Provider | Type | Free Tier | Card? | Student Benefits |
|---|---|---|---|---|
| **Resend** | Email API | 3,000/mo | No | ✅ GitHub Pack |
| **SendGrid** | Transactional | 100/day (3K/mo) | No | ✅ GitHub Pack |
| **Mailgun** | Email API | 5,000/mo (limited) | Yes | No |
| **Brevo** | Marketing + API | 300/day (9K/mo) | No | ✅ edu email |
| **Loops** | Email API | 500/mo, 5K contacts | No | No |

## Selection Guide

- **Best total free volume**: Brevo (9,000/month with unlimited contacts)
- **Best developer experience**: Resend (React Email, modern SDKs, no card)
- **Best deliverability**: SendGrid (proven infrastructure, 99.9% uptime)
- **Best API power**: Mailgun (full control, advanced routing)
- **Best for startups**: Loops (beautiful UX, simple pricing)
- **All-in-one**: Brevo (email marketing + transactional + SMS + chat)
