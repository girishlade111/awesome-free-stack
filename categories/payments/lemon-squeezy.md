## Lemon Squeezy

**Website**: https://www.lemonsqueezy.com
**Docs**: https://docs.lemonsqueezy.com
**GitHub**: https://github.com/lmsqueezy
**Category**: payments
**Subcategory**: payment-processing

### Description
Developer-friendly payment platform built specifically for software creators (now part of Stripe). Features license key generation, software update delivery, customer management, and a beautiful storefront. Handles all tax compliance as merchant of record.

### Free Tier
- **Transaction fee**: 5% + $0.50 per transaction (includes tax compliance)
- **Monthly fee**: None
- **Setup fee**: None
- **Included**: Storefront, license keys, software updates, customer portal, affiliate management

### Paid Plan
- **Enterprise**: Custom rates for high-volume sellers
- **Features**: Lower transaction fees, priority support
