### Description
State-of-the-art open text-to-image model by Stability AI with improved prompt adherence, typography, and image quality. Available under open weights license for local or cloud inference.

### Free Tier
- **Open weights**: Download and run locally for free with no usage limits
- **Stability AI Platform**: 25 free API credits per day on signup
- **Rate limit**: 100 requests per day on free API tier
- **Local use**: Unlimited generations on personal hardware

- **Starting at**: $0.004 per image (standard generation)
- **Billing**: Usage-based per image
