## OpenAI Playground

**Website**: https://platform.openai.com/playground
**Docs**: https://platform.openai.com/docs/guides/prompt-engineering
**GitHub**: https://github.com/openai
**Category**: ai
**Subcategory**: prompt-tools

### Description
A web-based prompt playground for experimenting with GPT-4 and GPT-4o models. Includes system prompt editing, temperature and top-p controls, multi-turn chat, and JSON mode for structured output testing.

### Free Tier
- **Playground**: Free web-based playground with new user credits
- **Credits**: $5 free API credits for new users
- **Rate limit**: 10K tokens per minute on GPT-4o mini
- **Models**: GPT-4o mini, GPT-4o, GPT-4, DALL-E 3 (rate limited)

### Paid Plan
- **Model**: Pay-as-you-go
- **Starting at**: $0.15 per 1M input tokens (GPT-4o mini)
- **Billing**: usage-based
