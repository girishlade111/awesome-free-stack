## Google AI Studio

**Website**: https://aistudio.google.com
**Docs**: https://ai.google.dev
**GitHub**: https://github.com/google-gemini
**Category**: ai
**Subcategory**: prompt-tools

### Description
A free web-based IDE for prototyping and testing prompts with Gemini models. Provides prompt templates, system instructions, safety settings, model comparison, and one-click API key generation — all with zero setup.

### Free Tier
- **Requests**: 60 requests per minute, 1,500 requests per day
- **Context**: 1 million token context window on Gemini 1.5 Flash
- **Models**: Gemini 1.5 Flash, Gemini 1.5 Pro (rate limited)
- **No card**: Absolutely free, no credit card required

### Paid Plan
- **Model**: Pay-as-you-go via API
- **Starting at**: $0.00025 per 1K input characters (Gemini 1.5 Pro)
- **Billing**: usage-based
