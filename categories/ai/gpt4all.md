## GPT4All

**Website**: https://gpt4all.io
**Docs**: https://docs.gpt4all.io

**Subcategory**: models

### Description
Desktop application that runs LLMs locally on consumer hardware with no GPU required. Provides a ChatGPT-like experience with privacy-preserving local inference, model downloader, and local RAG capabilities.

### Free Tier
- **Cost**: Completely free and open-source
- **Models**: 1,000+ open-source models available for download
- **Usage**: Unlimited local inference with no API costs
- **Hardware**: Runs on CPU only, no GPU required
