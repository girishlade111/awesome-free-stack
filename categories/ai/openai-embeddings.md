## OpenAI Embeddings

**Website**: https://platform.openai.com
**Docs**: https://platform.openai.com/docs/guides/embeddings
**GitHub**: https://github.com/openai

**Subcategory**: embeddings

### Description
Industry-leading text embedding models including text-embedding-3-small and text-embedding-3-large. Produce dense vector representations optimized for semantic search, clustering, and RAG pipelines with state-of-the-art performance on MTEB benchmarks.

### Free Tier
- **Credits**: $5 free credit for new users
- **Rate limit**: 3,000 tokens per minute on free tier
- **Models**: text-embedding-3-small available on free tier
- **Usage limits**: Rate-based, no monthly request cap with credits

### Paid Plan
- **Model**: Pay-as-you-go per token
- **Starting at**: $0.02/1M tokens (text-embedding-3-small)
- **Billing**: Usage-based per token
