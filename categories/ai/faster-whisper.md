## Faster Whisper

**Website**: https://github.com/SYSTRAN/faster-whisper

**Category**: ai

### Description
Highly optimized Whisper inference using CTranslate2, achieving up to 4x faster transcription than OpenAI's implementation. Supports all Whisper models with reduced memory usage and batched inference.

### Free Tier
- **Pricing**: Completely free and open source
- **Models**: Supports tiny through large-v3
- **Features**: Batched inference, VAD, diarization integration
- **Hardware**: CPU (int8), GPU (FP16), CUDA, ROCm

None — fully open-source
