### Description
IBM's open-source document understanding library for RAG pipelines. Parses PDFs, Word docs, and PowerPoint files into structured Markdown with layout preservation, table extraction, and OCR. Designed to feed clean document content into RAG systems.

### Free Tier
- **License**: MIT, fully open-source
- **Limits**: Unlimited self-hosted usage
- **Formats**: PDF, DOCX, PPTX, images
- **Features**: Layout analysis, table extraction, OCR, Markdown output
