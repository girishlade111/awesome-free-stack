## Open WebUI

**Website**: https://openwebui.com
**Docs**: https://docs.openwebui.com

**Category**: ai
**Subcategory**: models

### Description
Feature-rich web interface for interacting with LLMs, designed as a frontend for Ollama and OpenAI-compatible backends. Provides chat management, RAG, web search, multi-user support, and plugin system with a clean responsive UI.

### Free Tier
- **Cost**: Completely free and open-source, self-hosted via Docker
- **Models**: Works with any Ollama or OpenAI-compatible backend
- **Usage**: Unlimited local inference with offline-capable interface
- **Features**: Multi-user support, RAG, image generation, voice input
