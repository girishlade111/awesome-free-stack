## Google Cloud Text-to-Speech

**Website**: https://cloud.google.com/text-to-speech
**Docs**: https://cloud.google.com/text-to-speech/docs
**GitHub**: https://github.com/GoogleCloudPlatform
**Category**: ai
**Subcategory**: speech

### Description
Google Cloud's text-to-speech API with 380+ voices across 50+ languages. Features WaveNet and Neural2 voices for natural-sounding speech, SSML support, and custom voice tuning.

### Free Tier
- **Characters**: 1 million characters per month free
- **Voices**: Standard and WaveNet voices included
- **Features**: SSML, pitch/speed/volume controls
- **Rate limit**: Standard API quotas apply

### Paid Plan
- **Model**: Pay-as-you-go
- **Starting at**: $0.000004/character (standard), $0.000016/character (WaveNet)
- **Billing**: Usage-based per character
