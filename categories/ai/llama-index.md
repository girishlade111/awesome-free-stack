## LlamaIndex

**Website**: https://llamaindex.ai
**Docs**: https://docs.llamaindex.ai
**GitHub**: https://github.com/run-llama/llama_index
**Category**: ai
**Subcategory**: agents

### Description
Data framework for LLM applications with powerful agent and RAG capabilities. Connects LLMs to 160+ data sources with ingestion, indexing, retrieval, and agentic workflows — all free and open source.

### Free Tier
- **Open source**: MIT license, fully free self-hosted
- **LlamaCloud**: Free tier for managed parsing and retrieval
- **160+ connectors**: Data sources included

### Paid Plan
- **LlamaCloud**: Managed parsing and retrieval, usage-based pricing
