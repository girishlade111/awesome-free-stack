## ComfyUI

**Website**: https://www.comfy.org
**Docs**: https://docs.comfy.org
**GitHub**: https://github.com/comfyanonymous/ComfyUI
**Category**: ai
**Subcategory**: image-generation

### Description
Powerful open-source node-based interface for Stable Diffusion image generation. Provides a visual workflow editor for building complex diffusion pipelines with custom nodes and advanced control.

### Free Tier
- **Open source**: Fully free under GPL-3.0 license
- **Local execution**: Run on your own GPU with no usage limits
- **Custom nodes**: 1000+ community custom nodes available
- **Model support**: SD 1.5, SDXL, SD3, Flux, and custom checkpoints

### Paid Plan
- **Model**: Free and open source
- **Starting at**: None
- **Billing**: No paid version
