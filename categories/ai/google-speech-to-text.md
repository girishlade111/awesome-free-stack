## Google Cloud Speech-to-Text

**Website**: https://cloud.google.com/speech-to-text
**Docs**: https://cloud.google.com/speech-to-text/docs
**GitHub**: https://github.com/GoogleCloudPlatform
**Category**: ai
**Subcategory**: speech

### Description
Google Cloud's speech recognition API supporting 125+ languages with real-time and async transcription. Features include diarization, profanity filtering, word-level confidence, and domain-specific models.

### Free Tier
- **Minutes**: 60 minutes per month free
- **Models**: Standard and enhanced models available
- **Features**: Real-time streaming, batch transcription
- **Rate limit**: Standard API quotas apply

### Paid Plan
- **Model**: Pay-as-you-go
- **Starting at**: $0.006/15 seconds (standard model)
- **Billing**: Usage-based per 15-second increments
