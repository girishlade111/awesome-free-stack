### Description
Fast, lightweight LLM API server built on exllamav2 for optimal GPU inference. Provides an OpenAI-compatible endpoint with support for Llama, Mistral, and Qwen models in EXL2 format with dynamic batching and streaming.

### Free Tier
- **Cost**: Completely free and open-source
- **Models**: Supports EXL2 format models with very fast inference
- **Usage**: Unlimited self-hosted inference with OpenAI-compatible API
- **Hardware**: CUDA GPU optimized with high throughput
