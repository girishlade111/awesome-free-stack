### Description
High-performance C/C++ implementation of LLM inference optimized for CPU and GPU. The foundation for GGUF model format, used by nearly every local LLM tool. Features quantization, GPU offloading, and a built-in HTTP server.

### Free Tier
- **Cost**: Completely free and open-source
- **Models**: Runs all GGUF models including Llama 3, Mistral, Qwen, Gemma
- **Usage**: Unlimited local inference with no restrictions
- **Hardware**: CPU optimized with optional GPU acceleration (CUDA, Metal, Vulkan)
