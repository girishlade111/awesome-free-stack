### Description
Professional open-source image generation toolkit with a unified canvas interface for Stable Diffusion. Features node-based workflows, layer support, and integrated editing with inpainting and outpainting.

### Free Tier
- **Open source**: Fully free under Apache 2.0 license
- **Local execution**: Run on your hardware with unlimited generations
- **Unified Canvas**: Built-in image compositing and editing workspace
- **Model support**: SD 1.5, SDXL, SD3, Flux, and fine-tuned models
