## Gemini API

**Website**: https://ai.google.dev
**Docs**: https://ai.google.dev/docs
**GitHub**: https://github.com/google-gemini
**Category**: ai
**Subcategory**: apis

### Description
Google's multimodal AI API with access to Gemini 1.5 Pro and Flash models. Supports text, image, audio, video, and code generation with a best-in-class 1M token context window completely free.

### Free Tier
- **Rate limit**: 60 requests/minute, 1,500 requests/day
- **Context window**: 1M tokens (free tier)
- **Models**: Gemini 1.5 Flash (free), Gemini 1.5 Pro (rate-limited free)
- **No credit card required**: Sign up with Google account

### Paid Plan
- **Model**: Pay-as-you-go
- **Starting at**: $0.00025/1K input characters (Gemini 1.5 Pro)
- **Billing**: Usage-based
