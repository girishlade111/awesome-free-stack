### Description
Claude 3 API (Opus, Sonnet, Haiku) for text analysis, code generation, and reasoning. Features industry-leading safety, 200K token context, and free chat on claude.ai.

### Free Tier
- **API rate limit**: ~5 requests/minute on free tier
- **Free chat**: Unlimited free chat on claude.ai web interface
- **Context window**: 200K tokens
- **Models**: Claude 3 Haiku (free API), Claude 3 Sonnet (limited)

### Paid Plan
- **Model**: Pay-as-you-go
- **Starting at**: $0.003/1K tokens (Claude 3 Haiku)
- **Billing**: Usage-based
