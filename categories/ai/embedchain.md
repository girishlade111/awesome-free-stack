## Embedchain

**Website**: https://embedchain.ai
**Docs**: https://docs.embedchain.ai
**GitHub**: https://github.com/embedchain/embedchain
**Category**: ai
**Subcategory**: rag

### Description
Open-source RAG framework designed for unstructured data from any source. Supports documents, websites, YouTube videos, code repositories, and more with a simple API. Abstracts away the complexity of chunking, embedding, and retrieval.

### Free Tier
- **License**: Apache 2.0, fully open-source
- **Limits**: Unlimited self-hosted usage
- **Supported**: OpenAI, Anthropic, Azure, Hugging Face, Ollama, local LLMs

### Paid Plan

- **Starting at**: Custom pricing
- **Billing**: Usage-based
