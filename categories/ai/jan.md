### Description
Open-source ChatGPT alternative that runs entirely on your desktop with local AI models. Features a clean interface with extensions, model management, and built-in inference engine supporting GGUF models with GPU acceleration.

### Free Tier
- **Cost**: Completely free and open-source
- **Models**: Download and run any GGUF model from Hugging Face
- **Usage**: Unlimited offline inference with no API costs
- **Hardware**: CPU and GPU support (CUDA, Metal, Vulkan)
