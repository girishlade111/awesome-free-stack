### Description
Serverless GPU compute platform for AI and ML workloads. Run containerized Python apps with GPU acceleration (A100, T4, L4), auto-scaling, and pay-per-second billing. Generous free monthly credits included.

### Free Tier
- /month free credits (~500 GPU hours on T4)
- 17GB persistent storage
- 1GB ephemeral disk per app
