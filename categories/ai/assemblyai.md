### Description
Speech recognition API with state-of-the-art accuracy for transcription, speaker diarization, content moderation, and summarization. Offers easy-to-use REST API with SDKs in multiple languages.

### Free Tier
- **Hours**: 10 hours of audio processing per month
- **Models**: Access to Conformer-2 model
- **Features**: Punctuation, sentiment analysis, entity detection, summarization
- **Rate limit**: 2 concurrent requests

### Paid Plan
- **Model**: Pay-as-you-go
- **Starting at**: $0.015/min (real-time), $0.008/min (batch)
- **Billing**: Usage-based per audio minute
