### Description
Hugging Face's production-grade inference server for deploying large language models. Provides optimized inference with continuous batching, tensor parallelism, quantization, and watermarking — powers Hugging Face's own Inference API.

### Free Tier
- **Cost**: Completely free and open-source, self-hosted
- **Models**: Supports all Hugging Face transformer models
- **Usage**: Unlimited self-hosted inference with OpenAI-compatible API
- **Hardware**: GPU optimized with multi-GPU sharding support
