**Website**: https://mistral.ai

### Description
French AI company offering open-weight and API-accessible models. Mistral Large, Small, and Codestral for code generation. Le Chat provides a free chat interface. Open-weight models available for self-hosting.

### Free Tier
- **API**: Free tier with rate limits for experimentation
- **Le Chat**: Completely free web chat interface
- **Open-source**: Many models available as open weights

### Paid Plan
- **Model**: Pay-as-you-go
- **Starting at**: €0.004/1K tokens (Mistral Large)
- **Billing**: Usage-based
