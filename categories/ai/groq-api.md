## Groq API

**Website**: https://console.groq.com
**Docs**: https://console.groq.com/docs

**Category**: ai
**Subcategory**: apis

### Description
Ultra-fast LLM inference API powered by Groq's LPU hardware. Runs Llama 3, Mixtral, Gemma, and Whisper at blazing speeds with an OpenAI-compatible free tier endpoint.

### Free Tier
- **Requests**: 30 requests/minute
- **Daily limit**: 14,400 requests/day
- **Models**: Llama 3, Mixtral, Gemma, Whisper, and other open models
- **No free credits**: Free tier is rate-limited but generous

### Paid Plan
- **Model**: Pay-as-you-go
- **Starting at**: ~$0.27/1M tokens for premium throughput
- **Billing**: Usage-based
