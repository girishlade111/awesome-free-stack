### Description
Open-source Python library for building ML demo web apps with minimal code. Create shareable UIs for any ML model with drag-and-drop interfaces, live API endpoints, and free hosting on Hugging Face Spaces.

### Free Tier
- Completely free under Apache 2.0 license. Unlimited local usage. Free hosting on Hugging Face Spaces.

### Paid Plan
- **Model: No paid version; fully free and open source. Gradio Cloud free tier for hosted demos.
- **Billing**: usage-based
