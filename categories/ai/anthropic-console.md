## Anthropic Console

**Website**: https://console.anthropic.com
**Docs**: https://docs.anthropic.com
**GitHub**: https://github.com/anthropics
**Category**: ai
**Subcategory**: prompt-tools

### Description
A free browser-based prompt playground for testing and iterating on prompts with Claude models. Features system prompt editing, multi-turn conversations, JSON output mode, and direct API key generation for development.

### Free Tier
- **Playground**: Unlimited free prompt testing in the browser
- **API requests**: 5 requests per minute on free API tier
- **Models**: Claude 3.5 Sonnet, Claude 3 Haiku available
- **Chat**: Unlimited free chat on claude.ai

### Paid Plan
- **Model**: Pay-as-you-go via API
- **Starting at**: $3 per million input tokens (Claude 3.5 Sonnet)
- **Billing**: usage-based
