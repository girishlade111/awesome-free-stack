### Description
BAAI's BGE-M3 is a state-of-the-art multilingual embedding model supporting dense, sparse, and multi-vector retrieval. With support for over 100 languages and a 8K context window, it excels at cross-lingual retrieval and hybrid search in RAG pipelines.
