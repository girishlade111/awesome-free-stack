## LiteLLM

**Website**: https://litellm.ai
**Docs**: https://docs.litellm.ai
**GitHub**: https://github.com/BerriAI/litellm
**Category**: ai
**Subcategory**: models

### Description
Unified API interface that provides access to 100+ LLM providers through a single OpenAI-compatible format. Simplifies switching between OpenAI, Anthropic, Google, Ollama, vLLM, and local models with consistent input/output formatting.

### Free Tier
- **Cost**: Open-source and free for self-hosted usage
- **Models**: Access to 100+ providers through unified interface
- **Usage**: Unlimited local proxy calls with no rate limits
- **Features**: Load balancing, cost tracking, model fallback

### Paid Plan
- **Model**: LiteLLM Proxy Enterprise
- **Starting at**: Custom pricing
- **Billing**: subscription
