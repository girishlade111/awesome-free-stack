### Description
Advanced text-to-image generation model by Black Forest Labs offering high-quality outputs with precise prompt adherence. Available in Pro, Dev, and Schnell variants with open-source options.

### Free Tier
- **Flux Schnell**: Open-source model available for local use under Apache 2.0 license
- **BFL API**: 10 free image generations on signup
- **Rate limit**: 5 requests per minute on free API tier
- **Community hosting**: Run on Replicate, Hugging Face, or ComfyUI

### Paid Plan
- **Model**: Flux Pro / Flux Dev API
- **Starting at**: $0.05 per image (Pro), $0.025 per image (Dev)
- **Billing**: Usage-based per image
