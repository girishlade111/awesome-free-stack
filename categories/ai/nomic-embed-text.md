## Nomic Embed Text

**Website**: https://atlas.nomic.ai
**Docs**: https://docs.nomic.ai
**GitHub**: https://github.com/nomic-ai/nomic
**Category**: ai
**Subcategory**: embeddings

### Description
Nomic AI's open-source embedding model that achieves top-tier performance on MTEB and LoCo benchmarks. Nomic Embed Text offers a long 8K context window and supports both API-based and self-hosted deployment for semantic search applications.

### Free Tier
- **API requests**: 1,000 free API requests per month
- **Model**: nomic-embed-text-v1.5 (8K context)
- **Rate limit**: 100 requests per minute
- **No card required**: Free tier available

### Paid Plan
- **Model**: Pay-as-you-go per token
- **Starting at**: $0.00001/1K input tokens
- **Billing**: Usage-based
