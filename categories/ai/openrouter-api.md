## OpenRouter

**Website**: https://openrouter.ai
**Docs**: https://openrouter.ai/docs
**GitHub**: https://github.com/OpenRouterTeam
**Category**: ai

### Description
Unified API gateway to 200+ AI models from 20+ providers. Access OpenAI, Anthropic, Google, Meta, and Mistral models through a single OpenAI-compatible endpoint. Free credits included with no card required.

### Free Tier
- **Credits**: $1 free credits for new users, no card required
- **Free models**: Rate-limited access to smaller open-source models
- **One endpoint**: Switch between providers with a single API key

### Paid Plan
- **Model**: Pay-per-token across all providers
- **Starting at**: Varies by provider/model
- **Billing**: Usage-based, no subscription required
