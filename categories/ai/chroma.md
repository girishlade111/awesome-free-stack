## Chroma

**Website**: https://www.trychroma.com
**Docs**: https://docs.trychroma.com

**Category**: ai
**Subcategory**: vector-databases

### Description
Lightweight, open-source embedding database designed for AI prototyping. Runs in-memory or persisted to disk with a simple Python API — just pip install and start using with a forever free tier.

### Free Tier
- **Self-hosted**: Completely free, no limits
- **Vectors**: Unlimited count, unlimited dimensions
- **No server**: Runs embedded in your Python process

### Paid Plan
- No paid version yet; Chroma Cloud coming soon.
