## Agenta

**Website**: https://agenta.ai
**Docs**: https://docs.agenta.ai
**GitHub**: https://github.com/Agenta-AI/agenta
**Category**: ai

### Description
An open-source platform for prompt engineering, versioning, and LLM evaluation. Provides a collaborative web UI for A/B testing prompts across models, human evaluation workflows, and continuous improvement pipelines.

### Free Tier
- **Self-hosted**: Fully free under MIT license
- **Cloud**: 1,000 evaluations per month on free tier
- **Users**: 2 users on cloud free tier
- **Features**: Prompt versioning, A/B testing, evaluation

### Paid Plan
- **Model**: Cloud Pro
- **Starting at**: $29/month
- **Billing**: subscription
