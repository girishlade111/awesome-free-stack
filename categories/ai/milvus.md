## Milvus

**Website**: https://milvus.io
**Docs**: https://milvus.io/docs
**GitHub**: https://github.com/milvus-io/milvus
**Category**: ai
**Subcategory**: vector-databases

### Description
Cloud-native vector database built for billion-scale similarity search. Features multiple index types including GPU-accelerated, DiskANN, and hybrid search with a free tier via Zilliz Cloud.

### Free Tier
- **Self-hosted**: Fully free, unlimited
- **Zilliz Cloud**: 100K vectors, 1 CU free
- **Milvus Lite**: Embedded Python, free

### Paid Plan
- **Zilliz Cloud**: Usage-based CU pricing
- **Self-hosted**: Free
