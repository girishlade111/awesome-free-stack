### Description
An open-source LLM observability platform for monitoring, debugging, and optimizing prompts in production. Provides request logging, cost tracking, prompt experimentation, and custom dashboards with a generous free tier.

### Free Tier
- **Requests**: 100,000 requests per month
- **Retention**: 14-day data retention
- **Features**: Request logging, cost tracking, basic analytics
- **Self-hosted**: Unlimited and free (MIT license)

### Paid Plan
- **Model**: Growth
- **Starting at**: $20/month
- **Billing**: subscription
