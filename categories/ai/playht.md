**Website**: https://play.ht

### Description
Text-to-speech API and web platform with 900+ ultra-realistic AI voices across 140+ languages. Offers voice cloning, real-time streaming, SSML support, and an embeddable audio player.

### Free Tier
- **Characters**: 20,000 characters per month
- **Voices**: Access to standard voice library
- **Features**: Basic TTS API, downloadable audio
- **Rate limit**: 100 requests per day

### Paid Plan
- **Model**: Subscription
- **Starting at**: $39/month (Creator)
- **Billing**: Monthly subscription with character quotas
