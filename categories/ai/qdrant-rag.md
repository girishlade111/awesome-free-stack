**Website**: https://qdrant.tech

### Description
Collection of RAG examples, tools, and reference architectures built around Qdrant vector database. Includes production-ready RAG patterns with hybrid search, semantic caching, and multi-modal retrieval. Self-hosted or cloud with generous free tier.

### Free Tier
- **License**: Apache 2.0, fully open-source
- **Limits**: Unlimited self-hosted usage
- **Qdrant Cloud**: 1 cluster with 1GB storage free

### Paid Plan
