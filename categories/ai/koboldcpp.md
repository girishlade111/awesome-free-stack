### Description
All-in-one LLM inference package based on llama.cpp with a built-in API server and web interface. Designed for story generation and role-play with special features like grammar sampling, adventure mode, and image generation support.

### Free Tier
- **Cost**: Completely free and open-source
- **Models**: Supports GGUF models with flexible quantization options
- **Usage**: Unlimited local inference with built-in web UI and API
- **Hardware**: CPU and GPU support with partial offloading
