**Website**: https://www.mixedbread.ai

### Description
Mixedbread AI develops mxbai-embed-large, a state-of-the-art open-source embedding model that rivals proprietary alternatives. Offers a free API tier alongside the open-source model for semantic search and RAG applications.

### Free Tier
- **API requests**: 1,000 free API requests per month
- **Rate limit**: 10 requests per minute on free tier
- **Models**: mxbai-embed-large (open-source), mxbai-rerank
- **No card required**: Free tier without credit card

### Paid Plan
- **Model**: Pay-as-you-go
- **Starting at**: $0.0003/1K input tokens
- **Billing**: Usage-based
