### Description
FastEmbed is Qdrant's open-source library for fast, efficient embedding generation. Built with ONNX Runtime, it supports popular embedding models with optimized inference speed and minimal dependencies for production RAG pipelines.

### Free Tier
- **Open source**: Fully free, Apache 2.0 license
- **Models**: BGE, Instructor, E5, Jina, Nomic, and more
- **Usage**: Unlimited local usage, no API calls needed
- **No card required**: Free to download and use
