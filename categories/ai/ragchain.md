## RAGchain

**Website**: https://ragchain.xyz

**Subcategory**: rag

### Description
Open-source RAG framework with modular pipeline components for document ingestion, chunking, embedding, retrieval, and LLM generation. Supports advanced RAG strategies including RAPTOR, context compression, and hybrid search with multiple vector store backends.

### Free Tier
- **License**: Apache 2.0, fully open-source
- **Limits**: Unlimited self-hosted usage
- **Supported**: OpenAI, Anthropic, Cohere, Hugging Face, local LLMs
