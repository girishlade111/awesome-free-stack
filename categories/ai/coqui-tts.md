## Coqui TTS

**Website**: https://github.com/coqui-ai/TTS
**Docs**: https://tts.readthedocs.io
**GitHub**: https://github.com/coqui-ai/TTS
**Category**: ai
**Subcategory**: speech

### Description
Open-source deep learning toolkit for text-to-speech with 1100+ pre-trained models including XTTS-v2, Bark, and YourTTS. Supports multi-speaker TTS, voice cloning, and fine-tuning on custom datasets.

### Free Tier
- **Pricing**: Completely free and open source
- **Models**: 1100+ pre-trained models across 80+ languages
- **Features**: Multi-speaker TTS, voice cloning, fine-tuning API
- **Hardware**: CPU inference, GPU (CUDA) recommended for XTTS-v2
