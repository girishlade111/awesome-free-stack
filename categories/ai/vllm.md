### Description
High-throughput, memory-efficient LLM serving engine with PagedAttention for optimal GPU utilization. Supports continuous batching, tensor parallelism, and OpenAI-compatible API — the industry standard for production LLM serving.

### Free Tier
- **Cost**: Completely free and open-source, self-hosted
- **Models**: Supports Hugging Face models, Llama, Mistral, Qwen, and more
- **Usage**: Unlimited self-hosted inference with no rate limits
- **Hardware**: CUDA GPUs with optimized memory management
