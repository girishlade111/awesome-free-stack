### Description
Stability AI's suite of image editing and generation tools with a free API tier. Offers text-to-image, image upscaling, background removal, relighting, and image-to-image translation.

### Free Tier
- **API calls**: 100 free API calls per month
- **Rate limit**: 10 requests per minute on free tier
- **Tools**: Text-to-image, remove background, upscale, clean up, relight
- **Web app**: Free access to Clipdrop web platform with daily limits

### Paid Plan
- **Model**: Clipdrop Pro
- **Starting at**: $9/month (1,000 API calls)
- **Billing**: Monthly subscription or usage-based API
