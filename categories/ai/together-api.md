## Together AI

**Website**: https://together.ai
**Docs**: https://docs.together.ai
**GitHub**: https://github.com/togethercomputer
**Category**: ai
**Subcategory**: apis

### Description
Cloud platform for running 100+ open-source AI models. Provides inference API for Llama 3, Mistral, Mixtral, and Stable Diffusion with OpenAI-compatible endpoints and fine-tuning support.

### Free Tier
- **Credits**: $1 free credit with no card required
- **Models**: Rate-limited free access to 100+ open models
- **OpenAI-compatible**: Drop-in replacement for OpenAI client

### Paid Plan
- **Model**: Pay-as-you-go
- **Starting at**: ~$0.10/1M tokens for most models
- **Billing**: Usage-based
