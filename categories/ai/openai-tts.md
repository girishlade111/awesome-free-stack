## OpenAI TTS

**Website**: https://platform.openai.com
**Docs**: https://platform.openai.com/docs/guides/text-to-speech
**GitHub**: https://github.com/openai
**Category**: ai
**Subcategory**: speech

### Description
OpenAI's text-to-speech API offering six natural-sounding voices across two models (tts-1 and tts-1-hd). Supports streaming, SSML, and multiple output formats including MP3, Opus, AAC, and FLAC.

### Free Tier
- **Credits**: $5 free credit for new users
- **Pricing**: $0.015 per 1K input characters (tts-1), $0.030 per 1K (tts-1-hd)
- **Rate limit**: 50 requests per minute
- **Voices**: 6 built-in voices (alloy, echo, fable, onyx, nova, shimmer)

### Paid Plan
- **Model**: Pay-as-you-go
- **Starting at**: $0.015/1K characters (tts-1)
- **Billing**: Usage-based per character
