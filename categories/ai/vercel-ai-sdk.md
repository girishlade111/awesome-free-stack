## Vercel AI SDK

**Website**: https://sdk.vercel.ai
**Docs**: https://sdk.vercel.ai/docs
**GitHub**: https://github.com/vercel/ai
**Category**: ai
**Subcategory**: agents

### Description
TypeScript toolkit for building AI-powered user interfaces. Provides React/Vue/Svelte hooks for streaming chat, completion, tool calling, and agent interactions with any LLM provider — all free.

### Free Tier
- **Open source**: Apache 2.0 license, fully free
- **Any provider**: OpenAI, Anthropic, Google, Mistral, Ollama
- **No limits**: Unlimited usage of the framework itself

### Paid Plan
- Framework is free and open source; Vercel hosting and LLM API costs are separate.
