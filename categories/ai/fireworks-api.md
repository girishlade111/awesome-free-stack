### Description
Fast inference API for open-source models with blazing speeds. Supports Llama 3, Mistral, Mixtral, DeepSeek, and fine-tuned models via an OpenAI-compatible endpoint with a generous free tier.

### Free Tier
- **Rate limit**: 25 requests/minute on all open models
- **No credit card**: Free tier available without card
- **Models**: Llama 3, Mistral, Mixtral, DeepSeek, fine-tuned models

### Paid Plan
- **Model**: Pay-as-you-go
- **Starting at**: $0.15/1M tokens for higher rate limits
- **Billing**: Usage-based
