## NeMo Guardrails

**Website**: https://developer.nvidia.com/nemo-guardrails
**Docs**: https://docs.nvidia.com/nemo/guardrails
**GitHub**: https://github.com/NVIDIA/NeMo-Guardrails
**Category**: ai
**Subcategory**: rag

### Description
Open-source guardrails framework by NVIDIA for building safe and trustworthy RAG applications. Provides programmable guardrails for input/output validation, fact-checking, hallucination detection, and topical boundaries. Integrates with LangChain and NeMo.

### Free Tier
- **License**: Apache 2.0, fully open-source
- **Limits**: Unlimited self-hosted usage
- **Integrations**: LangChain, NeMo, custom LLM backends
