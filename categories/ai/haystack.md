### Description
Open-source NLP framework for building production-grade RAG pipelines, search systems, and agent-based applications. Provides modular components for document processing, retrieval, and LLM orchestration with 100+ pipeline examples.

### Free Tier
- **License**: Apache 2.0, fully open-source
- **Limits**: Unlimited self-hosted usage with any LLM (OpenAI, Anthropic, Cohere, Hugging Face, local)
- **Haystack Cloud**: Free tier with limited pipeline runs

### Paid Plan
- **Model**: Haystack Cloud
- **Starting at**: Custom pricing for managed pipelines
- **Billing**: Usage-based
