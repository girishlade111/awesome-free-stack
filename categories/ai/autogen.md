## AutoGen

**Website**: https://microsoft.github.io/autogen
**Docs**: https://microsoft.github.io/autogen/stable
**GitHub**: https://github.com/microsoft/autogen
**Category**: ai
**Subcategory**: agents

### Description
Microsoft's multi-agent conversation framework enabling agents to converse, collaborate, and solve tasks. Supports code generation, execution, debugging, and human-in-the-loop interactions — all free.

### Free Tier
- **Open source**: MIT license, fully free self-hosted
- **AutoGen Studio**: Free GUI for prototyping and debugging agents
- **No limits**: Unlimited agents and conversations

### Paid Plan
- Entire framework is free and open source; no paid version exists.
