### Description
Open-source Python library for turning data scripts into shareable web apps in minutes. Build interactive ML dashboards, data apps, and AI demos with pure Python. Free community cloud hosting included.

### Free Tier
- Completely free under Apache 2.0 license. Streamlit Community Cloud: 1 app with 1GB storage
- unlimited public apps.

### Paid Plan
- **Model: Streamlit Teams — custom pricing for private apps, SSO, and team features
- **Billing**: contact-sales
