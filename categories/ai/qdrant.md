## Qdrant

**Website**: https://qdrant.tech
**Docs**: https://qdrant.tech/documentation

**Category**: ai

### Description
High-performance vector database written in Rust. Production-ready with rich filtering, quantization, and multi-tenant support. Outstanding performance with low memory footprint and a generous free tier.

### Free Tier
- **Self-hosted**: Unlimited, completely free
- **Qdrant Cloud**: 1 cluster, 1GB storage free
- **Rust-native**: Blazing fast, memory efficient

### Paid Plan
- **Qdrant Cloud**: $25+/month for dedicated clusters
- **Billing**: Monthly subscription
