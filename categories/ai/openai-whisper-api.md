## OpenAI Whisper API

**Website**: https://platform.openai.com
**Docs**: https://platform.openai.com/docs/guides/speech-to-text
**GitHub**: https://github.com/openai/whisper
**Category**: ai
**Subcategory**: speech

### Description
OpenAI's speech-to-text API powered by the Whisper model. Supports transcription and translation across 100+ languages with high accuracy. Available through the OpenAI API platform.

### Free Tier
- **Credits**: $5 free credit for new users
- **Pricing**: $0.006 per minute (transcription)
- **Limits**: Rate-limited to 50 requests per minute
- **Models**: Whisper-1 (large-v2)

### Paid Plan
- **Model**: Pay-as-you-go
- **Starting at**: $0.006/min (transcription), $0.012/min (translation)
- **Billing**: Usage-based per second of audio
