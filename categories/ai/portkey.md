## Portkey

**Website**: https://portkey.ai
**Docs**: https://docs.portkey.ai
**GitHub**: https://github.com/Portkey-AI/gateway
**Category**: ai

### Description
An LLM observability and prompt management platform with an AI gateway for monitoring, versioning, and managing prompts across multiple providers. Includes request logging, cost tracking, and prompt version control with an OpenAI-compatible SDK.

### Free Tier
- **Requests**: 10,000 requests per month
- **Retention**: 3-day data retention
- **Users**: 1 user
- **Features**: Multi-provider support, logging, analytics

### Paid Plan
- **Model**: Team
- **Starting at**: $49/month
- **Billing**: subscription
