## PydanticAI

**Website**: https://ai.pydantic.dev
**Docs**: https://ai.pydantic.dev
**GitHub**: https://github.com/pydantic/pydantic-ai
**Category**: ai
**Subcategory**: agents

### Description
Type-safe Python agent framework built on Pydantic. Provides structured outputs with compile-time validation, dependency injection, streaming, and multi-model support — all verified by Python's type system.

### Free Tier
- **Open source**: MIT license, fully free self-hosted
- **Any LLM**: OpenAI, Anthropic, Gemini, Ollama, Groq

### Paid Plan
- Entire framework is free and open source; no paid version exists.
