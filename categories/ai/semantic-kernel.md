## Semantic Kernel

**Website**: https://learn.microsoft.com/semantic-kernel
**Docs**: https://learn.microsoft.com/semantic-kernel/overview

**Category**: ai
**Subcategory**: agents

### Description
Microsoft's enterprise AI orchestration SDK integrating LLMs with .NET, Python, and Java. Provides plugins, function calling, planning, memory, and enterprise-grade AI for existing codebases — all free.

### Free Tier
- **Open source**: MIT license, fully free self-hosted
- **Multi-language**: First-class .NET, Python, Java support
- **Any LLM**: OpenAI, Azure AI, Ollama, local models

### Paid Plan
- Framework is free and open source; Azure AI services have separate pricing.
