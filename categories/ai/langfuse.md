## LangFuse

**Website**: https://langfuse.com

**Category**: ai

### Description
An open-source observability and prompt management platform for LLM applications. Combines tracing, prompt versioning, evaluation, and cost tracking in one dashboard with self-hosted and managed cloud options.

### Free Tier
- **Self-hosted**: Fully free under MIT license
- **Cloud**: 50,000 observations per month free
- **Features**: Prompt management, tracing, evaluations, cost analysis
- **Users**: Unlimited users on self-hosted

### Paid Plan
- **Model**: Cloud Team
- **Starting at**: $59/month
- **Billing**: subscription
