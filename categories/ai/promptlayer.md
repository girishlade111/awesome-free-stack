## PromptLayer

**Website**: https://promptlayer.com
**Docs**: https://docs.promptlayer.com
**GitHub**: https://github.com/MagnivOrg/promptlayer
**Category**: ai
**Subcategory**: prompt-tools

### Description
A prompt management platform for logging, versioning, and analyzing LLM prompts in production. Provides a collaborative dashboard for tracking prompt performance, A/B testing, and team-based prompt engineering workflows.

### Free Tier
- **Requests**: 1,000 requests per month
- **Retention**: 7-day data retention
- **Users**: 1 user
- **Features**: Basic prompt versioning and logging

### Paid Plan
- **Model**: Team
- **Starting at**: $99/month
- **Billing**: subscription
