### Description
Open-source library for optimal text chunking strategies in RAG pipelines. Provides implementations of semantic chunking, recursive splitting, sentence windowing, and context-aware segmentation. Helps improve retrieval quality through smarter chunk boundaries.

### Free Tier
- **License**: MIT, fully open-source
- **Limits**: Unlimited self-hosted usage
- **Strategies**: Semantic, recursive, fixed-size, sentence-based, sliding window
