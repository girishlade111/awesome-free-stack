**Website**: https://platform.openai.com

### Description
Access to GPT-4, GPT-4o, DALL-E 3, Whisper, and embedding models via REST API. Industry-leading LLM platform for building AI-powered applications with a $5 free credit free tier.

### Free Tier
- **Credits**: $5 free credit for new users
- **Rate limit**: 10K tokens per minute on GPT-4o mini
- **Free models**: GPT-4o mini, text-embedding-3-small, Whisper, DALL-E 3 (rate limited)
- **Usage limits**: Rate-based, not request-based

### Paid Plan
- **Model**: Pay-as-you-go
- **Starting at**: $0.15/1M input tokens (GPT-4o mini)
- **Billing**: Usage-based per token
