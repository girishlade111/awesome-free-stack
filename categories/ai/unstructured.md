### Description
Document preprocessing platform for RAG pipelines. Parses PDFs, HTML, emails, images, and 20+ file formats into structured data ready for vector databases. Free hosted API with generous limits and open-source library for self-hosting.

### Free Tier
- **API**: 1,000 pages/month free with hosted API
- **Open source**: MIT license, unlimited self-hosted usage
- **Formats**: PDF, DOCX, HTML, XML, emails, markdown, images, and more

### Paid Plan
- **Model**: Unstructured API
- **Starting at**: Custom pricing for higher volume
- **Billing**: Usage-based
