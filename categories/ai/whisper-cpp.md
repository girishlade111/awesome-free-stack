## Whisper.cpp

**Website**: https://github.com/ggerganov/whisper.cpp

**GitHub**: https://github.com/ggerganov/whisper.cpp
**Category**: ai
**Subcategory**: speech

### Description
High-performance C++ port of OpenAI's Whisper model using GGML and GGML-accelerated inference. Runs entirely on CPU, no GPU required, with support for all Whisper model sizes including distilled variants.

### Free Tier
- **Pricing**: Completely free and open source
- **Models**: tiny to large-v3 plus distilled variants
- **Features**: CLI tool, library API, real-time streaming, VAD
- **Hardware**: CPU-only (ARM/x86), GPU via Metal/CUDA, cross-platform

None — fully open-source
