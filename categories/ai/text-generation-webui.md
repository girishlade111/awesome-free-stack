## Text Generation WebUI

### Description
Comprehensive web interface for running large language models locally. Supports multiple model formats (GGUF, GPTQ, EXL2, AWQ), LoRA fine-tuning, multimodal models, and has a rich ecosystem of extensions.

### Free Tier
- **Cost**: Completely free and open-source
- **Models**: Supports Llama, Mistral, GPTQ, GGUF, EXL2, AWQ formats
- **Usage**: Unlimited local inference with no restrictions
- **Features**: Training/LoRA support, multimodal, character management, extensions
