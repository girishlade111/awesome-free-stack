## RAGAS

**Website**: https://docs.ragas.io
**Docs**: https://docs.ragas.io
**GitHub**: https://github.com/explodinggradients/ragas
**Category**: ai
**Subcategory**: rag

### Description
Open-source evaluation framework for RAG pipelines. Provides automated metrics for assessing retrieval quality (context precision, recall) and generation quality (faithfulness, answer relevancy). The standard benchmark for RAG system evaluation.

### Free Tier
- **License**: Apache 2.0, fully open-source
- **Limits**: Unlimited self-hosted usage
- **Metrics**: Faithfulness, answer relevancy, context precision, context recall, and more
