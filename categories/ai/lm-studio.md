### Description
Desktop application for discovering, downloading, and running local LLMs with a polished user interface. Features built-in model search from Hugging Face, GPU acceleration, and an OpenAI-compatible local API server.

### Free Tier
- **Cost**: Free desktop application
- **Models**: Browse and download models directly from Hugging Face
- **Usage**: Unlimited local inference with local API server
- **Hardware**: GPU acceleration with CUDA, Metal, and Vulkan support
