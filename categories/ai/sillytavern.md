### Description
Feature-rich chat interface for LLMs with character management, role-play, and group chats. Connects to any backend (Ollama, OpenAI, Claude, KoboldCPP, TabbyAPI) with advanced features like world info, lorebooks, and extension system.

### Free Tier
- **Cost**: Completely free and open-source
- **Models**: Works with any OpenAI-compatible API or local backend
- **Usage**: Unlimited local chat with rich character system
- **Features**: Group chats, character cards, world info, plugins, TTS
