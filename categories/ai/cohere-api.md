### Description
Enterprise LLM API specializing in RAG, embeddings, classification, and tool use. Command R/R+ models are optimized for retrieval-augmented generation and multi-step reasoning with a free trial free tier.

### Free Tier
- **Trial requests**: 100 trial requests/month
- **Free tier**: Rate-limited free tier for developers
- **Models**: Command R, Command R+, Embed v3
