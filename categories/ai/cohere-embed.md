## Cohere Embed

**Website**: https://cohere.com

### Description
Cohere's Embed endpoint provides multilingual and English embedding models optimized for semantic search, classification, and clustering. Supports over 100 languages with v3 models and offers both cloud API and self-hosted options.

### Free Tier
- **Trial requests**: 100 trial requests for new users
- **Rate limit**: 5 API calls per minute on free tier
- **Models**: Embed v3 (English and multilingual)
- **No credit card required**: Free trial available
