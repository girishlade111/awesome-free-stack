**GitHub**: none

### Description
Native local image generation app for macOS and iOS powered by Stable Diffusion. Runs entirely on-device with GPU acceleration optimized for Apple Silicon, requiring no internet connection.

### Free Tier
- **Completely free**: No paid tiers or subscriptions
- **Local generation**: Runs on Apple Silicon (M1-M4) GPU
- **Model support**: SD 1.5, SDXL, SD3, and Flux models
- **Features**: Text-to-image, img2img, inpainting, ControlNet, LoRA

- **Billing**: No paid version
