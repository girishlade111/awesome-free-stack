### Description
High-performance LLM inference engine forked from vLLM with additional optimizations for role-play and creative writing. Features include continuous batching, quantization (AWQ, GPTQ), and an OpenAI-compatible API with advanced sampling methods.

### Free Tier
- **Cost**: Completely free and open-source
- **Models**: Supports Hugging Face models, Llama, Mistral, Qwen, and more
- **Usage**: Unlimited self-hosted inference with no restrictions
- **Hardware**: CUDA GPU optimized with tensor parallelism support
