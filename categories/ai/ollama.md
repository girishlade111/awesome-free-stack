### Description
Run open-source LLMs locally with a single command. Supports Llama 3, Mistral, Gemma, Qwen, and hundreds of models with GPU acceleration, OpenAI-compatible API, and a rich model library.

### Free Tier
- **Cost**: Completely free and open-source, self-hosted
- **Models**: Access to 200+ open models from the Ollama library
- **Usage**: Unlimited local inference, no rate limits
- **Hardware**: Runs on CPU or GPU (NVIDIA, AMD, Apple Silicon)
