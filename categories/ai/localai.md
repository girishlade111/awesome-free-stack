## LocalAI

**Website**: https://localai.io
**Docs**: https://localai.io/docs
**GitHub**: https://github.com/mudler/LocalAI
**Category**: ai
**Subcategory**: models

### Description
Open-source, self-hosted OpenAI API replacement that runs LLMs, image generation, audio transcription, and text-to-speech locally. Supports multiple model backends including llama.cpp and transformers with no GPU required.

### Free Tier
- **Cost**: Completely free and open-source, self-hosted
- **Models**: Supports GGUF, GPTQ, EXL2, and Hugging Face models
- **Usage**: Unlimited local inference with OpenAI-compatible endpoints
- **Hardware**: CPU and GPU support (CUDA, Metal, OpenCL)
