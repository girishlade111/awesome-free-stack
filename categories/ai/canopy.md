### Description
Open-source RAG framework built on Pinecone vector database. Provides a complete end-to-end pipeline for ingesting documents, generating embeddings, and answering questions with LLM integration. Designed for quick RAG prototyping.

### Free Tier
- **License**: Apache 2.0, fully open-source
- **Limits**: Unlimited self-hosted usage
- **Requires**: Pinecone API key (free tier: 1M vectors on pod-based index)

### Paid Plan

- **Starting at**: $0.075/pod-hour
- **Billing**: Usage-based
