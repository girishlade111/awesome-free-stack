## Hugging Face Inference API

**Website**: https://huggingface.co
**Docs**: https://huggingface.co/docs/api-inference
**GitHub**: https://github.com/huggingface
**Category**: ai
**Subcategory**: apis

### Description
Free serverless API access to 150,000+ open-source models on the Hugging Face Hub. Supports text, image, audio, video, and multimodal inference with a unified free tier API.

### Free Tier
- **Tokens**: 30,000 free input tokens/month for serverless inference
- **Models**: Free access to 150K+ open-source models
- **Rate limits**: Rate-limited for serverless endpoints
- **No card required**: Free tier available without credit card

### Paid Plan
- **Inference**: Dedicated endpoints $0.06/hour (CPU) or $0.80/hour (GPU)
- **Pro account**: $9/month for higher rate limits
- **Billing**: Usage-based for dedicated endpoints
