## Coolify

**Website**: https://coolify.io
**Docs**: https://coolify.io/docs
**GitHub**: https://github.com/coollabsio/coolify
**Category**: deployment
**Subcategory**: paas

### Description
Open-source, self-hosted PaaS alternative to Vercel, Netlify, and Heroku. Deploy anything on your own server with a beautiful web UI — static sites, Node.js, Python, Docker, and databases.

### Free Tier
- **Unlimited apps**: Deploy any number of apps on your own server
- **Unlimited databases**: PostgreSQL, MySQL, Redis, MongoDB
- **Self-hosted**: Completely free and open source
- **Cost**: Pay only for your VPS or server

### Paid Plan
- **Self-hosted**: Free forever
- **Coolify Cloud**: Coming soon
- **Billing**: N/A (open source)
