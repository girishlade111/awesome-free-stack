## Dokku

**Website**: https://dokku.com
**Docs**: https://dokku.com/docs
**GitHub**: https://github.com/dokku/dokku
**Category**: deployment
**Subcategory**: containers

### Description
Docker-powered mini-Heroku you can run on a $5 VPS. Heroku-compatible buildpacks, Git-based deployment, and 100+ plugins. The simplest way to self-host apps.

### Free Tier
- **Unlimited apps**: Deploy any number of apps on your own server
- **Unlimited databases**: PostgreSQL, MySQL, Redis, MongoDB
- **Self-hosted**: Completely free and open source
- **Cost**: Pay only for your VPS ($5+/month)

### Paid Plan
- **Software**: Free
- **Cost**: Pay only for your VPS or server
- **Billing**: N/A (open source)
