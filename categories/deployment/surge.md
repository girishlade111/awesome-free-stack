## Surge

**Website**: https://surge.sh
**Docs**: https://surge.sh/help
**GitHub**: https://github.com/sintaxi/surge
**Category**: deployment
**Subcategory**: serverless

### Description
Single-command static site deployment from the CLI. The simplest deployment tool — deploy any folder to a public URL with no config files needed and a free tier.

### Free Tier
- **Sites**: Unlimited static sites
- **Custom domain**: 1 domain with auto SSL via Let's Encrypt

### Paid Plan
- **Pro**: $30/month
- **Upgrades**: Custom SSL, basic auth, team collaboration
- **Billing**: Monthly subscription
