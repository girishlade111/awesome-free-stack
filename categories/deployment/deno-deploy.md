## Deno Deploy

**Website**: https://deno.com/deploy
**Docs**: https://deno.com/deploy/docs
**GitHub**: https://github.com/denoland/deploy_framework
**Category**: deployment
**Subcategory**: edge-functions

### Description
JavaScript/TypeScript edge runtime by the creators of Deno. Run serverless functions and applications at the edge with zero config, global distribution, and instant deployment.

### Free Tier
- **Requests**: 100,000/month
- **Bandwidth**: 1 GB/day
- **CPU time**: 10ms/request
- **Regions**: 34+ global regions

### Paid Plan
- **Pro**: $10/month
- **Upgrades**: 5M requests/month, 100 GB bandwidth, team features
- **Billing**: Monthly subscription
