## GitHub Pages

**Website**: https://pages.github.com
**Docs**: https://docs.github.com/pages
**GitHub**: https://github.com/github/pages-gem
**Category**: deployment
**Subcategory**: serverless

### Description
Free static site hosting directly from GitHub repositories. Perfect for project documentation, personal sites, and team pages. Built-in Jekyll support and GitHub Actions integration.

### Free Tier
- **Storage**: 1 GB
- **Bandwidth**: 100 GB/month
- **Builds**: 10/hour
- **Custom domains**: Supported with automatic SSL

### Paid Plan
- **Free with GitHub**: Enhanced limits on GitHub Pro ($4/month)
- **Billing**: Monthly subscription
