### Description
The fastest color palette generator on the web. Generate, save, export, and browse color schemes with one click. Includes accessibility contrast checking, image color extraction, and gradient generation.

### Free Tier
- **Palettes**: Unlimited generation
- **Export**: CSS, SCSS variables
- **Features**: Color blindness simulation, browse community palettes, pick from image

### Paid Plan
- **Pro**: $18/year
- **Features**: Unlimited palette saving, PDF export, Adobe/Canva integration, color history
