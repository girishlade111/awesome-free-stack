## Fontsource

**Website**: https://fontsource.org
**Docs**: https://fontsource.org/docs
**GitHub**: https://github.com/fontsource/fontsource
**Category**: design
**Subcategory**: typography

### Description
Self-host open-source fonts via npm — the privacy-first alternative to Google Fonts. 1,500+ font families as installable npm packages. Zero external requests, automatic subsetting, and TypeScript declarations.

### Free Tier
- **Fonts**: 1,500+ font families
- **Format**: WOFF2, npm packages
- **License**: Open-source (OFL, Apache, etc.)
- **Delivery**: Self-hosted via npm/bundler

### Paid Plan
- **Price**: No paid version
- **Model**: Completely free and open-source
