## Google Fonts

**Website**: https://fonts.google.com
**Docs**: https://developers.google.com/fonts
**GitHub**: https://github.com/google/fonts
**Category**: design
**Subcategory**: typography

### Description
The largest free font library on the web with 1,500+ open-source font families. All fonts are free for commercial use, optimized for web delivery via Google's global CDN, and include variable font support.

### Free Tier
- **Fonts**: 1,500+ font families
- **Format**: WOFF2, variable fonts
- **License**: Open-source (OFL, Apache, etc.), free for commercial use
- **Delivery**: Global CDN or download/self-host

### Paid Plan
- **Price**: No paid version
- **Model**: Completely free under open-source licenses
