## Excalidraw

**Website**: https://excalidraw.com
**Docs**: https://docs.excalidraw.com

**Category**: design
**Subcategory**: prototyping

### Description
Free open-source whiteboarding tool with a unique hand-drawn style. Perfect for diagrams, wireframes, flowcharts, architecture sketches, and quick UI mockups. Real-time collaboration with end-to-end encryption.

### Free Tier
- **Drawings**: Unlimited
- **Features**: Real-time collaboration, export to PNG/SVG, embeddable, dark mode, all shapes and arrows
- **Self-host**: Docker image available

### Paid Plan
- **Excalidraw+**: Coming soon — cloud storage and team features
