### Description
Industry-standard collaborative design tool for UI/UX design, prototyping, and design systems. Browser-based with real-time collaboration, component libraries, auto layout, and developer handoff with inspect mode and CSS export.

### Free Tier
- **Files**: Unlimited
- **Projects**: 3 (Figma)
- **Version history**: 30 days
- **Collaborators**: Unlimited
- **Templates**: Free community resources

### Paid Plan
- **Professional**: $12/month
- **Features**: Unlimited projects, version history, shared fonts, team libraries
