## Free Tier Details

- **Analytics**: Unlimited events, unlimited users
- **Crashlytics**: Unlimited crashes, real-time alerts
- **Cloud Messaging**: Unlimited notifications
- **Remote Config**: Unlimited configs, unlimited fetches
- **A/B Testing**: Unlimited experiments
- **App Distribution**: Unlimited testers, unlimited builds
- **Test Lab**: 10 tests/day on physical devices
- **Cloud Storage**: 5GB
- **Cloud Firestore**: 1GB stored, 10GB/month download
- **Authentication**: 50K MAUs (Identity Platform)
- **Cloud Functions**: 2M invocations/month

## Pros

- Most comprehensive mobile backend platform
- Generous free tier for most features
- Excellent documentation and tutorials
- Integrates with all Google Cloud services
- SDKs for iOS, Android, Web, Flutter, Unity

## Cons

- Vendor lock-in to Google ecosystem
- Pricing can scale quickly on Blaze plan
- Complex pricing model across products
- Limited analytics exports on free tier

## Key Features

- Real-time Analytics and audience segmentation
- Crashlytics with real-time alerts
- Cloud Messaging (push notifications)
- Firestore (NoSQL database)
- Remote Config (feature flags & A/B testing)
- App Distribution for test builds
- Dynamic Links (deep linking)

## Alternatives

- Supabase — open-source, PostgreSQL, real-time
- Appwrite — open-source, self-host or cloud
- Nhost — open-source, GraphQL-based
