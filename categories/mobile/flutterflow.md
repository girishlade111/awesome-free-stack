# FlutterFlow

> **Low-Code Flutter App Builder**

| Detail | Value |
|---|---|
| **Website** | [flutterflow.io](https://flutterflow.io) |
| **Docs** | [docs.flutterflow.io](https://docs.flutterflow.io) |
| **GitHub** | None (closed-source) |
| **Category** | mobile |
| **Subcategory** | app-builders |
| **Status** | active |
| **Free Tier** | Community plan: 2 projects, 500 API calls/mo, basic widgets, Flutter code export, web preview |
| **Student Plan** | Free Standard via GitHub Student Developer Pack |
| **Card Required** | No |

## Free Tier Details

- **Projects**: 2
- **API Calls**: 500 per month
- **Pages**: Unlimited
- **Widgets**: Basic library included
- **Export**: Clean Flutter code export
- **Preview**: Web preview only
- **Publishing**: Manual (download code + publish)
- **Custom Code**: Not available on free

## Pros

- Visual drag-and-drop Flutter builder
- Clean Flutter code export (not locked in)
- Firebase and API integration
- Great for MVPs and prototypes
- Student plan unlocks Standard for free

## Cons

- Free tier very limited (2 projects, 500 API calls)
- Custom code not available
- Advanced widgets require paid plan
- Generated code can be verbose

## Key Features

- Visual UI builder with real-time preview
- Firebase and REST API integration
- Flutter code export (clean, readable)
- App Store / Google Play publishing
- Custom widget library
- Team collaboration (paid plans)

## Alternatives

- Bubble — no-code web apps, not Flutter
- Adalo — no-code mobile, less powerful export
- Retool — internal tools, web-focused
