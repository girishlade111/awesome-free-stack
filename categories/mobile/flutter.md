## Free Tier Details

- **Apps**: Unlimited
- **Platforms**: iOS, Android, Web, Windows, macOS, Linux
- **Code**: 100% Dart, hot reload
- **Packages**: Unlimited pub.dev packages
- **Dev Tools**: Flutter DevTools included
- **License**: BSD 3-Clause

## Pros

- Hot reload for instant iteration
- Single codebase for 6 platforms
- Excellent performance (native ARM compilation)
- Strong Google backing and community
- Rich widget library with Material Design + Cupertino

## Cons

- Dart language learning curve
- Platform-specific features need channels/FFI
- Large app binary sizes compared to native
- Web support still maturing

## Key Features

- Stateless and Stateful widgets
- Material Design and Cupertino theming
- Custom painting and animations
- Platform channels for native code
- DevTools suite for debugging
- CI/CD with Codemagic/Codemagic

## Alternatives

- React Native — JavaScript-based, larger ecosystem
- Kotlin Multiplatform — native UI per platform
- SwiftUI — iOS/macOS native only
