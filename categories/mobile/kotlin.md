- **KMP**: Unlimited platform sharing

- **Libraries**: Unlimited from Maven Central

## Pros

- First-class Android support (Google recommended)
- Kotlin Multiplatform shares business logic
- Concise and expressive syntax
- Null safety built into type system
- Interoperable with Java

## Cons

- KMP doesn't share UI (native UI per platform)
- Smaller ecosystem than Flutter/RN
- iOS KMP support still evolving
- Learning curve for developers new to JVM

## Key Features

- Kotlin Multiplatform (share logic across iOS, Android, web, desktop)
- Coroutines for async/concurrent programming
- Compose Multiplatform (shared UI, experimental)
- Data classes, sealed classes, smart casts
- Full Java interop
- Ktor for networking (multiplatform)

## Alternatives

- Flutter — shared UI + logic, Dart language
- React Native — shared UI + logic, JavaScript
- Swift — iOS/macOS native only
