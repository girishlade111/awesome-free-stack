## Free Tier Details

- **Events**: 20,000,000 per month
- **MTUs**: Limited to 1,000 monthly tracked users
- **Projects**: Unlimited
- **Funnels**: Unlimited
- **Retention**: Unlimited reports
- **Flows**: Unlimited
- **Data Retention**: 5 years (full history)
- **Exports**: CSV export included
- **API**: REST API included

## Pros

- 20M events/month free — very generous
- No sampling on free tier
- 5 year data retention included
- Powerful funnel, retention, and flow analysis
- Excellent for product-led growth

## Cons

- MTU limit (1K users) on free tier
- Advanced features (formulas, predictions) paid
- Some visualization options limited
- Data modeling requires planning

## Key Features

- Event-based analytics (no sampling)
- Funnel analysis with conversion metrics
- Retention and engagement cohorts
- User flow visualization
- A/B experiment analysis
- Data exports and API access

## Alternatives

- Amplitude — similar free tier, 10M events
- PostHog — open-source, self-host option
- Heap — auto-capture, less flexibility
