## Free Tier Details

- **Framework**: Unlimited, MIT license
- **EAS Builds**: 30 builds per month
- **Updates**: 1GB OTA updates storage
- **Concurrent Builds**: 1
- **Submit**: Included on free tier
- **Development Builds**: Unlimited

## Pros

- Best DX for React Native development
- EAS Build and Submit for CI/CD
- Over-the-air updates included
- Large library of pre-built native modules
- Expo Go for instant testing on device

## Cons

- EAS free tier limited to 30 builds/month
- Some native modules require dev builds
- Bare workflow needed for custom native code
- Build queue can be slow on free tier

## Key Features

- Expo SDK with 200+ native modules
- Development builds for custom native code
- EAS Build (remote native compilation)
- EAS Submit (app store deployment)
- Expo Updates (OTA updates)
- Expo Go (quick testing sandbox)

## Alternatives

- React Native CLI — full control, no build service
- Flutter — different ecosystem, Dart language
- Capacitor — web-first mobile framework
