## Free Tier Details

- **Apps**: Unlimited
- **Platforms**: iOS, Android
- **Code**: JavaScript/TypeScript + React
- **Packages**: Unlimited npm packages
- **Dev Tools**: React DevTools, Flipper
- **License**: MIT

## Pros

- Largest mobile ecosystem and community
- JavaScript/TypeScript — familiar to most web devs
- Huge selection of third-party libraries
- Hot reloading for development
- Expo simplifies the experience

## Cons

- Bridge architecture impacts performance
- Native modules require native code knowledge
- Larger app size than native
- Navigation and state management require third-party choices

## Key Features

- React component model for mobile
- JavaScript to native bridge
- Virtual DOM for efficient rendering
- React DevTools debugging
- Hermes engine (JS-to-bytecode compiler)
- Fabric (new architecture, concurrent mode)
- TurboModules (native modules, new arch)

## Alternatives

- Flutter — Dart-based, better performance, growing fast
- Expo — managed RN, easier DX, OTA updates
- Kotlin Multiplatform — native UI, shared logic
