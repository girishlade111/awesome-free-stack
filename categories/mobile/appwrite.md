- **Database Writes**: 100,000 per month

- **Storage**: 5GB
- **Functions**: 20,000 executions per month
- **Push Notifications**: 50,000 per month
- **Emails**: 500 per month
- **SMS**: 50 per month

## Pros

- Open-source (MIT) — self-host or use cloud
- Generous free tier with clear limits
- Excellent developer experience and docs
- Supports multiple platforms (iOS, Android, Web, Flutter)
- Active community and Discord

## Cons

- Smaller ecosystem than Firebase
- Cloud is newer, some latency concerns
- Self-hosting requires infrastructure knowledge
- Fewer third-party integrations

## Key Features

- Authentication (email, OAuth, magic links, SMS)
- NoSQL database with real-time subscriptions
- File storage with image transformations
- Cloud Functions (Node.js, Python, Dart, Ruby, PHP)
- Push notifications and email/SMS messaging
- GraphQL API alongside REST

## Alternatives

- Firebase — proprietary, larger ecosystem, Google-backed
- Supabase — PostgreSQL-based, real-time
- Nhost — GraphQL-based, PostgreSQL
