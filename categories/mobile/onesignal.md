## Free Tier Details

- **Subscribers**: 10,000 (unlimited sends to them)
- **Push**: iOS, Android, Web Push, Huawei
- **Email**: 10,000 emails per month
- **SMS**: Not included
- **In-App**: Unlimited in-app messages
- **Segmentation**: Basic
- **A/B Testing**: Basic included
- **Data Retention**: 60 days

## Pros

- 10K subscribers for free with unlimited sends
- Covers all push channels (iOS, Android, Web)
- Easy setup with SDKs for all platforms
- Email and in-app included
- Intuitive dashboard and analytics

## Cons

- SMS and advanced segmentation require Growth
- Data retention limited to 60 days on free
- Support on free tier is community-based
- Some advanced features cost extra

## Key Features

- Push notifications for iOS, Android, Web, Huawei
- Email messaging and templates
- In-app messaging
- Audience segmentation
- A/B testing on messages
- Automated delivery (drip campaigns)

## Alternatives

- Firebase Cloud Messaging — free, less features
- Pusher Beams — simpler, smaller free tier
- Airbridge — attribution + push
