## Free Tier Details

- **Attributed Events**: 10,000 per month
- **Deep Links**: Unlimited creation
- **Platforms**: iOS (Universal Links), Android (App Links)
- **Analytics**: Basic dashboard
- **SDKs**: iOS, Android, React Native, Flutter, Unity, Web
- **Journeys**: Basic included
- **Data Retention**: 30 days

## Pros

- Industry standard for mobile deep linking
- Generous 10K free attributed events
- Works across installs, re-engagements, web-to-app
- Comprehensive SDK support
- Student plan unlocks Growth features

## Cons

- Advanced attribution and multi-touch paid only
- Data retention only 30 days on free
- Complex setup for advanced use cases
- Free tier attribution limited

## Key Features

- Universal Links and App Links
- Deferred deep linking (post-install)
- Attribution and campaign measurement
- Branch Journeys (visual marketing)
- QR codes and short links
- Web-to-app links

## Alternatives

- Adjust — enterprise attribution, paid
- AppsFlyer — enterprise, comprehensive
- Firebase Dynamic Links — free, being deprecated
