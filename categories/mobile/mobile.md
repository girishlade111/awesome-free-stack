# Mobile Development

Curated collection of free mobile SDKs, backend platforms, push notification services, app builders, and analytics tools.

## Quick Comparison

| Tool | Type | Free Limit | Open Source | Card? |
|---|---|---|---|---|
| **Flutter** | Mobile SDK | Unlimited (fully free) | ✅ | No |
| **Expo** | Mobile SDK | Unlimited + EAS (30 builds/mo) | ✅ | No |
| **Kotlin** | Mobile SDK | Unlimited (fully free) | ✅ | No |

## Selection Guide

- **Best cross-platform SDK**: Flutter — fastest growing, hot reload, single codebase for all platforms
- **Best for React devs**: React Native — largest ecosystem, huge community, Expo simplifies everything
- **Best mobile backend**: Firebase — most comprehensive free tier, best documentation
- **Best open-source backend**: Appwrite — self-host or cloud, generous free tier, MIT license
- **Best push notifications**: OneSignal — 10K free subscribers, all channels included
- **Best low-code mobile app builder**: FlutterFlow — visual Flutter builder with real code export
- **Best deep linking**: Branch — industry standard, generous 10K free events
- **Best app analytics**: Mixpanel — 20M free events, no sampling, 5 year retention
- **Best for Android-native**: Kotlin — modern, concise, 100% compatible with Java ecosystem
- **Best for production apps**: Expo — managed builds, OTA updates, extensive libraries

> **Note**: Flutter, React Native, and Kotlin are 100% free with no paid tiers — they're open-source frameworks, not services. Firebase Spark plan requires no credit card but some features automatically upgrade to paid Blaze plan for certain services. OneSignal's 10K limit is on subscribers (not sends), making it very generous.
