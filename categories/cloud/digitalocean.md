## DigitalOcean

**Website**: https://www.digitalocean.com
**Docs**: https://docs.digitalocean.com
**GitHub**: https://github.com/digitalocean
**Category**: cloud
**Subcategory**: compute

### Description
Developer-friendly cloud platform focused on simplicity. Known for intuitive dashboard, predictable pricing, and excellent documentation. $200 free credits for 60 days.

### Free Tier
- **Credits**: $200 for 60 days (new accounts)
- **Can run**: A basic droplet for months with $200
- **Tier type**: No always-free tier, generous trial credits

### Paid Plan
- **Basic Droplet**: $4/month (512MB, 1vCPU, 25GB SSD)
- **Kubernetes**: $12/month
- **Managed Database**: $15/month
- **Billing**: Hourly/monthly subscription
