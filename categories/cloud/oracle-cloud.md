## Oracle Cloud

**Website**: https://www.oracle.com/cloud
**Docs**: https://docs.oracle.com/en/cloud
**GitHub**: https://github.com/oracle
**Category**: cloud
**Subcategory**: compute

### Description
Best always-free tier in the industry — 2 AMD VMs + 4 ARM VMs (up to 24GB RAM) forever. Strong in enterprise databases, autonomous DB, and cloud ERP.

### Free Tier
- **Compute**: 2 AMD instances (1GB ea) + 4 ARM instances (24GB total)
- **Storage**: 200GB block + 10GB object storage
- **Database**: 10GB autonomous database
- **Bandwidth**: 10TB egress/month
- **Tier type**: Always free (no time limit)

### Paid Plan
- **Starting at**: $0.0125/h (VM)
- **Universal credits**: Flexible pricing
- **BYOL**: Bring your own license
- **Billing**: Usage-based per hour
