## Microsoft Azure

**Website**: https://azure.microsoft.com
**Docs**: https://learn.microsoft.com/azure
**GitHub**: https://github.com/Azure
**Category**: cloud
**Subcategory**: compute

### Description
Microsoft's cloud platform with deep enterprise and hybrid cloud capabilities. Best-in-class integration with Active Directory, Visual Studio, and .NET ecosystem. $200 free credits for new users.

### Free Tier
- **Trial**: $200 credit for 30 days
- **Compute**: 750h/mo B1s VM
- **Storage**: 5GB blob storage + 64GB files
- **Serverless**: 1M functions/month
- **Database**: 250GB SQL Database
- **Tier type**: Trial + always-free services

### Paid Plan
- **Starting at**: $0.005/h (B1s VM)
- **Reserved instances**: Up to 72% discount
- **Hybrid benefit**: Use existing on-prem licenses
- **Billing**: Usage-based per minute
