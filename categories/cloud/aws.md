## AWS (Amazon Web Services)

**Website**: https://aws.amazon.com
**Docs**: https://docs.aws.amazon.com
**GitHub**: https://github.com/aws
**Category**: cloud
**Subcategory**: compute

### Description
The largest public cloud platform with 200+ services spanning compute, storage, databases, AI/ML, serverless, and IoT. Generous 12-month free tier with 100+ always-free offers.

### Free Tier
- **Compute**: 750h/mo EC2 (t2.micro) for 12 months
- **Storage**: 5GB S3 + 20GB EBS
- **Serverless**: 1M Lambda requests/month
- **Database**: 25GB DynamoDB always free
- **Email**: 62K SES emails/month
- **Tier type**: 12-month trial + 100+ always-free services

### Paid Plan
- **Starting at**: $0.0058/h (t2.nano EC2)
- **Reserved instances**: Up to 72% discount
- **Savings plans**: Flexible pricing across services
- **Billing**: Usage-based per hour/second
