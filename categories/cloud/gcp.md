## Google Cloud Platform

**Website**: https://cloud.google.com
**Docs**: https://cloud.google.com/docs

### Description
Google's cloud platform excelling in data analytics, ML/AI, and Kubernetes. $300 free credits for 90 days with generous always-free tier. Home to BigQuery, Vertex AI, and GKE.

### Free Tier
- **Trial**: $300 credit for 90 days
- **Compute**: 1 f1-micro VM (US regions)
- **Storage**: 5GB cloud storage
- **Serverless**: 1M Cloud Functions/month
- **Data**: 1GB BigQuery/month, 60min Speech API
- **Tier type**: Trial + always-free services

### Paid Plan
- **Starting at**: $0.0076/h (f1-micro)
- **Committed use**: Up to 57% discount
- **Sustained use**: Automatic discounts
- **Billing**: Usage-based per second
