## IBM Cloud

**Website**: https://cloud.ibm.com
**Docs**: https://cloud.ibm.com/docs

### Description
Enterprise-focused cloud platform with strengths in AI (Watson), quantum computing, and regulated industries. $200 free credits for new users and generous free tier for AI services.

### Free Tier
- **Trial**: $200 credit for 30 days
- **Compute**: 1 VM (128MB, 1vCPU)
- **Storage**: 5GB COS (Cloud Object Storage)
- **Serverless**: 1M Code Engine requests/month
- **AI**: 10K Watson Assistant API calls/month
- **Tier type**: Trial + always-free services

### Paid Plan
- **Starting at**: $0.012/h (VM)
- **Reserved instances**: Subscription pricing available
- **Billing**: Usage-based per hour
