## Supabase Storage

**Website**: https://supabase.com/storage
**Docs**: https://supabase.com/docs/guides/storage
**GitHub**: https://github.com/supabase/storage
**Category**: storage
**Subcategory**: object-storage

### Description
S3-compatible object storage tightly integrated with Supabase PostgreSQL. Secure file uploads with built-in image resizing, CDN delivery, and row-level security policies.

### Free Tier
- **Storage**: 1 GB
- **File size**: 50 MB max
- **MAU**: 50K
- **Bandwidth**: 2 GB
- **Features**: Image optimization, CDN, RLS policies

### Paid Plan
- **Pro**: $25/month
- **Storage**: 100 GB
- **File size**: 5 GB
- **MAU**: 100K
- **Bandwidth**: 50 GB
