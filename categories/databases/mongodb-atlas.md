## MongoDB Atlas

**Website**: https://www.mongodb.com/atlas
**Docs**: https://www.mongodb.com/docs/atlas
**GitHub**: https://github.com/mongodb
**Category**: databases
**Subcategory**: nosql

### Description
Fully managed MongoDB on AWS, Azure, and GCP. Free M0 cluster with 512MB storage. Industry-leading document database with flexible schema, aggregation pipeline, and change streams.

### Free Tier
- **Cluster**: M0 (shared RAM)
- **Storage**: 512 MB
- **Backup**: Not included
- **Multi-region**: Not supported

### Paid Plan
- **M2**: $9/month (2 GB, dedicated RAM, backups)
- **M10**: $57/month (10 GB, production grade)
- **Serverless**: Pay-as-you-go
