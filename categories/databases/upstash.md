## Upstash

**Website**: https://upstash.com
**Docs**: https://upstash.com/docs
**GitHub**: https://github.com/upstash
**Category**: databases
**Subcategory**: caching

### Description
Serverless Redis and Kafka platform designed for modern applications. REST API access to Redis without managing infrastructure. Ideal for caching, rate limiting, and session storage at the edge.

### Free Tier
- **Redis**: 10K commands/day, 50 MB storage
- **Kafka**: 10K messages/day, 50 MB storage
- **Number of databases**: 1

### Paid Plan
- **Redis**: Pay-as-you-go from $0.10/GB
- **Kafka**: From $0.50/GB messages
- **Global database**: Multi-region replication
