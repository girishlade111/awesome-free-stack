## Supabase

**Website**: https://supabase.com
**Docs**: https://supabase.com/docs
**GitHub**: https://github.com/supabase/supabase
**Category**: databases
**Subcategory**: backend-platform

### Description
Open-source Firebase alternative. Provides PostgreSQL database, authentication, real-time subscriptions, storage, and Edge Functions in a single platform with a generous free tier.

### Free Tier
- **Database**: 500 MB PostgreSQL
- **Storage**: 2 GB file storage
- **File size limit**: 50 MB per file
- **Auth**: 50,000 monthly active users
- **Bandwidth**: 2 GB/month
- **Edge Functions**: 500K invocations/month

### Paid Plan
- **Pro**: $25/month
- **Upgrades**: 8 GB database, 100 GB storage, 100,000 MAUs
- **Billing**: Monthly subscription
