## Amazon DynamoDB

**Website**: https://aws.amazon.com/dynamodb
**Docs**: https://docs.aws.amazon.com/dynamodb
**GitHub**: https://github.com/aws/aws-sdk-js-v3
**Category**: databases
**Subcategory**: nosql

### Description
Fully managed NoSQL key-value and document database from AWS. Single-digit millisecond performance at any scale with on-demand capacity mode and ACID transactions.

### Free Tier
- **Storage**: 25 GB
- **Requests**: 200 million/month
- **Throughput**: 25 WCU and 25 RCU
- **Streams**: 25 GB
- **DAX cache**: 1 GB

### Paid Plan
- **On-demand**: Pay-per-request
- **Writes**: $1.25 per WCU/month
- **Reads**: $0.25 per RCU/month
- **Storage**: $0.25/GB/month
