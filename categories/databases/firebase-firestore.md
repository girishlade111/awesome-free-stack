## Firebase Firestore

**Website**: https://firebase.google.com/products/firestore
**Docs**: https://firebase.google.com/docs/firestore
**GitHub**: https://github.com/firebase
**Category**: databases
**Subcategory**: nosql

### Description
Google's flexible, scalable NoSQL document database for mobile and web apps. Real-time sync, offline support, and deep integration with Firebase and Google Cloud ecosystem.

### Free Tier
- **Storage**: 1 GB
- **Reads**: 50K document reads/day
- **Writes**: 20K/day
- **Deletes**: 20K/day
- **Bandwidth**: 10 GB/month
- **Network egress**: 1 GB/day

### Paid Plan
- **Blaze**: Pay-as-you-go
- **Storage**: $0.108/GB
- **Reads**: $0.06/100K
- **Writes**: $0.18/100K
