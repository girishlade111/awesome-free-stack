## Gluu Server

**Website**: https://gluu.org
**Docs**: https://gluu.org/docs/gluu-server/
**GitHub**: https://github.com/GluuFederation/gluu-server
**Category**: auth
**Subcategory**: sso

### Description
Open-source identity and access management platform. Supports OAuth 2.0, OIDC, SAML 2.0, UMA 2.0, FIDO 2.0, and WebAuthn. Provides certificate authentication, SCIM, and a no-code admin UI for policy configuration.

### Free Tier
- Free CE (Community Edition) version with unlimited users and all standard features
- Self-hosted on any Linux server.

### Paid Plan
- **Starting Price**: $15000/month
- Enterprise subscription with support from $15,000/year for production deployments.
