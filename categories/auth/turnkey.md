## Turnkey

**Website**: https://turnkey.com
**Docs**: https://docs.turnkey.com
**GitHub**: https://github.com/tkhq
**Category**: auth
**Subcategory**: passwordless

### Description
Passkey infrastructure for consumer authentication. Provides secure key management with hardware-level passkey storage. Designed for apps requiring passkey-first auth with multi-device support and recovery flows.

### Free Tier
- Free tier: up to 1K passkeys, unlimited verifications, community support
- All API features included.

### Paid Plan
- **Starting Price**: $99/month
- Scale plan from $99/month for 10K passkeys. Enterprise with dedicated HSM, SLA, and compliance.
