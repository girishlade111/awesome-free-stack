### Description
Google Zanzibar-inspired fine-grained authorization system. Open-source with high-performance, low-latency relationship-based access control. Supports ReBAC with graph-based authorization model. REST API and SDKs.
### Free Tier
- Free self-hosted open-source version
- Auth0 FGA free tier: 100 stores, read/write/check operations
- Self-hosted has no limits.
### Paid Plan
- **Starting Price**: $10/month
- Auth0 FGA: from $10/month for 250K operations. Dedicated instances available for enterprise.
