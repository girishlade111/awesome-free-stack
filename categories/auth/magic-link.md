## Magic.link

**Website**: https://magic.link
**Docs**: https://magic.link/docs
**GitHub**: https://github.com/magiclabs
**Category**: auth
**Subcategory**: passwordless

### Description
Passwordless authentication service using magic links and OTP. Provides email and SMS-based authentication with decentralized identity (DID) support. SDKs for web and mobile with built-in session management.

### Free Tier
- Free tier: 10K users, 100K transactions/month, email and SMS authentication
- Community support on Discord.

### Paid Plan
- **Starting Price**: $175/month
- Pro from $175/month for 50K users. Enterprise with dedicated support, custom domains, and compliance.
