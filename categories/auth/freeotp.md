## FreeOTP

**Website**: https://freeotp.github.io

### Description
Open-source TOTP and HOTP authenticator app by Red Hat. Supports time-based and counter-based one-time passwords with QR code scanning. No network permissions required. Lightweight, focused, and privacy-respecting.

### Free Tier
- Completely free open-source app
- No ads, no tracking, no in-app purchases
- All TOTP/HOTP features included.
