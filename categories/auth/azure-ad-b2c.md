## Azure AD B2C

**Website**: https://azure.microsoft.com/en-us/services/active-directory-b2c/
**Docs**: https://learn.microsoft.com/en-us/azure/active-directory-b2c/
**Category**: auth
**Subcategory**: social-login

### Description
Microsoft Azure customer identity with social login. Supports Google, Apple, Facebook, Amazon, and any OAuth/OIDC provider. Features custom policies, MFA, and conditional access. Free tier with monthly active user limits.

### Free Tier
- Free tier: 50K monthly active users with social/enterprise identity providers
- Includes authentication, MFA, and token management.

### Paid Plan
- **Starting Price**: N/A
- Pay-as-you-go: $0.033 per MAU beyond free tier. First 50K MAU per month free. No upfront costs.
