## Passwordless.dev
**Website**: https://passwordless.dev
**Docs**: https://docs.passwordless.dev
**GitHub**: https://github.com/bitwarden/passwordless-server
**Category**: auth
**Subcategory**: passwordless
### Description
FIDO2 WebAuthn service by Bitwarden for adding passkeys to applications. Supports biometrics, platform authenticators, and security keys. Provides APIs and SDKs with flexible deployment options including self-hosted.
### Free Tier
- Free tier: 100 users, 10K passkey registrations/month, email support
- Community and open-source self-hosted option available.
### Paid Plan
- **Starting Price**: $67/month
- Pro from $67/month for 1K users. Enterprise with custom limits, SLA, and dedicated infrastructure.
