### Description
Okta free developer tier for building SSO, MFA, and user management into applications. Supports OAuth 2.0, OIDC, SAML, social login, and Lifecycle Management. Includes 25,000 monthly active users in the free tier.

### Free Tier
- Developer tier: 25,000 MAU, unlimited apps and social providers
- Includes MFA, rate limits: 100K API calls/month.

### Paid Plan
- **Starting Price**: $2/month
- Plans start at $2/user/month. Enterprise: custom pricing with advanced security and support.
