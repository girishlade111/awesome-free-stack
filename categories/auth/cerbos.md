### Description
Open-source, decoupled access control for applications. Uses YAML-based policy definitions for RBAC, ABAC, and derived roles. Lightweight with gRPC and REST APIs. Designed for cloud-native deployments with high performance.
### Free Tier
- Free Community Edition: self-hosted with unlimited policies and users
- All API features and SDKs included.
### Paid Plan
- **Starting Price**: $25/month
- Cerbos Cloud Free Tier: 10K/month checks. Pro from $25/month for 100K checks. Enterprise with custom limits.
