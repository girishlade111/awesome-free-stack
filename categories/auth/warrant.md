### Description
Open-source authorization-as-a-service platform. Supports RBAC, ABAC, and relationship-based access control with a simple API. Low-latency authorization checks with SDKs for JavaScript, Python, Go, Java, and Rust.
### Free Tier
- Cloud Free tier: 1M authorizations/month, 1K users, unlimited policies
- Self-hosted open-source version has no limits.
### Paid Plan
- **Starting Price**: $99/month
- Scale plan from $99/month for 5M authorizations. Enterprise with dedicated support and SLA.
