## LinOTP
**Website**: https://www.linotp.org
**Docs**: https://linotp-doc.readthedocs.io
**GitHub**: https://github.com/LINOTP-Project/linotp
**Category**: auth
**Subcategory**: mfa
### Description
Open-source MFA server with support for TOTP, HOTP, SMS, email, YubiKey, and Push authentication. Centralized management with user self-service, policy enforcement, and RADIUS integration. Python-based with REST API.
### Free Tier
- Completely free community edition under AGPLv3
- Unlimited users and authentication methods
- Self-hosted with full REST API.
