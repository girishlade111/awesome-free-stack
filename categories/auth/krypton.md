### Description
Passwordless authentication using FIDO2 and WebAuthn with a mobile app as authenticator. Supports SSH, PGP, and web authentication via NFC and QR pairing. Aims to replace hardware security keys with mobile devices.
### Free Tier
- Free for individual use with unlimited personal keys
- Supports SSH, WebAuthn, and PGP authentication
- Open-source mobile apps.
### Paid Plan
- **Starting Price**: $5/month
- Krypton Team: $5/user/month with team management, SSO, and audit logs.
