## Casbin
**Website**: https://casbin.org
**Docs**: https://casbin.org/docs
**GitHub**: https://github.com/casbin/casbin
**Category**: auth
**Subcategory**: authorization
### Description
Open-source access control library supporting ACL, RBAC, ABAC, and custom permission models. Available in Go, Java, Node.js, Python, PHP, .NET, Rust, and more. Uses a configuration file-based policy model without custom DSL.
### Free Tier
- Completely free under Apache 2.0 license
- Unlimited policies, users, and models
- All language implementations included.
### Paid Plan
- **Starting Price**: N/A
- Casbin Cloud and enterprise support available. Self-hosted version remains free.
