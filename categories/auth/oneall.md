## OneAll
**Website**: https://www.oneall.com
**Docs**: https://docs.oneall.com
**GitHub**: https://github.com/OneAll
**Category**: auth

### Description
Social login and user identity API with 50+ OAuth provider integrations. Centralized management for social network login, share buttons, and user profiles. Free tier for small projects with generous monthly limits.
### Free Tier
- Free tier: 10K users, 100K API calls/month, unlimited social providers
- Includes user profiles and social network data.
### Paid Plan
- **Starting Price**: $99/month
- Pro from $99/month for 50K users and 1M API calls. Enterprise with custom limits and dedicated support.
