### Description
Open-source identity provider with SSO, MFA, LDAP, and proxy integration. Features a no-code policy engine, application library, and flexible providers including OAuth 2.0, OIDC, SAML, and LDAP outposts.
### Free Tier
- Completely free self-hosted version with all features
- No user limits, no feature restrictions
- Community support via Discord and GitHub.
