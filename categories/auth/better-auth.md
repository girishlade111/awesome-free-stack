**Website**: https://better-auth.com

### Description
Open-source TypeScript-first authentication framework. Pluggable, framework-agnostic (React, Vue, Svelte, Next.js), and fully self-hostable. The modern auth library for the JS ecosystem.

### Free Tier
- **Open-source**: Completely free with unlimited users, unlimited apps, all features
- **Self-hosted**: No limits, no restrictions
