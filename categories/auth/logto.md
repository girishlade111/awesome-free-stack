## Logto

**Website**: https://logto.io
**Docs**: https://docs.logto.io
**GitHub**: https://github.com/logto-io/logto
**Category**: auth
**Subcategory**: authentication

### Description
Open-source identity platform with pre-built sign-in experiences, user management, and social login. Self-host for full control or use Logto Cloud for managed auth.

### Free Tier
- **Cloud**: 50K MAU, all social providers, pre-built UI, user management panel
- **Self-host**: Unlimited, completely free

### Paid Plan
- **Pro Cloud**: $199/month
- **Features**: Unlimited MAU, SAML/SSO, audit logs, priority support
