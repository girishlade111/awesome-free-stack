## Supabase Auth

**Website**: https://supabase.com/auth
**Docs**: https://supabase.com/docs/guides/auth

### Description
Authentication built into Supabase PostgreSQL platform. Email/password, OAuth, magic link, phone auth, and anonymous sign-in — all with row-level security integration.
