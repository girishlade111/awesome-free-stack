## AWS Cognito
**Website**: https://aws.amazon.com/cognito/
**Docs**: https://docs.aws.amazon.com/cognito/
**Category**: auth
**Subcategory**: social-login
### Description
AWS identity platform with social login via Cognito Hosted UI. Supports Google, Apple, Facebook, Amazon, and SAML/OIDC federation. Includes user pools, identity pools, and multi-factor authentication with a generous free tier.
### Free Tier
- Free tier: 50K MAU for social login, 50GB/month data sync, unlimited federation
- Pay only for MAU beyond free limits.
### Paid Plan
- **Starting Price**: N/A
- Pay-as-you-go: $0.015 per MAU for social login beyond free tier. No upfront costs, usage-based pricing.
