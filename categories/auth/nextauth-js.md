## NextAuth.js (Auth.js)

**Website**: https://authjs.dev
**Docs**: https://authjs.dev/getting-started
**GitHub**: https://github.com/nextauthjs/next-auth
**Category**: auth
**Subcategory**: authentication

### Description
Open-source authentication for Next.js — now framework-agnostic as Auth.js. 80+ built-in OAuth providers, database adapters, JWT sessions, and middleware-based protection.

### Free Tier
- **Open-source**: Completely free with unlimited users, any database, 80+ providers
- **Self-hosted**: No limits, no restrictions

### Paid Plan
- **Self-hosted**: Free forever
- **Auth.js Cloud**: Coming soon
