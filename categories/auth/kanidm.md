## Kanidm
**Website**: https://kanidm.com

### Description
Open-source identity and authorization platform written in Rust. Features fine-grained RBAC, OAuth 2.0, OIDC, WebAuthn, and SSH key management. Designed as a modern, secure alternative to LDAP with REST APIs.
### Free Tier
- Completely free under MPL-2.0 license
- Self-hosted with unlimited users and groups
- All features included with no paid tier.
