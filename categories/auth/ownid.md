## OwnID
**Website**: https://www.ownid.com
**Docs**: https://docs.ownid.com
**GitHub**: https://github.com/ownid
**Category**: auth
**Subcategory**: passwordless
### Description
Passwordless authentication solution using passkeys with biometric authentication. Integrates as a drop-in replacement for existing login forms. Supports FIDO2 WebAuthn, QR-based cross-device auth, and email fallback.
### Free Tier
- Free tier: unlimited users and auth requests on shared infrastructure
