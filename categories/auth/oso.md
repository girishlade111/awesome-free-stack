### Description
Open-source authorization library with declarative Polar policy language. Embeds into applications for fine-grained RBAC and ABAC. Supports Python, Node.js, Go, Java, and Ruby. Free self-hosted community edition.

### Free Tier
- Free self-hosted community edition with unlimited policies and users
- All language SDKs included
- Community support via Slack and GitHub.

### Paid Plan
- **Starting Price**: $4500/month
- Oso Cloud from $4,500/year for up to 10M API calls. Enterprise with SSO, audit logs, and dedicated support available.
