## Hanko
**Website**: https://www.hanko.io
**Docs**: https://docs.hanko.io
**GitHub**: https://github.com/teamhanko/hanko
**Category**: auth
**Subcategory**: passwordless
### Description
Open-source passwordless authentication with passkeys and WebAuthn. Provides a pre-built login component, Go backend, and APIs for custom integrations. Supports biometric (Face ID, Touch ID), security keys, and cross-device authentication.
### Free Tier
- Self-hosted open-source version is completely free
- Cloud free tier: 5K MAU, all features, community support.
### Paid Plan
- **Starting Price**: $199/month
- Cloud Pro from $199/month for 25K MAU. Enterprise with custom limits, SLA, and dedicated support.
