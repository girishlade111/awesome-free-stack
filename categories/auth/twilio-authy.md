## Twilio Authy

**Website**: https://www.twilio.com/authy
**Docs**: https://www.twilio.com/docs/authy
**GitHub**: https://github.com/twilio
**Category**: auth
**Subcategory**: mfa

### Description
Twilio's 2FA service with push authentication, TOTP, SMS, voice, and hardware token support. Provides SDKs for web and mobile with encrypted backup and multi-device sync. Generous free tier for developers.

### Free Tier
- Free tier: unlimited push authentications, 10 SMS/voice verifications per day
- Unlimited applications and users for push 2FA.

### Paid Plan
- **Starting Price**: N/A
- Usage-based pricing from $0.045 per verification (SMS), $0.10 per phone call. Enterprise plans available with dedicated support.
