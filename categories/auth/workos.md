### Description
Enterprise SSO, directory sync, and SCIM API platform. Provides a unified interface for Okta, Azure AD, OneLogin, Google Workspace, and 400+ identity providers. Free tier for development and small deployments.
### Free Tier
- Free Starter plan: unlimited developer accounts, 1 production connection, community support
- All features included for development.
### Paid Plan
- **Starting Price**: $99/month
- Scale plan at $99/month per connection. Enterprise plan with dedicated support and SLA available.
