### Description
Passwordless-first authentication API platform. Supports email magic links, OTP via SMS/email/WhatsApp, WebAuthn/passkeys, OAuth social login, and crypto wallets. Free tier includes 10K MAU with all auth methods.
### Free Tier
- Free Developer tier: 10K monthly active users, unlimited projects, all auth methods (magic links, OTP, passkeys, OAuth)
- No credit card required.
