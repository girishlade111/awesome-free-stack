## Open Policy Agent (OPA)

**Website**: https://www.openpolicyagent.org
**Docs**: https://www.openpolicyagent.org/docs
**GitHub**: https://github.com/open-policy-agent/opa

### Description
Open-source general-purpose policy engine using Rego policy language. Used for authorization across microservices, Kubernetes, CI/CD, and API gateways. CNCF-graduated project with broad integration and community support.
