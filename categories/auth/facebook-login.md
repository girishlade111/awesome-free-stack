## Facebook Login

**Website**: https://developers.facebook.com/docs/facebook-login/
**Docs**: https://developers.facebook.com/docs/facebook-login/overview
**Category**: auth
**Subcategory**: social-login

### Description
Facebook's social login OAuth service for web, mobile, and TV apps. Provides user profile data, friend lists, and sharing capabilities with granular permissions. One of the most widely adopted social login providers globally.

### Free Tier
- Completely free for app authentication and basic profile data
- No usage limits
- Requires Facebook App review for extended permissions.
