## Authelia
**Website**: https://www.authelia.com
**Docs**: https://www.authelia.com/docs
**GitHub**: https://github.com/authelia/authelia
**Category**: auth
**Subcategory**: sso
### Description
Open-source authentication and authorization server for self-hosted environments. Acts as a companion to reverse proxies like nginx, Traefik, and Caddy. Supports 2FA, LDAP, OIDC, and access control rules.
### Free Tier
- Completely free under Apache 2.0 license
- Self-hosted with unlimited users and authentication policies.
