## Cloudflare DNS

**Website**: https://www.cloudflare.com/dns
**Docs**: https://developers.cloudflare.com/dns
**GitHub**: https://github.com/cloudflare
**Category**: domains
**Subcategory**: dns-management

### Description
World's fastest authoritative DNS provider with built-in DDoS protection, DNSSEC, and global CDN integration. Manage DNS for any domain with instant propagation across 330+ data centers.

### Free Tier
- **Unlimited zones**: No limit on domains
- **Unlimited records**: No limit on DNS records
- **DNSSEC**: Included
- **DDoS protection**: Included
- **Analytics**: Basic analytics included
- **Email routing**: Free email forwarding

### Paid Plan
- **Pro**: $200/month
- **Features**: Advanced DDoS, WAF, custom SSL certificates
