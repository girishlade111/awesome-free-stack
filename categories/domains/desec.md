## deSEC

**Website**: https://desec.io
**Docs**: https://desec.readthedocs.io
**GitHub**: https://github.com/desec-io/desec-stack
**Category**: domains
**Subcategory**: dns-management

### Description
Free, open-source DNS hosting service with DNSSEC, dynamic DNS, and full REST API. Privacy-focused and hosted in Germany (GDPR compliant). Supports TSIG authenticated updates and multi-user access.

### Free Tier
- **DNS zones**: Unlimited
- **DNS records**: Unlimited
- **DNSSEC**: Automatic signing
- **Dynamic DNS**: Built-in with API
- **Users**: Multi-user access
- **Tokens**: API token authentication

### Paid Plan
- **Price**: No paid version
- **Model**: Donation-supported
