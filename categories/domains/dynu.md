### Description
Free dynamic DNS provider with custom subdomains and support for custom domains. Free DNS hosting with all record types (A, AAAA, CNAME, MX, TXT). No renewal confirmation required on the free tier.

### Free Tier
- **Subdomains**: 5 free (yourusername.dynu.com)
- **Records**: A, AAAA, CNAME, MX, TXT, NS, SRV
- **Updates**: Dynamic DNS via API or client
- **Renewal**: No confirmation needed

### Paid Plan
- **Premium**: $19.95/year
- **Features**: 25 subdomains, premium domains, priority support
