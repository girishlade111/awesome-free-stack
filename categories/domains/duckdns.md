## Duck DNS

**Website**: https://www.duckdns.org
**Docs**: https://www.duckdns.org/faqs.jsp
**GitHub**: https://github.com/Raging-Ray/DuckDNS
**Category**: domains
**Subcategory**: dynamic-dns

### Description
Free dynamic DNS service hosted on AWS infrastructure. Get a *.duckdns.org subdomain that automatically updates when your IP changes. Simple, reliable, and supported by donations.

### Free Tier
- **Subdomains**: 5 domains of your choice
- **Updates**: Unlimited via API or client
- **Renewal**: None — no confirmation needed
- **Forever**: Completely free forever

### Paid Plan
- **Price**: No paid version
- **Model**: Supported by donations
