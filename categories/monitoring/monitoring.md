# Free Monitoring & Observability Tools

Curated collection of free monitoring, observability, and alerting platforms.

## Quick Comparison

| Provider | Type | Free Tier | Card? | Student Benefits |
|---|---|---|---|---|
| **Sentry** | Error Tracking | 5K errors/mo, 5K traces | No | ✅ GitHub Pack |
| **Datadog** | Full Observability | 10 hosts, 5M logs/mo | Yes | ✅ 2yr Pro |
| **Grafana** | Metrics + Dashboards | 10K series, 50GB logs | No | ✅ GitHub Pack |
| **BetterStack** | Uptime Monitoring | 10 monitors, 1 status page | No | No |
| **Logtail** | Log Management | 1 GB/day, 7 day retention | No | No |

## Selection Guide

- **Error tracking**: Sentry — industry standard, every SDK imaginable
- **Full observability**: Grafana Cloud (best free tier), Datadog (most powerful)
- **Uptime + status pages**: BetterStack — beautiful status pages in minutes
- **Log management**: Logtail — SQL-powered, live tail, generous free tier
- **APM + traces**: Grafana Tempo or Datadog APM
