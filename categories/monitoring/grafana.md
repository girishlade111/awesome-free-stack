## Grafana

**Website**: https://grafana.com
**Docs**: https://grafana.com/docs/grafana
**GitHub**: https://github.com/grafana/grafana
**Category**: monitoring
**Subcategory**: apm

### Description
The leading open-source observability platform for metrics, logs, and traces. Create beautiful dashboards, set alerts, and query data from 100+ sources. Self-host or use Grafana Cloud with Prometheus, Loki, and Tempo.

### Free Tier
- **Metrics**: 10K series Prometheus
- **Logs**: 50GB (Loki)
- **Traces**: 50GB (Tempo)
- **Retention**: 14 days
- **Self-host**: Unlimited, forever free

### Paid Plan
- **Pro**: $49/month
- **Features**: 100K series, 200GB logs, 30 day retention, team collaboration
