## Free Tier Details

- **Courses**: All course basic lessons available
- **Exercises**: Interactive in-browser coding
- **Community**: Forums and discussions
- **Certificates**: Not available on free tier
- **Projects**: Limited on free tier
- **Quizzes**: Basic included

## Pros

- Best-in-class interactive coding experience
- Browser-based editor with instant feedback
- Guided learning paths and skill tracks
- Clean, gamified interface
- Pro plan available free for students

## Cons

- Free tier very limited (no projects, no quizzes)
- Pro required for certificates
- No deep project-based learning (compared to TOP/fCC)
- Monthly subscription cost for Pro

## Key Features

- In-browser code editor with real-time feedback
- Step-by-step guided lessons
- Skill paths (Data Science, Web Dev, Python)
- Career paths (targeted job preparation)
- Code challenges and quizzes
- Portfolio projects (Pro only)

## Alternatives

- freeCodeCamp — completely free, project-based
- The Odin Project — deeper projects, free
- SoloLearn — mobile-first coding lessons
