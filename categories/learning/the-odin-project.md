## Free Tier Details

- **Paths**: Ruby on Rails and Node.js full-stack
- **Projects**: 20+ portfolio-ready projects
- **Content**: In-depth lessons, assignments, external resources
- **Community**: Active Discord for peer support
- **Curriculum**: Open-source and community-maintained

## Pros

- Thorough, project-driven approach
- Two paths (Rails or Node.js)
- Real-world portfolio projects
- Active community and support
- Open-source curriculum

## Cons

- No certificates or formal credentials
- Heavier focus on Ruby/Rails in one path
- Self-paced (no deadlines or structure)
- Less interactive than codecademy-style platforms

## Key Features

- Foundations course (basics for all)
- Full Stack Node.js path (Node, Express, MongoDB, React)
- Full Stack Ruby on Rails path (Ruby, Rails, PostgreSQL, React)
- Git and deployment lessons
- Job preparation resources
- Open-source contribution opportunities

## Alternatives

- freeCodeCamp — similar structure, more certifications
- Codecademy — interactive, less project depth
- MDN Web Docs — reference, not curriculum
