## Free Tier Details

- **References**: HTML, CSS, JavaScript, Web APIs
- **Guides**: Tutorials and learning pathways
- **Compatibility**: Browser compatibility tables for all features
- **Examples**: Interactive code examples (playground)
- **License**: Open-source, CC-BY-SA content

## Pros

- Authoritative source for web documentation
- Browser compatibility data for every feature
- Interactive example playground
- Open-source and community-maintained
- Multi-language support (20+ languages)

## Cons

- Documentation only (no hands-on exercises)
- Some advanced topics lack depth
- CSS references can be overwhelming
- No certification or assessment

## Key Features

- Complete HTML reference (elements, attributes, global attrs)
- Comprehensive CSS reference (properties, selectors, values)
- JavaScript reference (built-in objects, statements, expressions)
- Web API documentation (DOM, Fetch, Canvas, WebGL)
- HTTP documentation (headers, methods, status codes)
- Learning Area (beginner tutorials)
- Browser compatibility tables

## Alternatives

- DevDocs — aggregated API docs, fast search
- W3Schools — simpler, beginner-focused
- web.dev — Google's web development guides
