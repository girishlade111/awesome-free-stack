## Selection Guide

- **Best for complete beginners**: freeCodeCamp — structured, project-based, no account required
- **Best for career roadmaps**: roadmap.sh — visual guides for every developer role
- **Best university-level courses**: MIT OCW — actual MIT materials, completely free
- **Best CS degree alternative**: OSSU — rigorous curriculum from top universities
- **Best for interview prep**: LeetCode — largest problem library, company-specific questions
- **Best web development docs**: MDN Web Docs — authoritative, browser compatibility tables
- **Best interactive learning**: Codecademy — instant feedback in-browser editor
- **Best full-stack curriculum**: The Odin Project — project-driven, open-source
- **Best for certifications**: Coursera — recognized certificates from top universities
- **Best multi-language coding practice**: HackerRank — 40+ languages, domain tracks

> **Note**: All listed platforms have generous free tiers. Some (Coursera, Codecademy, LeetCode) have paid upgrades for certificates or advanced features. freeCodeCamp, MIT OCW, OSSU, The Odin Project, roadmap.sh, and MDN Web Docs are 100% free with no paid plans.
