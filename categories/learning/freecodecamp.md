## Free Tier Details

- **Curriculum**: 10+ professional certifications
- **Hours**: 2,000+ hours of interactive coding
- **Languages**: HTML, CSS, JavaScript, Python, SQL, and more
- **Projects**: 5 projects per certification
- **Community**: Global forum, Discord, local study groups
- **Publication**: freeCodeCamp News (tech publication)
- **YouTube**: Thousands of free tutorial videos

## Pros

- Completely free — no paid tiers at all
- Comprehensive, structured curriculum
- Project-based learning with portfolio-worthy work
- Very active community and support
- Regular content updates and new certifications

## Cons

- No formal certificates (verified by badges only)
- Curriculum can feel slow for experienced devs
- No live instruction or mentorship
- Some topics covered at surface level

## Key Features

- Responsive Web Design certification
- JavaScript Algorithms and Data Structures
- Front End Development Libraries (React, Redux)
- Data Visualization (D3.js)
- Back End Development and APIs (Node, Express, MongoDB)
- Python for Data Science
- Quality Assurance and Testing

## Alternatives

- The Odin Project — Ruby/Rails + Node focused
- Codecademy — interactive, paid Pro for projects
- Khan Academy — beginner-friendly, broader scope
