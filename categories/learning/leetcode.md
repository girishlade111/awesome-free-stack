## Free Tier Details

- **Problems**: 2,000+ with varied difficulty
- **Solutions**: Community solutions and discussions
- **Contests**: Weekly contest (free)
- **Topics**: Algorithms, data structures, databases, shell
- **Languages**: 20+ programming languages

## Pros

- Largest collection of coding interview problems
- Company-specific question filters (Premium)
- Active community with detailed solution discussions
- Realistic mock interview experience
- Weekly contests to test skills

## Cons

- Premium ($35/mo) needed for company questions
- Free tier lacks official solutions
- No structured learning path
- Can be discouraging for absolute beginners

## Key Features

- Daily coding challenge
- Problem categories (Array, DP, Graph, etc.)
- Study plans (LeetCode Explore)
- Mock interview simulator
- Contest rankings and leaderboards
- Official solutions (Premium)
- AI-powered hints (Premium)

## Alternatives

- HackerRank — domain-specific tracks, free certifications
- Codewars — martial arts themed, community challenges
- Exercism — mentorship-focused, free
