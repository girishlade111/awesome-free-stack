## Free Tier Details

- **Curriculum**: Equivalent to CS bachelor's degree
- **Courses**: 40+ courses from MIT, Stanford, Berkeley, Princeton
- **Duration**: ~2-4 years (self-paced)
- **Community**: Discord, GitHub, study groups
- **Materials**: All free and open online

## Pros

- Complete CS education comparable to university degree
- Uses best free materials from top universities
- Active community and study groups
- Curriculum regularly updated
- Project portfolio opportunities

## Cons

- No formal degree or certificate
- Requires significant self-discipline
- No instructor support
- 2-4 year commitment for full curriculum
- Some courses have gaps in materials

## Key Features

- Intro CS (Python, Scratch)
- Core Programming (Java, data structures)
- Math (Calculus, Linear Algebra, Probability)
- Systems (Computer Architecture, OS, Networking)
- Theory (Algorithms, Computation)
- Applications (Databases, ML, Graphics)
- Capstone Project

## Alternatives

- freeCodeCamp — web dev focused, quicker path
- MIT OCW — individual courses without structure
- The Odin Project — full-stack web dev, not CS
