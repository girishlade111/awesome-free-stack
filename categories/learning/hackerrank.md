## Free Tier Details

- **Challenges**: Unlimited algorithmic, SQL, database, shell
- **Languages**: 40+ programming languages
- **Contests**: Regular coding competitions
- **Certifications**: 5 free skill certifications per year
- **Tracks**: Dedicated learning tracks (Problem Solving, Python, SQL, Java)
- **Leaderboards**: Global and contest-specific rankings

## Pros

- Broad range of domains (algorithms, SQL, regex, shell)
- Free skill certifications with LinkedIn integration
- Good mix of difficulty levels
- Company recruitment partnerships
- Clean interface and code editor

## Cons

- Fewer problems than LeetCode (especially algorithm)
- Less community discussion detail
- Certifications are not widely recognized
- Focus on breadth over depth in problem sets

## Key Features

- Algorithmic challenges (data structures, sorting, graphs)
- SQL and database challenges
- Python, Java, and language-specific tracks
- 30 Days of Code (beginner learning path)
- Coding competitions and contests
- Skill certifications (free, up to 5/year)
- Company-specific hiring challenges

## Alternatives

- LeetCode — larger problem set, interview-focused
- Codewars — gamified, community-created challenges
- Exercism — mentor-based, free
