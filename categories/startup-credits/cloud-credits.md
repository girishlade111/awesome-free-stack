# Cloud Credits for Startups

Major cloud providers offer substantial free credits for early-stage startups.

## AWS Activate

| Detail | Info |
|---|---|
| **Credits** | Up to $100,000 |
| **Tiers** | Founders ($1,000) / Portfolio ($100,000) |
| **Duration** | 2 years |
| **Services** | Full AWS access |
| **Support** | AWS Business Support included |
| **Training** | Free AWS training credits |
| **Requirements** | Must be early-stage startup (< 10 yrs old) |

### How to Apply

1. Join an AWS Partner Network (APN) member organization
2. Or apply through an approved accelerator/incubator
3. Founders tier: $1,000 credits + $750 Business Support
4. Apply at [aws.amazon.com/activate](https://aws.amazon.com/activate)

## Google Cloud for Startups

| Detail | Info |
|---|---|
| **Credits** | Up to $200,000 |
| **Tiers** | Stage 1 ($1,000) / Stage 2 ($2,000) / Stage 3 ($20,000+) |
| **Duration** | 2 years |
| **Services** | Full GCP access incl. Vertex AI, BigQuery |
| **Mentorship** | Startup mentorship included |
| **Requirements** | < 5 years old, less than $5M funding |

### How to Apply

1. Go to [cloud.google.com/startup](https://cloud.google.com/startup)
2. Submit application with company details
3. Credits are approved in stages based on milestones
4. Must have an active Google Cloud project

## Microsoft for Startups (Azure)

| Detail | Info |
|---|---|
| **Credits** | Up to $150,000 |
| **Tier 1** | $1,000 free Azure credits |
| **Tier 2** | $5,000 free Azure credits |
| **Tier 3** | $25,000+ Azure credits |
| **Duration** | 1 year per tier |
| **Services** | Full Azure, OpenAI Service, GitHub Enterprise |
| **Support** | Azure support included |
| **Requirements** | B2B or B2C software company, < 5 years old |

### How to Apply

1. Apply at [startups.microsoft.com](https://startups.microsoft.com)
2. Company must have a .com or .net domain
3. GitHub Copilot and GitHub Enterprise included
4. Access to OpenAI Service credits separate

## Oracle for Startups

| Detail | Info |
|---|---|
| **Credits** | Up to $10,000 |
| **Duration** | 2 years |
| **Services** | OCI, Autonomous Database, Compute |
| **Requirements** | < 5 years old, < $5M funding |
| **Apply** | [oracle.com/startup](https://www.oracle.com/startup) |

## Comparison

| Provider | Maximum Credits | Duration | Easiest Tier |
|---|---|---|---|
| AWS Activate | $100,000 | 2 years | $1,000 (Founders) |
| Google Cloud | $200,000 | 2 years | $1,000 (Stage 1) |
| Microsoft Azure | $150,000 | 1 year | $1,000 |
| Oracle OCI | $10,000 | 2 years | Self-service |

## Tips

- **Stack them** — You can apply to all four providers simultaneously
- **Use credits wisely** — Credits expire, use them for scalable services
- **Start with the easiest tier** — Founders tier ($1k) is self-service
- **Accelerator access** — Joining an accelerator unlocks higher tiers
- **Renewal** — Most programs allow re-application at higher tiers as you grow
