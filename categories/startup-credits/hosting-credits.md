## Tips

- **Stack hosting** — Use Cloudflare CDN + Vercel hosting simultaneously
- **Vercel + Cloudflare** — Vercel for compute, Cloudflare for CDN/caching
- **Combine with cloud credits** — Use cloud provider credits for backend infrastructure
- **Accelerator bundling** — Many accelerators include hosting credits in their package
- **Start with free tier** — Test your stack on free tier before applying for startup plans
