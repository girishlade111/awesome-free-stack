## Credits & Benefits

- **Active Users**: 10,000 free (no time limit)
- **Features**: All Auth0 features included
- **Social Login**: Unlimited social connections
- **MFA**: Multi-factor authentication included
- **Security**: Anomaly detection, breached password detection
- **Customization**: Custom domains, Universal Login

## Pros

- 10,000 free users with full features
- No credit card required
- No time limit (not just 1 year)
- Enterprise-grade security features
- Excellent documentation and SDKs

## Cons

- Exceeding 10K users needs paid plan
- Premium add-ons (like SSO) not included
- More expensive than some alternatives at scale
- Complex pricing for advanced features

## Key Features

- Universal Login (hosted login page)
- Social login (Google, Apple, GitHub, etc.)
- Multi-factor authentication
- Anomaly detection and bot protection
- Machine-to-machine tokens
- User management dashboard
- Custom domains

## Alternatives

- Clerk — developer-friendly, generous free tier
- Supabase Auth — open-source, free
- Firebase Auth — free, limited features
