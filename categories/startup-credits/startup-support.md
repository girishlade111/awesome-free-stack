## Application Tips

- **Accelerator multiplier** — Most SaaS startup programs require you to be part of an accelerator
- **YC companies** get the widest access to startup programs
- **No accelerator?** — Apply to Google/Microsoft startup hubs for self-serve access
- **Timing** — Apply when you need the tool, not on day one
- **Negotiate** — Some programs offer better terms than advertised
- **Renewal** — Some programs allow extension if you're still early-stage

## Quick Start

1. **Join an accelerator** for maximum credit access
2. **Apply to all 3 cloud programs** (AWS, GCP, Azure) — they stack
3. **Claim SaaS tools** as you need them (Notion, Figma, Linear)
4. **Stripe** — Apply early; fee savings grow with revenue
5. **Stack everything** — Most programs are non-exclusive
