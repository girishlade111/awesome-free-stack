# AI Credits for Startups

Free credits and API access for AI-native startups and companies building with LLMs.

## OpenAI for Startups

| Detail | Info |
|---|---|
| **Credits** | $5,000+ in API credits |
| **Program** | OpenAI Startup Fund |
| **Duration** | Initial credits, then equity-based |
| **Services** | GPT-4, GPT-4o, DALL-E, Whisper, Embeddings |
| **Requirements** | Early-stage (< 3 years), AI-native focus |
| **Apply** | Via startup accelerators and VC partners |

## Tips

- **Start with free API providers first** — Groq, Gemini, DeepSeek have generous free tiers
- **Apply for GCP Startup** — Vertex AI credits are easiest to obtain
- **Use credits for scaling** — Save equity-based credits for growth phase
- **Combine with cloud credits** — AWS/GCP/Azure startup credits include AI services
- **Check accelerator access** — Many accelerators include OpenAI credits in their packages
