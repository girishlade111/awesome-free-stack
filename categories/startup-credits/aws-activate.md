## Credits & Benefits

- **Startup Tier**: $1,000 in AWS credits for 2 years, 45% discount on instance usage
- **Venture Tier**: $15,000-$100,000 through VC portfolio partners
- **Training**: Free AWS training and certification vouchers
- **Support**: Business-level AWS support included
- **Tools**: AWS Account Management and cost monitoring

## Pros

- Largest cloud ecosystem with most services
- Credits cover all AWS services (EC2, S3, Lambda, etc.)
- Two tiers for different startup stages
- Comprehensive training and support
- Integrates with YC, Techstars, and 100+ VC partners

## Cons

- Requires credit card even for credits
- Application process for venture tier
- Credits expire after 2 years
- Only cloud infrastructure (no SaaS perks)

## Key Features

- $1,000-$100,000 in AWS credits
- Business-level support
- AWS Training and certification
- Cost management tools
- Partner network access
- 45% instance discount
