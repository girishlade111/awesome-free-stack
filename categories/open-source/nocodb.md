## Free Tier Details

- **Self-hosted**: Completely free (AGPLv3)
- **Cloud Free**: Unlimited bases, 50,000 rows per base
- **Views**: Grid, Form, Gallery, Kanban, Calendar
- **API**: Full REST and GraphQL API
- **Automations**: Included
- **ACL**: Granular access control

## Key Features

- Turn any SQL database into a spreadsheet
- Multiple view types (Grid, Form, Gallery, Kanban)
- Rich API (REST + GraphQL)
- Webhook automations
- Role-based access control
- Import from Airtable, Excel, CSV
- Supports MySQL, PostgreSQL, SQL Server, SQLite
- Self-host (Docker, npm) or cloud
