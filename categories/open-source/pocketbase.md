## Free Tier Details

- **Database**: Embedded SQLite
- **Users**: Unlimited
- **Storage**: Unlimited file storage
- **Auth**: Email, OAuth2, magic links
- **API**: REST + realtime subscriptions
- **UI**: Built-in admin dashboard

## Key Features

- Single Go binary (no dependencies)
- Embedded SQLite database
- Auto-generated REST API
- Realtime subscriptions (WebSocket)
- File storage with thumbnails
- Authentication (email, OAuth, magic links)
- Admin dashboard UI
- Extensible with JavaScript hooks

## Alternatives To

- Firebase — PocketBase is the simplest self-hosted alternative
- Supabase — more features, heavier setup

## Alternatives

- Supabase — PostgreSQL-based, more features
- Nhost — GraphQL-based, serverless
- Directus — SQL-based, content management focus
