## Free Tier Details

- **Self-hosted**: Completely free (MIT)
- **Cloud Free**: 1 user, unlimited event types, 2 calendar connections
- **Booking**: Embeddable booking page
- **Duration**: Up to 30 min meetings
- **Routing**: Basic round-robin

## Key Features

- Customizable booking pages
- Multiple calendar integrations (Google, Outlook, Apple)
- Team scheduling (round-robin, collective)
- Workflow automation (email, SMS reminders)
- Embeddable widget
- Webhooks and API
- Self-hosted with Docker
- SSO and SCIM (paid)
