## Free Tier Details

- **Models**: 100+ (Llama 3, Mistral, Gemma, Phi, Qwen, DeepSeek)
- **Usage**: Unlimited, local-only
- **API**: OpenAI-compatible API
- **Platforms**: macOS, Linux, Windows
- **GPU**: NVIDIA GPU acceleration, Metal (Apple Silicon)

## Key Features

- Pull and run models with a single command
- OpenAI-compatible REST API
- Modelfile for custom model configurations
- GPU acceleration (NVIDIA + Apple Silicon)
- Llama 3.1 405B with quantization support
- Community model library
