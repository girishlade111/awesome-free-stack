## Free Tier Details

- **Documents**: Unlimited
- **Team**: 1 team (self-hosted unlimited)
- **Guests**: 10 guests (cloud)
- **History**: 30 day version history
- **Integrations**: Slack, Google, Microsoft SSO

## Key Features

- Real-time Markdown editor
- Nested document collections
- Full-text search with highlights
- Slack, Google, and Microsoft SSO
- API and webhooks
- Self-hosted (Docker) or cloud
- Mobile-responsive design
