## Free Tier Details

- **Chat**: Unlimited
- **Models**: Any Ollama or OpenAI-compatible model
- **RAG**: Upload documents for context-aware Q&A
- **Web Search**: Built-in web search
- **Users**: Multi-user with role management
- **Plugins**: Extensible plugin system

## Key Features

- ChatGPT-like conversation interface
- RAG (Retrieval Augmented Generation) with documents
- Web search integration
- Image generation (DALL-E, Stable Diffusion)
- Voice input support
- Multi-user with admin panel
- Docker deployment (single command)
