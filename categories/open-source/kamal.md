## Free Tier Details

- **Deployments**: Unlimited
- **Servers**: Multi-server
- **Containers**: Docker-based
- **Updates**: Zero-downtime rolling updates
- **Management**: Built-in health checks
- **Traefik**: Built-in reverse proxy

## Key Features

- Deploy to any server with SSH
- Zero-downtime rolling deployments
- Docker container orchestration
- Built-in Traefik reverse proxy
- Multi-server support
- Environment management
- Auto-generated SSL via Let's Encrypt
- CI/CD integration

## Alternatives To

- Vercel — Kamal deploys to your own servers
- Kubernetes — simpler, less overhead

## Alternatives

- Coolify — web UI, Vercel-like experience
