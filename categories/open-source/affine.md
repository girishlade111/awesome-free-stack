## Free Tier Details

- **Documents**: Unlimited rich text docs
- **Whiteboards**: Unlimited infinite canvas
- **Databases**: Unlimited
- **Storage**: Local-first, offline capable
- **Collaboration**: Real-time sync
- **AI**: Built-in AI features

## Key Features

- Block-based rich text editor
- Infinite canvas whiteboard
- Database / spreadsheet views
- Local-first with offline support
- Real-time collaboration
- Self-hosted or cloud
- Cross-platform (macOS, Windows, Linux, Web)
