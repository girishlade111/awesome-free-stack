## Free Tier Details

- **Cloud Credits**: $300 in Google Cloud credits
- **Skills Boost**: Additional credits for hands-on labs
- **Learning**: Access to Google Cloud training content
- **Labs**: Qwiklabs hands-on exercises
- **Services**: All Google Cloud services accessible
- **Duration**: Credits valid for 12 months

## Pros

- $300 in free credits — generous for trying services
- Google Cloud Skills Boost included
- Excellent documentation and training
- Can combine with Google Cloud Free Tier
- Covers all GCP services (Compute, Storage, AI, etc.)

## Cons

- Credits expire after 12 months
- Some advanced services are expensive
- Complex billing if you exceed credits
- Verification can take time

## Key Features

- Google Cloud Platform credits
- Cloud Skills Boost platform access
- Hands-on labs with real GCP environment
- Training for cloud certification
- Access to AI/ML services
- Students can also get Google Workspace

## Alternatives

- AWS Educate — $500+ credits + labs
- Azure for Students — $100 + 25+ free services
- Oracle for Education — $300 + always-free tier
