## Free Tier Details

- **Credits**: Free cloud credits for students (up to $300)
- **Always Free**: 4 ARM Ampere A1 cores, 24GB RAM, 200GB storage
- **Services**: Full OCI services access
- **Learning**: Oracle University learning content
- **Duration**: Credits valid for 12 months

## Pros

- Generous always-free tier (4 ARM cores, 24GB RAM)
- $300 in additional credits
- No credit card required for student program
- Always-free tier never expires
- Good for running production apps on free tier

## Cons

- Smaller ecosystem than AWS/Azure/GCP
- Less student community and resources
- Documentation not as developer-friendly
- Fewer student-specific offers

## Key Features

- OCI Compute (ARM and x86)
- Autonomous Database
- Object Storage
- Networking and Load Balancers
- Oracle University training
- Cloud credits for premium services

## Alternatives

- AWS Educate — $500+ more services
- Google Cloud for Students — better docs
- Azure for Students — Microsoft ecosystem
