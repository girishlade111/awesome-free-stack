## Free Tier Details

- **Credits**: $100 in Azure credits (no expiry while student)
- **Free Services**: 25+ permanently free services
- **Learning**: Free Microsoft Learn access
- **DevOps**: Azure DevOps free for students
- **Tools**: Visual Studio Enterprise free
- **Duration**: While enrolled as student ($100 credits)

## Pros

- $100 credits don't expire while enrolled
- 25+ always-free services
- Includes Visual Studio Enterprise
- Microsoft Learn training included
- Azure DevOps free for students

## Cons

- $100 is less than AWS/GCP offers
- Some services have usage limits
- Requires Microsoft account
- Credits are for Azure only, not other MS products

## Key Features

- Azure App Service, Functions, and VMs
- SQL Database and Cosmos DB
- AI and Machine Learning services
- Visual Studio Enterprise IDE
- Microsoft Learn training platform
- Azure DevOps for CI/CD

## Alternatives

- AWS Educate — $500+ credits + labs
- Google Cloud for Students — $300 + Skills Boost
- Oracle for Education — $300 + always-free tier
