# Google Cloud for Students

Google Cloud Platform offers free credits and learning resources for students.

## Google Cloud Skills Boost (formerly Qwiklabs)

| Detail | Info |
|---|---|
| **Credits** | $300 in Google Cloud credits |
| **Duration** | 12 months |
| **Card Required** | No (with student program) |
| **Services** | All GCP services |
| **Learning** | Free hands-on labs + skill badges |

### Included Free Tier (Always Free)

| Service | Limit |
|---|---|
| Compute Engine | 1 f1-micro VM (30 GB/mo) |
| Cloud Storage | 5 GB |
| Cloud Functions | 2M invocations/mo |
| Firestore | 1 GB storage |
| BigQuery | 1 TB queries/mo |
| Cloud Run | 2M requests/mo |
| Vertex AI | Custom model training (free tier) |

## Google for Education (Educator Program)

| Detail | Info |
|---|---|
| **Google Workspace** | Free for educational institutions |
| **Classroom** | Free LMS |
| **Credits** | Additional credits for educators |

## Google Cloud for Startups (Student Entrepreneurs)

| Detail | Info |
|---|---|
| **Credits** | Up to $2,000 |
| **Requirements** | Must be a startup founder |
| **Duration** | 2 years |

## Verification

| Method | Details |
|---|---|
| **Skills Boost** | `.edu` email |
| **Processing** | Instant |
| **Duration** | 12 months, renewable |
| **Card Required** | No |

## How to Claim

1. Go to [cloud.google.com/edu/students](https://cloud.google.com/edu/students)
2. Sign in with Google account
3. Verify `.edu` email
4. Access credits + free labs immediately
5. Enroll in skill badge programs for certifications
