## Free Tier Details

- **Duration**: 3 months free Premium (renewable)
- **Courses**: Unlimited access to all courses
- **Projects**: Real-world data projects
- **Assessments**: Skill assessments and tracks
- **Certificates**: Certificate for each course
- **Workspace**: In-browser coding environment

## Pros

- Best interactive data science learning platform
- Courses in Python, R, SQL, AI, and ML
- Hands-on exercises with real datasets
- Skill tracks and career paths
- In-browser coding (no setup)

## Cons

- Only 3 months free (renewable)
- Limited free tier without student pack
- DataCamp had past controversy (2019)
- Mostly data-science focused

## Key Features

- Interactive Python, R, and SQL courses
- Machine Learning and AI tracks
- Data Engineering and Analytics
- Real-world data projects
- Skill assessment and benchmarks
- Career tracks for specific roles

## Alternatives

- freeCodeCamp — completely free, web dev focus
- LinkedIn Learning — broader topics
- Kaggle — free data science competitions
