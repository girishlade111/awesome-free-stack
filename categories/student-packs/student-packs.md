## Selection Guide

- **Best starting point**: GitHub Student Developer Pack — unlocks 50+ partner offers
- **Best cloud credits**: AWS Educate ($500+ in credits + labs)
- **Best IDE offer**: JetBrains Student Licenses — all professional IDEs free
- **Best AI tools**: GitHub Copilot (free) + OpenAI API ($200 credits)
- **Best for design**: Figma Education — full Professional plan free
- **Best for learning**: LinkedIn Learning — 20K+ free courses with certificates
- **Best for domains**: Namecheap Bundle — free .me domain + SSL
- **Best for data science**: DataCamp — free 3 months Premium access
- **Best Git tool**: GitKraken Student — free Pro license

> **Note**: All offers require academic verification (.edu email, ISIC card, or school documentation). The GitHub Student Developer Pack is the most comprehensive single entry point — it bundles most of the other offers in one verification. Cloud credits from AWS, Google, Azure, and Oracle can be combined with the free tier for extended use. Offers are typically renewable annually while enrolled as a student.
