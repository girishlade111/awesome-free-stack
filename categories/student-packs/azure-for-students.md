# Azure for Students

Microsoft Azure provides free credits and services for students.

## Azure for Students

| Detail | Info |
|---|---|
| **Credits** | $100 free credit |
| **Duration** | 12 months |
| **Services** | VMs, App Service, Functions, SQL, AI services |
| **Card Required** | No |
| **Renewal** | Renewable annually while enrolled |

### Included Free Services

| Service | Limit |
|---|---|
| Virtual Machines | 750 hours B1s |
| App Service | 60 GB storage |
| Azure Functions | 1M requests/mo |
| Azure SQL | 250 GB database |
| Cognitive Services | 5,000 transactions/mo |
| Azure DevOps | 5 users, unlimited repos |
| GitHub Copilot | Free via GitHub Student Pack |

## Azure for Students Starter

| Detail | Info |
|---|---|
| **Credits** | No credit limit (restricted services) |
| **Audience** | Students under 18 |
| **Services** | Limited to web apps, functions, and learning resources |
| **Card Required** | No |

## Verification

| Method | Details |
|---|---|
| **Email** | `.edu` email (instant) |
| **Alternate** | ISIC card, enrollment verification |
| **Processing** | Instant with `.edu` |
| **Support** | [education@microsoft.com](mailto:education@microsoft.com) |

## How to Claim

1. Go to [azureforeducation.microsoft.com](https://azureforeducation.microsoft.com)
2. Sign in with Microsoft account
3. Verify student email
4. Credits available immediately
