## Free Tier Details

- **License**: GitKraken Pro (normally $59/year)
- **Repos**: Unlimited repositories
- **Integration**: GitHub, GitLab, Bitbucket
- **Features**: Merge conflict editor, dark theme, workspaces
- **Duration**: While enrolled as student

## Pros

- Beautiful drag-and-drop Git GUI
- Visual merge conflict editor
- Deep GitHub/GitLab/Bitbucket integration
- Great for Git beginners
- Includes CLI integration

## Cons

- Pro-only features (compared to free GitKraken)
- Heavier than CLI Git
- Some advanced features still paid
- Requires internet for some features

## Key Features

- Visual commit graph and branch management
- Drag-and-drop staging and committing
- Interactive rebase with visualization
- Merge conflict editor
- GitHub/GitLab/Bitbucket PR management
- Dark and light themes

## Alternatives

- GitHub Desktop — free, simple, official
- SourceTree — free, Atlassian
- Git CLI — free, no GUI needed
