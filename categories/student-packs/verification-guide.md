# Student Verification Guide

How to verify your student status across all major platforms.

## Verification Methods

### 1. School Email (.edu)

This is the fastest and most widely accepted method.

| Platform | Accepts `.edu` | Processing Time |
|---|---|---|
| GitHub Student Pack | ✅ | Instant |
| AWS Educate | ✅ | 24-48 hours |
| Azure for Students | ✅ | Instant |
| Google Cloud | ✅ | Instant |
| Figma Education | ✅ | Instant |
| Notion Education | ✅ | Instant |
| JetBrains | ✅ | Instant |
| Canva Education | ✅ | Instant |
| Salesforce | ✅ | Instant |
| Tableau | ✅ | Instant |

**Requirements**: Active `.edu` email address issued by your institution. Some platforms accept `.ac.*` (country-specific) and `.sch.*` emails.

### 2. ISIC Card (International Student Identity Card)

Used when `.edu` email is not available.

| Platform | Accepts ISIC | Processing Time |
|---|---|---|
| GitHub Student Pack | ✅ | 2-5 days |
| AWS Educate | ✅ | 24-48 hours |
| JetBrains | ✅ | 1-2 days |
| Figma Education | ✅ | 24 hours |
| GitHub Copilot | ✅ | 2-5 days |

**Cost**: ~$25 for the card. Valid for 16 months.

### 3. Enrollment Documentation

For institutions that do not provide `.edu` emails.

| Accepted Documents | Notes |
|---|---|
| Enrollment certificate | Issued by registrar |
| Current class schedule | Must show full name + institution |
| Tuition receipt | Current semester |
| Student ID card (photo) | Front and back |
| Official transcript | Current year |

### 4. Single Sign-On (SSO)

Some platforms support direct SSO through your institution.

| Platform | SSO Support |
|---|---|
| GitHub Education | Microsoft/Google for Education |
| Google Cloud | Google Workspace for Education |
| Azure | Microsoft 365 Education |
| Figma | Google for Education |

### 5. Third-Party Verification (SheerID)

Some platforms use SheerID for verification.

| Platform | Uses SheerID |
|---|---|
| GitHub Student Pack | ✅ |
| Figma Education | ✅ |
| Canva Education | ✅ |
| Notion Education | ❌ (direct email) |
| JetBrains | ❌ (direct email) |

**SheerID Process**: Submit name, institution, and documentation. Processing takes 2-5 minutes.

## Tips

- **Check eligibility first** — Not all programs are available in all countries
- **Use your `.edu` email** for everything — it unlocks the most benefits
- **Set a renewal reminder** — Most packs expire after 12 months
- **Keep documentation ready** — If `.edu` is not available, have enrollment docs scanned
- **Stack your benefits** — Claim all packs; they are additive, not exclusive
- **No `.edu`?** — Use ISIC card ($25) — pays for itself with first benefit
