# AWS for Students

Amazon Web Services offers multiple programs for students with free credits and learning resources.

## AWS Educate

| Detail | Info |
|---|---|
| **Credits** | $110 AWS credits (no card required) |
| **Duration** | 12 months |
| **Services** | EC2, S3, Lambda, RDS, SageMaker, and more |
| **Learning** | Free AWS training + labs |
| **Access** | AWS Educate Starter Account |

### How to Claim

1. Go to [awseducate.com](https://awseducate.com)
2. Sign up with your student email
3. Complete your profile
4. Receive credits within 24-48 hours
5. No credit card required

## AWS Activate (for Student Startups)

| Detail | Info |
|---|---|
| **Credits** | Up to $1,000 |
| **Requirements** | Must be part of a startup incubator or accelerator |
| **Duration** | 2 years |
| **Services** | Full AWS access |

## AWS Free Tier (Always Free)

| Service | Limits |
|---|---|
| EC2 | 750 hours/mo (t2.micro) |
| S3 | 5 GB storage |
| Lambda | 1M requests/mo |
| DynamoDB | 25 GB storage |
| RDS | 750 hours/mo (db.t2.micro) |

## Verification

| Method | Details |
|---|---|
| **AWS Educate** | `.edu` email or ISIC card |
| **Processing** | 24-48 hours |
| **Card Required** | No (starter account) |
| **Duration** | 12 months, renewable |
