## Stacking Guide

You can claim all of these simultaneously:

```
GitHub Student Pack      → Foundation (unlocks most others)
    ├── Vercel Pro        → Hosting
    ├── JetBrains         → IDE
    ├── GitHub Copilot    → AI Coding
    ├── Sentry            → Error Tracking
    └── Frontend Masters  → Learning

Cloud Providers (separate):
    ├── AWS Educate       → $110 credits
    ├── Azure             → $100 credits
    └── Google Cloud      → $300 credits

Design (separate):
    ├── Figma Education   → Design + Prototyping
    └── Canva Education   → Visual Design

Productivity (separate):
    ├── Notion Education  → Notes + Docs
    └── Todoist Premium   → Task Management
```

## Quick Start

1. **First**: Verify your student status (see [verification guide](./verification-guide.md))
2. **Second**: Claim [GitHub Student Pack](https://education.github.com/pack)
3. **Third**: Claim individual cloud credits (AWS, Azure, GCP)
4. **Fourth**: Claim design + productivity tools
5. **Fifth**: Set renewal reminders for 12 months
