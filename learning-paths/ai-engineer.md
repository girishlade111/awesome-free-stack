# AI Engineer Learning Path

Build AI-powered applications using LLMs, embeddings, vector databases, and RAG — free of charge.

## Phase 1: Foundations

| Topic | Free Resource | Duration |
|---|---|---|
| Python | [Python for Everybody](https://www.freecodecamp.org) | 4 weeks |
| Linear Algebra | [3Blue1Brown Essence](https://www.3blue1brown.com/topics/linear-algebra) | 2 weeks |
| Probability | [Khan Academy](https://www.khanacademy.org/math/statistics-probability) | 2 weeks |
| SQL | [SQL Bolt](https://sqlbolt.com) | 1 week |
| Git & GitHub | [GitHub Skills](https://skills.github.com) | 1 week |

### Tools
- **Language**: Python
- **Notebooks**: Google Colab (free GPU)
- **Editor**: VS Code + Jupyter
- **Vector DB**: Supabase pgvector (free)
- **LLM Access**: Groq, Gemini, DeepSeek (free tier)

## Phase 2: Machine Learning

| Topic | Free Resource | Duration |
|---|---|---|
| ML Fundamentals | [fast.ai Practical Deep Learning](https://course.fast.ai) | 6 weeks |
| NumPy & Pandas | [freeCodeCamp Data Analysis](https://www.freecodecamp.org) | 3 weeks |
| Scikit-learn | [Scikit-learn Tutorials](https://scikit-learn.org/stable/tutorial) | 2 weeks |
| Neural Networks | [3Blue1Brown Neural Networks](https://www.3blue1brown.com/topics/neural-networks) | 2 weeks |

### Platforms
- **Compute**: Google Colab (free T4 GPU), Kaggle (free GPU)
- **Datasets**: Hugging Face Datasets (free)
- **Model Hub**: Hugging Face (free inference)

## Phase 3: LLMs & RAG

| Topic | Free Resource | Duration |
|---|---|---|
| Transformers | [Hugging Face NLP Course](https://huggingface.co/learn/nlp-course) | 4 weeks |
| Prompt Engineering | [OpenAI Prompt Guide](https://platform.openai.com/docs/guides/prompt-engineering) | 2 weeks |
| Embeddings | [OpenAI Embeddings Guide](https://platform.openai.com/docs/guides/embeddings) | 1 week |
| Vector Databases | [pgvector docs](https://github.com/pgvector/pgvector) | 2 weeks |
| RAG Architecture | [LangChain RAG Tutorial](https://python.langchain.com/docs/tutorials/rag) | 3 weeks |
| AI Agents | [LangGraph Quick Start](https://langchain-ai.github.io/langgraph/tutorials/introduction) | 3 weeks |

### Free LLM Access
- **Groq**: 30 req/min on Llama-3, Mixtral (no card)
- **Gemini**: 60 req/min via API (free tier)
- **DeepSeek**: 500k tokens free
- **OpenRouter**: Multi-model router (free tier)

## Phase 4: Build

| Project | Stack | Difficulty |
|---|---|---|
| Text summarizer | Python + Gemini API | Beginner |
| Document Q&A (RAG) | LangChain + pgvector + Groq | Intermediate |
| AI chatbot with memory | LangGraph + Supabase | Intermediate |
| Autonomous agent | LangGraph + tools | Advanced |
| Image generation app | Replicate API + Next.js | Intermediate |

## Recommended Sequence

```
Python → ML Basics → LLM APIs → Embeddings → Vector DB → RAG → Agents → Deploy
```
