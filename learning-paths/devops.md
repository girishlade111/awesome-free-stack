# DevOps Learning Path

Master infrastructure, CI/CD, containers, and cloud deployment — entirely with free tools.

## Phase 1: Foundations

| Topic | Free Resource | Duration |
|---|---|---|
| Linux | [Linux Journey](https://linuxjourney.com) | 4 weeks |
| Networking | [Computer Networking Course](https://www.networkingcourse.org) | 3 weeks |
| Bash Scripting | [Learn Bash (freeCodeCamp)](https://www.freecodecamp.org/news/bash-scripting-tutorial-linux-shell-script-and-command-line-for-beginners) | 2 weeks |
| Git & GitHub | [GitHub Skills](https://skills.github.com) | 1 week |
| Text Editors | [Vim Tutor](https://vimtutor.com) | 1 week |

### Tools
- **Terminal**: Windows Terminal / iTerm2 (free)
- **Editor**: VS Code or Neovim
- **Git Hosting**: GitHub (free)
- **Cloud**: Oracle Cloud (always free), Google Cloud (free tier)

## Phase 2: Containers & Orchestration

| Topic | Free Resource | Duration |
|---|---|---|
| Docker | [Docker Curriculum](https://docker-curriculum.com) | 4 weeks |
| Docker Compose | [Docker Compose Docs](https://docs.docker.com/compose) | 2 weeks |
| Kubernetes | [Killercoda](https://killercoda.com/killer-shell-ckad) | 6 weeks |
| Helm | [Helm Docs](https://helm.sh/docs) | 2 weeks |

### Platforms
- **Container Registry**: Docker Hub (free), GitHub Container Registry
- **K8s Playground**: Play with Kubernetes (free), Killercoda
- **Local K8s**: Minikube, kind (free)
- **Managed K8s**: Oracle OKE (free), Google GKE (free tier)

## Phase 3: CI/CD & IaC

| Topic | Free Resource | Duration |
|---|---|---|
| GitHub Actions | [GitHub Actions Docs](https://docs.github.com/en/actions) | 3 weeks |
| Terraform | [Terraform Tutorials](https://developer.hashicorp.com/terraform/tutorials) | 4 weeks |
| Ansible | [Ansible Docs](https://docs.ansible.com/ansible/latest/index.html) | 3 weeks |
| Monitoring | [Prometheus Docs](https://prometheus.io/docs) | 3 weeks |

### Free CI/CD
- **GitHub Actions**: 2,000 min/mo (free)
- **GitLab CI**: 400 min/mo (free)
- **CircleCI**: 6,000 min/mo (free)
- **Render**: Free deploys from GitHub

## Phase 4: Cloud & Production

| Topic | Free Resource | Duration |
|---|---|---|
| Cloud Fundamentals | [Google Cloud Skills Boost](https://www.cloudskillsboost.google) | 4 weeks |
| Infrastructure Monitoring | [Grafana Tutorials](https://grafana.com/tutorials) | 2 weeks |
| Log Management | [Loki docs](https://grafana.com/oss/loki) | 2 weeks |
| Secrets Management | [Vault Tutorials](https://developer.hashicorp.com/vault/tutorials) | 2 weeks |
| Service Mesh | [Istio Docs](https://istio.io/latest/docs) | 3 weeks |

## Phase 5: Build

| Project | Stack | Difficulty |
|---|---|---|
| Dockerize a web app | Docker + Docker Compose | Beginner |
| CI/CD pipeline | GitHub Actions + Docker | Intermediate |
| Monitor a stack | Prometheus + Grafana | Intermediate |
| Kubernetes cluster | Minikube + Helm | Advanced |
| Full IaC deployment | Terraform + Cloud | Advanced |

## Recommended Sequence

```
Linux → Bash → Git → Docker → CI/CD (GitHub Actions) → Kubernetes → Terraform → Cloud
```
