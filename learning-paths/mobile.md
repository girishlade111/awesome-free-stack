# Mobile Developer Learning Path

Build cross-platform mobile apps using free tools, frameworks, and backend services.

## Phase 1: Foundations

| Topic | Free Resource | Duration |
|---|---|---|
| JavaScript | [JavaScript.info](https://javascript.info) | 4 weeks |
| TypeScript | [TypeScript Handbook](https://www.typescriptlang.org/docs) | 2 weeks |
| React | [React Docs](https://react.dev) | 4 weeks |
| Git & GitHub | [GitHub Skills](https://skills.github.com) | 1 week |

### Tools
- **Editor**: VS Code
- **Mobile Runtime**: Expo Go (free)
- **Version Control**: GitHub
- **Design**: Figma (free tier)
- **API Testing**: Hoppscotch

## Phase 2: React Native (Expo)

| Topic | Free Resource | Duration |
|---|---|---|
| Expo Basics | [Expo Docs](https://docs.expo.dev) | 3 weeks |
| React Native Core | [React Native Docs](https://reactnative.dev/docs/getting-started) | 4 weeks |
| Navigation | [Expo Router Docs](https://docs.expo.dev/router/introduction) | 2 weeks |
| State Management | [Zustand docs](https://docs.pmnd.rs/zustand) | 1 week |
| Styling | [NativeWind docs](https://www.nativewind.dev) | 1 week |

### Platforms
- **Development**: Expo Go (free, real device testing)
- **Build**: EAS Build (30 free builds/mo)
- **Updates**: EAS Update (10k/mo free)
- **Submit**: EAS Submit (free)

## Phase 3: Backend & Services

| Topic | Free Resource | Duration |
|---|---|---|
| Mobile Backend | [Supabase Docs](https://supabase.com/docs) | 3 weeks |
| Push Notifications | [Expo Push Docs](https://docs.expo.dev/push-notifications/overview) | 1 week |
| Auth | [Supabase Auth](https://supabase.com/docs/guides/auth) | 1 week |
| Storage | [Supabase Storage](https://supabase.com/docs/guides/storage) | 1 week |
| Real-time | [Supabase Realtime](https://supabase.com/docs/guides/realtime) | 1 week |
| Payments | [RevenueCat Docs](https://www.revenuecat.com/docs) | 2 weeks |

### Free Backend
- **Supabase**: 500 MB DB, 50k MAUs, 2 GB storage
- **Appwrite**: Open-source Supabase alt
- **Firebase**: Free Spark plan (limits apply)

## Phase 4: Advanced

| Topic | Free Resource | Duration |
|---|---|---|
| Offline-First | [WatermelonDB docs](https://nozbe.github.io/WatermelonDB) | 2 weeks |
| Animations | [Reanimated docs](https://docs.swmansion.com/react-native-reanimated) | 2 weeks |
| Maps | [MapLibre docs](https://maplibre.org) | 1 week |
| Deep Linking | [Expo Linking docs](https://docs.expo.dev/guides/linking) | 1 week |
| App Store Deployment | [Expo Submit guide](https://docs.expo.dev/deploy/submit-to-app-stores) | 2 weeks |

## Phase 5: Build

| Project | Stack | Difficulty |
|---|---|---|
| Todo app | Expo + Supabase Auth | Beginner |
| Weather app | Expo + OpenWeather API | Beginner |
| Chat app | Expo + Supabase Realtime | Intermediate |
| Social feed | Expo + Supabase + R2 | Intermediate |
| Full e-commerce | Expo + Stripe + RevenueCat | Advanced |

## Recommended Sequence

```
JavaScript → React → Expo → React Native → Navigation → Supabase → Push → Deploy
```
