# Backend Developer Learning Path

Build server-side applications, APIs, and data pipelines — fully free.

## Phase 1: Foundations

| Topic | Free Resource | Duration |
|---|---|---|
| Programming Basics | [Python for Everybody](https://www.freecodecamp.org) | 4 weeks |
| Data Structures | [freeCodeCamp DS&A](https://www.freecodecamp.org) | 4 weeks |
| HTTP & APIs | [MDN HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP) | 2 weeks |
| Git & GitHub | [GitHub Skills](https://skills.github.com) | 1 week |
| Linux Basics | [Linux Journey](https://linuxjourney.com) | 2 weeks |

### Tools
- **Language**: Node.js (free), Python (free), or Go (free)
- **Editor**: VS Code
- **API Client**: Hoppscotch
- **Database GUI**: DBeaver (free)
- **Container**: Docker (free for personal)

## Phase 2: Core Backend

| Topic | Free Resource | Duration |
|---|---|---|
| Node.js | [Node.js Dev Guide](https://nodejs.dev/en/learn) | 4 weeks |
| Express.js | [Express Docs](https://expressjs.com) | 3 weeks |
| SQL & PostgreSQL | [PostgreSQL Tutorial](https://www.postgresqltutorial.com) | 4 weeks |
| NoSQL | [MongoDB University](https://university.mongodb.com) | 2 weeks |
| REST API Design | [REST API Tutorial](https://restapitutorial.com) | 1 week |

### Platforms
- **Hosting**: Railway ($5 free credit), Render (free)
- **Database**: Supabase (free), Neon (free), MongoDB Atlas (free)
- **CI/CD**: GitHub Actions (free)

## Phase 3: Advanced

| Topic | Free Resource | Duration |
|---|---|---|
| Authentication | [Supabase Auth docs](https://supabase.com/docs/guides/auth) | 2 weeks |
| Caching | [Redis docs](https://redis.io/docs) | 2 weeks |
| Message Queues | [RabbitMQ tutorials](https://www.rabbitmq.com/tutorials) | 2 weeks |
| Testing | [Jest docs](https://jestjs.io/docs/getting-started) | 2 weeks |
| Docker | [Docker Curriculum](https://docker-curriculum.com) | 3 weeks |

## Phase 4: Build

| Project | Stack | Difficulty |
|---|---|---|
| URL shortener API | Express + SQLite | Beginner |
| Blog CMS with auth | Node.js + Supabase | Intermediate |
| Real-time chat server | WebSocket + Redis | Advanced |
| Payment processing API | Stripe + PostgreSQL | Advanced |

## Recommended Sequence

```
Python/Node.js → SQL → Git → HTTP/APIs → Express → PostgreSQL → Docker → Deploy
```
