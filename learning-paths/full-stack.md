# Full Stack Developer Learning Path

Build complete web applications from database to UI — end to end.

## Phase 1: Foundations

| Topic | Free Resource | Duration |
|---|---|---|
| HTML & CSS | [freeCodeCamp](https://www.freecodecamp.org) | 3 weeks |
| JavaScript | [JavaScript.info](https://javascript.info) | 6 weeks |
| Git & GitHub | [GitHub Skills](https://skills.github.com) | 1 week |
| Terminal | [Linux Journey](https://linuxjourney.com) | 2 weeks |
| SQL Basics | [SQL Bolt](https://sqlbolt.com) | 1 week |

### Tools
- **Editor**: VS Code
- **Browser**: Chrome DevTools
- **API Client**: Hoppscotch
- **Version Control**: GitHub
- **Database**: Supabase (free), Neon (free)

## Phase 2: Full Stack Core

| Topic | Free Resource | Duration |
|---|---|---|
| React | [React Docs](https://react.dev) | 6 weeks |
| Node.js | [Node.js Dev Guide](https://nodejs.dev/en/learn) | 4 weeks |
| Next.js | [Next.js Learn](https://nextjs.org/learn) | 4 weeks |
| TypeScript | [TypeScript Handbook](https://www.typescriptlang.org/docs) | 3 weeks |
| PostgreSQL | [PostgreSQL Tutorial](https://www.postgresqltutorial.com) | 3 weeks |

### Platforms
- **Hosting**: Vercel (free), Cloudflare Pages (free)
- **Database**: Supabase (free), Neon (free)
- **Auth**: Clerk (10k MAUs), Supabase Auth
- **Storage**: Cloudflare R2 (10 GB), Supabase (2 GB)
- **CI/CD**: GitHub Actions

## Phase 3: Advanced

| Topic | Free Resource | Duration |
|---|---|---|
| Authentication & RBAC | [Clerk docs](https://clerk.com/docs) | 2 weeks |
| File Uploads | [Uploadthing docs](https://docs.uploadthing.com) | 1 week |
| Real-time Features | [Supabase Realtime](https://supabase.com/docs/guides/realtime) | 2 weeks |
| Payments (Stripe) | [Stripe docs](https://stripe.com/docs) | 2 weeks |
| Testing | [Testing Library](https://testing-library.com) | 2 weeks |
| Deployment | [Vercel docs](https://vercel.com/docs) | 1 week |

## Phase 4: Build

| Project | Stack | Difficulty |
|---|---|---|
| Full-stack blog | Next.js + Supabase | Beginner |
| SaaS dashboard | Next.js + Clerk + Stripe | Intermediate |
| Real-time chat app | Next.js + Supabase Realtime | Intermediate |
| E-commerce platform | Next.js + Stripe + R2 | Advanced |
| AI chat app | Next.js + Groq API + pgvector | Advanced |

## Recommended Sequence

```
JavaScript → React → Node.js → SQL/PostgreSQL → Next.js → TypeScript → Auth → Deploy
```
