# Frontend Developer Learning Path

Master frontend development from fundamentals to production deployment — all using free tools.

## Phase 1: Foundations

| Topic | Free Resource | Duration |
|---|---|---|
| HTML & CSS | [freeCodeCamp Responsive Web Design](https://www.freecodecamp.org) | 4 weeks |
| JavaScript Basics | [JavaScript.info](https://javascript.info) | 6 weeks |
| Git & GitHub | [GitHub Skills](https://skills.github.com) | 1 week |
| Terminal Basics | [Learn CLI the Hard Way](https://cli.learncodethehardway.org) | 1 week |

### Tools
- **Editor**: VS Code (free)
- **Browser**: Chrome DevTools
- **Version Control**: GitHub
- **Design**: Figma (free tier)

## Phase 2: Modern Frontend

| Topic | Free Resource | Duration |
|---|---|---|
| ES6+ JavaScript | [freeCodeCamp JS Algorithms](https://www.freecodecamp.org) | 4 weeks |
| TypeScript | [TypeScript Handbook](https://www.typescriptlang.org/docs) | 3 weeks |
| React | [React Docs](https://react.dev) | 6 weeks |
| State Management | [Zustand docs](https://docs.pmnd.rs/zustand) | 1 week |

### Platforms
- **Hosting**: Vercel (free tier)
- **Deploy**: GitHub Pages (free)
- **API Testing**: Postman or Hoppscotch (free)

## Phase 3: Advanced

| Topic | Free Resource | Duration |
|---|---|---|
| Next.js | [Next.js Learn](https://nextjs.org/learn) | 4 weeks |
| Tailwind CSS | [Tailwind Docs](https://tailwindcss.com/docs) | 2 weeks |
| Testing | [Vitest + Testing Library](https://testing-library.com) | 2 weeks |
| Performance | [web.dev](https://web.dev/learn) | 1 week |

## Phase 4: Build

| Project | Stack | Difficulty |
|---|---|---|
| Portfolio site | Astro + Tailwind | Beginner |
| Todo app with auth | React + Supabase | Intermediate |
| E-commerce UI | Next.js + Stripe | Advanced |
| Real-time dashboard | Next.js + Recharts | Advanced |

## Recommended Sequence

```
HTML/CSS → JavaScript → Git → React → TypeScript → Next.js → Tailwind → Deploy
```
