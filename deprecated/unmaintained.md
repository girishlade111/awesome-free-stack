# Unmaintained Projects

Open-source projects that are no longer actively maintained. The code may still work but use at your own risk.

## Criteria

A project is listed as unmaintained when:

- No commits in the last 12+ months
- No response to issues or pull requests for 6+ months
- No official statement of maintenance status
