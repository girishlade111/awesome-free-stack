# Deprecated Resources

This directory tracks tools and services whose free tier has been removed, degraded, or shut down.

## Status Definitions

| Badge | Status | Meaning |
|---|---|---|
| ⚠️ Deprecated | Free tier removed or reduced | Service exists but free offering is gone. Migration recommended. |
| 🗄️ Archived | Service shut down | Permanently gone. Included for historical reference only. |
| 🔧 Unmaintained | Open source, no updates | Code may still work but no active development. No guarantees. |
| 💀 Dead | Completely defunct | Service no longer exists. URL redirects or 404. |

## Sections

| File | Contents |
|---|---|
| [deprecated](./deprecated.md) | Tools whose free tier was removed or significantly reduced |
| [archived](./archived.md) | Services that have permanently shut down |
| [unmaintained](./unmaintained.md) | Open-source projects with no active maintainer |
| [dead-projects](./dead-projects.md) | Completely defunct projects |

## Data

Machine-readable data available at [`data/deprecated.json`](../data/deprecated.json).

## How to Deprecate a Resource

1. Open an issue using the [Report Broken Tool](../.github/ISSUE_TEMPLATE/report-broken-tool.yml) template
2. Specify the issue type (free tier removed, service shut down, etc.)
3. Provide evidence (announcement link, screenshot of pricing page)
4. Maintainer will verify, update the deprecated log, and remove from active categories
